# 수업 집필 지침 (하위 작업자용)

이 문서 하나만 읽고 수업 한 편을 완성할 수 있어야 한다. 전체 기준은 `PROJECT.md`에 있고,
여기에는 집필에 필요한 부분만 옮겨 둔다. 충돌하면 `PROJECT.md`가 우선한다.

## 1. 무엇을 만드는가

**학부 수업 교재의 한 장(chapter)**이다. 해당 주제를 처음 배우는 학생이 이 문서만 읽고도
따라갈 수 있어야 하고, 동시에 시험 준비에 다른 교재를 더 찾을 필요가 없을 만큼 충분해야 한다.
요약문, 쟁점 정리, 연구 리뷰가 아니다.

산출물은 `lesson.md` 하나다. 이 파일에서 HTML과 슬라이드가 자동 생성된다.
그림은 같은 폴더의 `assets/*.svg`로 직접 그린다.

## 2. 전개 순서 — 반드시 기본에서 응용으로

절 순서는 다음을 따른다. 주제에 따라 일부를 합치거나 뺄 수 있으나 **방향은 바꾸지 않는다.**

1. 정의와 생물학적 의의 — 이 물질·구조·현상이 무엇이고 왜 다루는가
2. 구조와 성질
3. 합성·대사 경로 — 단계, 효소, 보조인자, 세포 내 위치
4. 조절 — rate-limiting step과 그 조절 기전
5. 수송·분포·저장
6. 유도체와 생리적 기능
7. 이상과 질환 — 경로의 어느 지점이 막히면 무엇이 쌓이고 무엇이 모자라는가
8. 진단과 치료 — 약물이 어느 지점에 작용하는가

구조를 모르는 상태에서 조절을 먼저 설명하지 않고, 경로를 모르는 상태에서 약물을 먼저 설명하지 않는다.
선행 지식이 필요하면 그 자리에서 짧게 복습하고 넘어간다.

절 제목은 `1. Cholesterol의 구조와 생물학적 역할`처럼 **번호를 붙인 서술형 소단원 제목**으로 쓴다.
질문형 제목을 쓰지 않는다.

## 3. 분량과 밀도

- 절 7~10개, 절당 설명 800~1,500자, 전체 10,000자 이상
- 확인 문항 5개 이상, 절반 이상은 판단을 묻는 문항. 각 문항에 근거를 포함한 해설
- 참고문헌 5개 이상. 실제로 존재하는 문헌만 쓴다
- 수치를 쓴다. 정상 범위, 진단 역치, 용량, 빈도, 효과 크기를 적는다
- 기전을 쓸 때 어느 단계가 rate-limiting step인지, 조절이 깨지면 무엇이 쌓이고 무엇이 모자라는지를 밝힌다

## 4. 용어 — 가장 자주 지적받는 부분

**영문으로 쓴다**: 경로명, 효소명, 단백질·유전자명, 분자명, 세포소기관명, 해부학적 구역명,
질환명, 실험 기법명, 수용체·수송체명.

**한국어로 쓴다**: 일상 서술어, 기본 화학 동작(산화·환원·결합·분해·축적·배출),
완전히 자리 잡은 임상 용어(간, 신장, 혈액, 소변, 황달).

일본식 한자어를 쓰지 않는다.

| 쓰지 않는다 | 쓴다 |
|---|---|
| 율속 단계 | rate-limiting step |
| 측쇄 | side chain |
| 수산기 / 수산화 | hydroxyl기 / hydroxylation |
| 탈탄산 | decarboxylation |
| 활면소포체 / 조면소포체 | smooth ER / rough ER |
| 양친매성 | amphipathic |
| 유화 | emulsification |
| 세포내섭취 | endocytosis |
| 피막소포 | coated vesicle |
| 사구대 / 속상대 / 망상대 | zona glomerulosa / fasciculata / reticularis |
| 해당과정 | glycolysis |
| 당신생 | gluconeogenesis |
| 당원 | glycogen |
| 구연산 회로 | TCA cycle |
| 전자전달계 | electron transport chain |
| 상전이 온도 | phase transition temperature |
| 지질방울 | lipid droplet |
| 담즙정체 | cholestasis |

확립된 한국 의학용어는 한글을 쓰고 첫 등장에 영문을 병기한다(예: 당뇨병(diabetes mellitus)).
확신이 없으면 번역하지 말고 영문을 그대로 쓴다.

유전자는 이탤릭 대문자(`*LDLR*`), 단백질 산물은 정자체. 약어는 첫 등장에 full form을 적는다.
단위는 SI를 기본으로 하되 임상 관용 단위를 병기한다(예: 7.8 mmol/L (140 mg/dL)).

## 5. 그림 — 논문 figure처럼 그린다

- **수업당 최소 3개. 경로나 구조를 다루는 수업은 5개 이상.**
- **그림 안에는 라벨만 둔다. 문장을 넣지 않는다.** 이것이 가장 중요한 규칙이다.
  설명을 그림 안에 넣으면 글자가 서로 겹쳐 그림이 깨지고, 읽는 사람은 그림이 아니라
  작은 글자 덩어리를 만나 오히려 어려워한다. 논문의 figure를 보면 분자명과 단계 번호만
  있고 설명은 전부 범례에 있다. 같은 방식으로 그린다.
- **지켜야 하는 한 가지: 그림 안의 글자는 문장이 아니어야 한다.** 판정 기준은 셋이고
  하나라도 걸리면 문장으로 본다.
  - 한 줄이 **48자**를 넘는다
  - 마침표로 끝난다 (라벨은 마침표를 찍지 않는다)
  - 한 칸에 두 문장이 들어 있다
- **권고값: 글자 합계 380자, `<text>` 요소 26개.** 넘어도 불통과는 아니다. 표 형태의
  그림은 짧은 칸이 많아 넘을 수 있다. 다만 넘으면 그림 하나가 너무 많은 것을 담고 있는
  것은 아닌지 다시 본다. 표만 있는 내용이라면 SVG가 아니라 본문의 `|` 표로 쓴다.
- 확인은 다음으로 한다.

  ```
  python3 tools/qa_lesson.py --strict M01-W07-L01   새 그림은 이것으로 통과시킨다
  python3 tools/fig_audit.py --worst 20             문장이 남은 그림 목록
  python3 tools/fig_audit.py --lesson               수업별 평균
  ```

- **설명은 세 곳으로 옮긴다.**
  1. 본문의 `@fig` 캡션 — 읽는 사람이 보는 설명. 길어도 된다.
  2. SVG 맨 위의 주석 블록 — 집필자와 다음 개정자가 보는 설명. 이 그림이 무엇을
     보이려 하는지, 왜 이렇게 배치했는지, 캡션에 무엇을 쓸지 적는다.
  3. `aria-label` — 화면 낭독기가 읽는 설명.
- **그림 안의 글자는 모두 영문으로 쓴다.** 분자명, 효소명, 구조 라벨, 단계 표시를
  영문으로 적는다. 한글은 캡션과 SVG 주석에만 쓴다.
  (한글 글꼴이 없는 환경에서 슬라이드로 변환할 때 깨진다.)
- **말로 설명하지 말고 배치로 보인다.** 순서는 화살표, 대비는 같은 축에 나란히,
  양은 크기, 상태는 색으로 보인다. "A가 B를 활성화한다"를 글로 쓰지 말고 화살표를 그린다.
- **패널은 글자 하나로 나눈다.** `A` `B` `C`. 패널 제목을 길게 달지 않는다.
- 직접 SVG로 그린다. 교과서·논문 그림을 그대로 복제하지 않는다.
- 파일은 `assets/fig-<짧은이름>.svg`로 저장하고 본문에서 `@fig fig-<짧은이름> 캡션` 으로 부른다.

본보기: **`tools/figure-template.svg`**. 주석에 규칙이 들어 있고 예산 안에 들어간다.
새 그림은 이 파일을 복사해서 시작하면 된다.

SVG 작성 규칙:

- 루트에 `viewBox`, `width`, `height`, `role="img"`, `aria-label`(영문)을 둔다
- 색: 선·글자 `#16191d`, 강조·제목 `#003c71`, 표시 `#f2b705`, 보조 설명 `#4a5159`,
  상자 배경 `#ffffff`, 강조 상자 `#fff5d6`, 테두리 `#c6d2dd`
- 글꼴은 `font-family` 없이 두거나 `sans-serif`만 지정한다. 한글 글꼴 이름을 적지 않는다
- 화살표는 `<marker>`로 정의해 재사용한다
- 그림 하나가 한 가지를 설명한다. 본문에서 다루지 않은 요소를 채워 넣지 않는다
- 주석 안에 붙임표 두 개나 꺾쇠 여는 기호를 쓰지 않는다. XML 주석에서 금지된 글자라
  파일이 깨진다. 작도한 뒤 `xml.dom.minidom.parse`로 반드시 확인한다

@sec 2. 다음 절 제목

@quiz

@ref

마크업 규칙:

- `**굵게**`, `*기울임*`, `` `코드` ``, `^{위첨자}`, `_{아래첨자}`
- `- ` 불릿, 2칸 들여쓰기로 하위 수준
- `| ... |` 표. 구분선 행(`|---|`)은 넣어도 무시된다
- `> ` 임상 연계 상자, `=> ` 핵심 정리 상자
- `@fig <id> <캡션>` 그림 삽입

## 7. 금지 사항

- 기전 설명을 비유로 대체하지 않는다. 공장, 열쇠와 자물쇠, 택배, 도로 같은 비유를 쓰지 않는다
- 구어체 감탄, 수사적 과장, 학습자를 어린이로 취급하는 어조를 쓰지 않는다
- "매우 중요하다", "핵심이다", "~라고 할 수 있다" 같은 내용 없는 강조를 쓰지 않는다
- 존재하지 않는 문헌, DOI, 수치를 만들지 않는다. 확신이 없으면 수치를 빼거나 범위로 쓴다
- 문서 안에 제작 과정이나 작성 주체에 관한 서술을 남기지 않는다
