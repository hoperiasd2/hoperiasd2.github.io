reference만 있으면, 실제 wgsim(WASM)으로 그 reference 기반 가상 시퀀싱 리드를 만들어줍니다
1
정렬 (minimap2)
실제 minimap2 WASM 바이너리로 reads를 reference에 정렬합니다
minimap2 -a -x sr reference.fa reads.fastq > aligned.sam
2
정렬결과 정리 (samtools)
SAM → 정렬된 BAM으로 변환하고 인덱싱합니다
samtools sort aligned.sam -o aligned.sorted.bam && samtools index aligned.sorted.bam
3
변이 호출 (bcftools)
pileup을 만들고 변이를 호출합니다 (GATK의 경량 대안, 실제 도구)
bcftools mpileup -f reference.fa aligned.sorted.bam | bcftools call -mv -Ov -o variants.vcf

📚 포맷 가이드 탭을 눌러 각 파일 형식 설명 보기

4줄이 1개 read. ① @ID (read 이름) ② 서열(A/C/G/T) ③ + (구분선, 가끔 ID 반복) ④ 품질값 — 서열과 정확히 같은 길이.

품질값은 Phred+33 인코딩: ASCII 코드 - 33 = Phred quality. 문자 I(ASCII 73) → Q40(매우 좋음), 문자 #(ASCII 35) → Q2(매우 나쁨). wgsim으로 만든 파일은 보통 전부 같은 문자(Q20 균일) — 실제 시퀀서보다 단순화된 것.

SAM = 사람이 읽는 탭구분 텍스트. BAM = SAM을 그대로 이진 압축한 것 — 내용은 동일하고 용량만 작아짐(우리 예제에서 SAM 20MB → BAM 3.8MB). BAM은 직접 못 열고 samtools view로 다시 텍스트화해야 함.

SAM 컬럼: QNAME FLAG RNAME POS MAPQ CIGAR RNEXT PNEXT TLEN SEQ QUAL [태그들]

FLAG는 비트마스크: 4=매핑 안 됨, 16=역방향 가닥, 256=보조정렬 등. CIGAR는 정렬 모양(M=일치/불일치, I=삽입, D=결실, S=soft-clip). NM 태그 = 그 read의 edit distance(미스매치+indel 총 개수) — 이게 우리 "미스매치 비율" 계산의 근거.

##로 시작하는 줄 = 메타데이터(포맷 버전, 아래 INFO/FORMAT 필드가 뭘 뜻하는지 정의). #CHROM 줄 = 실제 데이터의 컬럼 이름.

데이터 줄: CHROM POS ID REF ALT QUAL FILTER INFO FORMAT SAMPLE — QUAL은 그 변이콜의 신뢰도(Phred 스케일, 높을수록 확실). INFO의 DP=depth(그 위치를 덮은 read 수), AF=alternate allele 비율.

FORMAT:SAMPLE 부분의 GT=genotype(0/0=ref 동형, 0/1=이형접합, 1/1=alt 동형), PL=각 genotype의 우도(작을수록 그 genotype일 가능성 높음).
