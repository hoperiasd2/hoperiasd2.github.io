# 의생명 강의록 아카이브 (`lectures/`)

의학생화학 · 의학분자생물학 · 중개의학 · 신경과학 강의록 **10묶음 123강**. 모든 강의는 HTML 강의록과 PPT 강의록으로 함께 제공됩니다.
모든 강의는 하나의 원고(`src/bNN*.md`)에서 **HTML 강의록**과 **PPT 강의록(.pptx, 발표자 노트 포함)** 이 동시에 생성됩니다.

- 전체 목록: `lectures/index.html`
- 묶음 목록: `lectures/bNN/index.html`
- 강의록 HTML: `lectures/bNN/lMM.html`
- 강의록 PPT: `lectures/bNN/ppt/bNN-lMM.pptx`

## 빌드

```bash
pip install python-pptx      # 1.0 이상
python3 lectures/build.py         # 전체 HTML + PPT 재생성
python3 lectures/build.py b03     # HTML 전체 + b03 묶음 PPT만 재생성
```

생성물(HTML, PPTX)도 저장소에 커밋되어 GitHub Pages에서 바로 열람·내려받기 됩니다.
원고를 고친 뒤에는 반드시 빌드를 다시 실행하고 생성물을 함께 커밋하세요.

## 원고 문법 (`src/bNN.md`)

여러 파일(`b01.md`, `b01_2.md`, …)은 파일명 앞 세 글자(`b01`)로 한 묶음에 합쳐집니다.

```text
=== B01                      ← 묶음 헤더 (첫 파일에만)
title: 의학생화학
en: Medical Biochemistry
desc: 묶음 설명

### L01                      ← 강의 시작
group: 당대사                 ← 소주제 (묶음 페이지에서 그룹 제목)
title: 포도당 수송과 해당과정
en: Glucose Transport and Glycolysis

@obj                         ← 학습 목표 (- 목록)
@sec 절 제목                  ← 본문 절 (여러 개)
  일반 문단
  - 글머리표 / "  - " 하위 글머리표
  | 표 | 머리글 |   (둘째 줄 |---| 구분선)
  > 임상 연계 상자
  !> 핵심 상자
@frontier                    ← 연구 최전선 (- 목록)
@summary                     ← 요약 (- 목록)
@quiz                        ← Q: 질문 / A: 해설
@ref                         ← 참고문헌 (- 목록)
```

인라인: `**굵게**`, `*기울임*`, `^{위첨자}`, `_{아래첨자}`.

PPT 변환 규칙: 절마다 글머리표 슬라이드(분량에 따라 자동 분할) → 표 슬라이드 → 임상/핵심 상자 슬라이드.
절의 일반 문단은 발표자 노트로 들어갑니다(글머리표가 없는 절은 문단이 슬라이드 본문이 됨).
