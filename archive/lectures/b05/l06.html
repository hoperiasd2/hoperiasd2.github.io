The Metabolic Cascade of Ischemic Stroke

학습 목표

  1. 뇌혈류 역치(기능 정지 vs 세포 사멸)와 허혈 중심부·반음영의 개념을 설명한다.
  2. 허혈 연쇄반응(ATP 고갈 → 탈분극 → 흥분독성 → Ca²⁺ → 미토콘드리아 → 세포사)을 설명한다.
  3. 확산 탈분극, 산화 스트레스, 재관류 손상, 염증과 BBB 붕괴를 설명한다.
  4. 재관류 치료(혈전용해, 혈전제거술)와 영상 기반 환자 선택의 원리를 설명한다.
  5. 신경보호제 실패의 교훈과 대사·혈당 관리를 이해한다.

1뇌혈류 역치와 반음영

  • 정상 뇌혈류(CBF) 약 50 mL/100 g/분.
CBF (mL/100 g/분)결과
<20–25전기 기능 정지(EEG 평탄화), 가역적 — 반음영(penumbra)
<10–12이온 펌프 실패, 막 탈분극, 수 분 내 비가역 손상 — 허혈 중심부(core)
  • 반음영은 시간에 따라 중심부로 흡수(평균 대뇌동맥 폐쇄 시 분당 약 190만 신경세포 소실 — 'Time is brain', Saver 2006) → 측부순환이 좋을수록 반음영이 오래 유지.
  • 영상: CT 관류(CBF·Tmax), MRI 확산강조(DWI — 세포독성 부종 = 대략 중심부) / 관류 불일치 → 구제 가능 조직 추정; FLAIR 불일치(DWI+ FLAIR−)는 발병 4.5시간 이내 시사(시간 불명 뇌졸중의 혈전용해 선택 — WAKE-UP).

2허혈 연쇄반응

  • 에너지 실패: 산소·포도당 공급 중단 → 산화적 인산화 정지 → 혐기성 해당(젖산·H⁺) → ATP 수 분 내 고갈 → Na⁺/K⁺-ATPase 실패 → 무산소 탈분극.
  • 흥분독성: 탈분극 → 시냅스 글루탐산 방출 + 수송체 역작동(EAAT가 Na⁺ 기울기 붕괴로 글루탐산 방출) → NMDA(특히 시냅스 외 GluN2B)·AMPA 과활성 → Ca²⁺·Na⁺ 대량 유입.
  • Ca²⁺ 과부하: 칼페인(세포골격 분해), 포스포리파아제 A₂(아라키돈산 → 지질 과산화), nNOS(NO + 초과산화물 → 퍼옥시나이트라이트), 미토콘드리아 Ca²⁺ 흡수 → mPTP 개방 → 사이토크롬 c 방출 → 자멸/괴사.
  • 세포독성 부종: Na⁺·Cl⁻·물 유입(SUR1–TRPM4 통로 — 글리벤클라마이드 표적), 성상세포 AQP4.
  • 세포사 양상: 중심부 괴사, 반음영 자멸·네크롭토시스·페로토시스·파르타나토스(PARP1 과활성 → NAD⁺ 고갈·AIF 핵 이동).
  • 산증: 젖산·H⁺ → ASIC1a 통로 활성 → Ca²⁺ 유입·세포사; 고혈당은 산증을 악화시켜 경색 확대.

3확산 탈분극·재관류·염증·BBB

  • 확산 탈분극(spreading depolarization): 중심부에서 시작해 반음영으로 퍼지는 대규모 탈분극 파동(2–5 mm/분) → 반음영 에너지 소모·혈관 수축(역혈류 반응) → 경색 확대. 지주막하출혈·TBI·편두통 전조(피질 확산 억제)와 공통 기전.
  • 재관류 손상: 재관류 시 산소 → 숙신산 산화 RET → ROS 폭발(B03 L02 심근과 유사), 호중구 유입, 미세혈관 '무재관류'(주피세포 수축 — 모세혈관 협착; Hall et al., Nature 2014), 출혈성 변형.
  • BBB 붕괴: MMP-9(호중구·미세아교세포 — tPA가 활성 증가 → 출혈 위험), 치밀이음부 단백 분해 → 혈관성 부종(경색 후 2–5일 정점 → 대뇌 반구 악성 부종: 감압 개두술).
  • 염증: DAMP(HMGB1, ATP, 퍼옥시레독신) → TLR2/4 → 미세아교세포·침윤 대식세포 → IL-1β, TNF; 이후 IL-17 γδ T세포(장내 미생물 영향), 조절 T세포·IL-10 → 해소·수복(혈관 신생, 신경가소성).
  • 전신 반응: 뇌졸중 유발 면역저하(교감·HPA 활성 → 림프구 감소 → 폐렴), 고혈당 스트레스 반응.

4재관류 치료와 환자 선택

치료적응·근거
정맥 혈전용해(알테플라제 0.9 mg/kg, 테넥테플라제 0.25 mg/kg 단회 — 2024–2025 지침 대체)발병 4.5시간 이내(영상 불일치 시 9시간·시간 불명까지 확대 — EXTEND, WAKE-UP); 플라스미노겐 → 플라스민 → 피브린 분해
기계적 혈전제거술대혈관 폐쇄(내경동맥·M1) 6시간 이내(MR CLEAN 등 2015 다수 RCT) → 관류 불일치 시 24시간까지(DAWN, DEFUSE 3) → 대경색 중심부(ASPECTS 3–5)도 이득(SELECT2, ANGEL-ASPECT 2023)
이중 항혈소판(경증·TIA)아스피린 + 클로피도그렐 21일(CHANCE, POINT) — CYP2C19 저대사자는 티카그렐러(CHANCE-2; 한국·중국 의미 큼)
2차 예방원인별(심방세동 → DOAC, 경동맥 협착 → 내막절제/스텐트, 고LDL → LDL <70(TST 시험)), 혈압, 당뇨
  • 혈전용해제 생화학: tPA는 피브린 결합 시 활성 증가(피브린 특이성; TNK가 더 높음·반감기 긺), 출혈 위험(증상 있는 두개내출혈 ~2–6%) — 혈소판 <100,000, INR >1.7, 최근 DOAC 등 금기 확인; 다비가트란 역전 이다루시주맙 후 혈전용해 가능.

5신경보호와 대사 관리

  • 신경보호제 실패의 역사: NMDA 길항제(셀포텔, 아프티간엘), 칼슘 통로 차단제, 자유 라디칼 소거(NXY-059 SAINT II), 마그네슘(FAST-MAG), 저체온, 수많은 동물 성공이 임상 실패 → 원인: 재관류 없이 투여, 치료 시간 지연, 동물 모델(젊은 수컷·동반질환 없음)의 한계, 단일 경로 표적.
  • 재관류 시대의 재시도: 네리네타이드(PSD-95–nNOS 결합 차단; ESCAPE-NA1 — 알테플라제 미투여군에서 신호), ApTOLL(TLR4 길항), 혈전제거 후 동맥 내 신경보호(CHOICE — 동맥 내 혈전용해 보충), 에다라본 덱스보르네올(중국 승인 — TASTE), 원격 허혈 조건화(RICAMIS 긍정, RESIST 음성).
  • 대사 관리:
    • 고혈당: 입원 시 고혈당은 경색 확대·출혈·불량 예후와 연관(무산소 해당 젖산 증가) → 그러나 집중 인슐린(SHINE: 80–130 목표)은 기능 결과 개선 없이 저혈당만 증가 → 140–180 mg/dL 유지 권장.
    • 체온: 발열은 예후 악화 → 해열; 치료적 저체온은 뇌졸중에서 근거 부족(심정지 후 혼수와 구별).
    • 산소: 저산소 시에만 보충(SO2S — 일상 산소 무익).
    • 혈압: 혈전용해 전 <185/110, 후 <180/105 유지; 반음영 관류를 위해 과도한 강하 피함(혈전제거술 후 집중 강하 해로움 — ENCHANTED2/MT, OPTIMAL-BP).
    • 연하 선별, 조기 동원(AVERT: 24시간 내 집중 동원은 해로움), 정맥혈전 예방(간헐 공기압박).

연구 최전선

  • 재관류 후 '무재관류' 미세혈관 손상(주피세포 수축, 호중구 정체)을 표적하는 치료와 영상 지표가 개발 중이다.
  • 뇌졸중 후 회복기 신경가소성 강화(미주신경 자극 + 재활 — Vivistim 승인 2021, 선택적 세로토닌 재흡수 억제제 FOCUS 음성)와 줄기세포 치료가 연구되고 있다.
  • 뇌졸중 위험의 유전·대사 요인(NOTCH3 CADASIL, HTRA1, Lp(a), 클론성 조혈)과 정밀 2차 예방이 확장되고 있다.

요약

  • CBF 20 이하에서 기능이 멈추고 10 이하에서 비가역 손상이 생기며, 반음영은 시간과 측부순환에 의존하는 구제 가능 조직이다.
  • 허혈 연쇄반응은 ATP 고갈 → 무산소 탈분극 → 흥분독성 → Ca²⁺ 과부하 → 미토콘드리아·mPTP·다양한 세포사로 진행한다.
  • 확산 탈분극, 재관류 ROS·무재관류, MMP-9 BBB 붕괴, 염증과 면역저하가 손상을 확대한다.
  • 혈전용해(알테플라제·테넥테플라제)와 혈전제거술은 영상 기반 선택으로 시간 창이 24시간까지 확대되었다.
  • 신경보호제는 대부분 실패했으며 혈당 140–180, 발열 조절, 적절한 혈압 관리가 대사적 지지의 핵심이다.

자가 평가

  1. 같은 시간에 도착한 두 환자 중 한 명은 반음영이 크고 다른 한 명은 작았다. 이 차이를 만드는 주요 요인은?

    해설 보기

    측부순환(연수막 측부 혈관)의 발달 정도가 가장 중요하다. 측부순환이 좋으면 폐쇄 혈관 영역의 CBF가 10–20 사이로 유지되어 반음영이 오래 남는다. 그 외 혈압, 혈당, 체온, 개인의 대사 요구와 나이가 영향을 준다. 이 때문에 '시계 시간'보다 영상의 '조직 시간'으로 재관류 대상을 고른다.

  2. 입원 시 고혈당이 허혈성 뇌졸중 예후를 악화시키는 생화학적 기전은?

    해설 보기

    허혈 조직에서 포도당이 풍부하면 혐기성 해당이 증가해 젖산과 H⁺가 더 많이 축적되어 세포 내 산증이 심해지고, ASIC 통로 활성·미토콘드리아 손상·자유 라디칼 증가로 반음영이 중심부로 빨리 전환된다. 고혈당은 BBB 손상과 출혈성 변형도 증가시킨다. 다만 집중 인슐린으로 정상화해도 결과는 개선되지 않아 140–180 mg/dL 유지가 권장된다.

  3. 동물에서 효과적이었던 NMDA 수용체 길항제가 뇌졸중 임상시험에서 실패한 이유로 제시되는 것들은?

    해설 보기

    투여 시간이 동물보다 훨씬 늦었고(흥분독성은 초기 수 분–수 시간에 집중), 재관류 없이 약물이 허혈 조직에 도달하기 어려웠으며, 정상 뇌 기능에 필요한 NMDA 신호까지 차단해 정신 이상 등 부작용으로 충분한 용량을 쓰지 못했다. 또 동물 모델이 젊고 동반질환 없는 수컷 위주라 사람 환자의 이질성을 반영하지 못했다.

  4. 혈전제거술 후 혈압을 매우 낮게(수축기 <120) 유지하는 것이 오히려 해로울 수 있는 이유는?

    해설 보기

    재개통 후에도 일부 영역은 자동조절 능력이 손상되어 뇌관류가 혈압에 수동적으로 의존하며, 불완전 재관류 부위나 반음영은 관류압이 떨어지면 다시 허혈에 빠질 수 있다. 실제 ENCHANTED2/MT·OPTIMAL-BP 시험에서 집중 강하군의 기능 결과가 더 나빴다.
