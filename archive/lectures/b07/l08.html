학습 목표

2피질척수로와 운동 피질

  • 일차 운동피질(M1, 중심전회 4번 영역): 베츠 세포(5층) 포함; 체성 소인(운동 호문쿨루스 — 손·얼굴 확대); 자극 시 단순 움직임.
  • 보조운동영역(SMA — 연속 동작·내적 생성 운동, 자극 시 복잡 동작), 전운동영역(PMA — 감각 유도 운동), 전두안구영역.
  • 피질척수로: M1·전운동·SMA·두정엽(약 40%는 M1 외) → 방사관 → 내포 후각 → 중뇌 대뇌각 → 교뇌 기저부 → 연수 추체 → 추체 교차(약 85–90%) → 외측 피질척수로(원위 사지 — 손가락 독립 운동) / 비교차 10–15% → 전 피질척수로(체간·근위부, 양측 지배 → 체간은 일측 병변에 보존).
  • 피질연수로: 뇌신경 운동핵 — 대부분 양측 지배(그래서 일측 병변에 보존)이나 하부 안면(반대측 단독 지배)과 설하신경은 예외 → 중추성 안면마비는 이마 보존, 말초성(벨 마비)은 이마 포함.
  • 병변 수준별 특징: 피질(국소·손 우세, 피질 징후 동반), 내포(얼굴·팔·다리 균등한 순수 운동 반신마비 — 열공), 뇌간(교차 증후군 — 동측 뇌신경 + 반대측 반신마비), 척수(수준 이하, 감각 수준·방광).
  • 기타 하행로: 적핵척수로(굴근 촉진 — 제피질 경직), 전정척수로(신전근 — 제뇌 경직), 망상척수로(자세·보행 개시), 시개척수로.
    • 제피질 경직(상지 굴곡·하지 신전) = 적핵 위 병변; 제뇌 경직(사지 모두 신전) = 적핵 아래 뇌간 병변 → 더 나쁜 예후.

3기저핵

  • 구성: 선조체(미상핵 + 피각), 담창구(내·외절), 시상하핵(STN), 흑질(치밀부 SNc — 도파민, 망상부 SNr — 출력).

대뇌소뇌(외측 반구)피질 → 뇌교핵사지 숙련 운동 계획·타이밍사지 실조, 측정이상, 의도 진전, 길항운동반복불능

  • 회로: 이끼 섬유(뇌교핵·척수) → 과립세포 → 평행섬유 → 퍼킨예 세포(유일한 출력, 억제성 GABA) → 심부 소뇌핵(치상·중간위·실정) → 시상·적핵; 등정 섬유(하올리브) → 퍼킨예 복합 스파이크 → 오차 신호 → 평행섬유 시냅스 LTD → 운동 학습.
  • 동측성: 소뇌 출력이 교차(상소뇌각) → 시상 → 피질 → 다시 교차(피질척수로) → 이중 교차 → 병변과 같은 쪽 증상.
  • 임상 징후: 운동실조, 안진, 구음장애(스캐닝), 저긴장, 측정이상·과도조정, 반동 현상, 길항운동반복불능, 의도 진전, 로멜버그 음성(감각성 실조와 감별 — 소뇌 실조는 눈 감아도 크게 악화되지 않음).
  • 원인: 뇌졸중(상소뇌동맥·후하소뇌동맥), 알코올, 종양(수모세포종·전이), 유전성(SCA·FRDA — B06 L02), 다발성 경화증, 부신생물(항-Yo, 항-Hu), 저산소, 약물(페니토인), 비타민 E·B1 결핍, 갑상선기능저하, 셀리악.

5보행과 자세

  • 척수의 중추 패턴 발생기(CPG): 기본 리듬 생성(동물에서 명확, 사람은 척수 자극 연구로 간접 근거) → 중뇌 보행 영역·망상척수로가 개시·조절 → 소뇌가 타이밍, 기저핵이 자동화, 피질이 적응 보행(장애물·이중 과제).
  • 보행 장애 유형: 경직성(가위 보행 — UMN), 실조성(넓은 보폭·불규칙 — 소뇌), 감각성 실조(발 내리찍기·로멜버그 양성 — 후삭), 파킨슨(종종걸음·동결·전방 돌진), 실행증(자석 보행 — 정상압 수두증·전두엽), 근병증(오리 보행 — 근위부 약화), 족하수(계단 보행 — 말초신경), 보행 실조-실조성 운동(전두엽), 기능성 보행 장애.
  • 낙상 평가: 자세 반사(당기기 검사), 기립성 저혈압, 시력, 전정, 말초신경, 약물, 환경 — 다요인 개입이 효과적.
  • 정상압 수두증 3징: 보행 장애(가장 먼저·가장 잘 반응) + 요실금 + 인지 저하 → 요추 배액 검사 → 션트.

연구 최전선

  • 적응형(폐쇄회로) 심부뇌자극이 베타 진동 등 생체표지에 따라 자극을 조절해 파킨슨병 증상 조절과 부작용을 개선하고 있다.
  • 척수 경막외 전기자극과 뇌-척수 인터페이스가 척수 손상 환자의 보행을 부분적으로 회복시켰다(디지털 브리지 연구).
  • 소뇌의 비운동 기능(인지·정서·사회)이 재조명되면서 소뇌 자극이 조현병·우울·실조 재활에 시험되고 있다.

요약

  • UMN 병변은 경직·반사 항진·바빈스키 양성, LMN 병변은 위축·근육다발수축·반사 소실을 보인다.
  • 피질척수로는 연수 추체에서 대부분 교차하며, 피질연수로의 양측 지배 때문에 중추성 안면마비는 이마를 보존한다.
  • 기저핵 직접 경로는 운동을 촉진하고 간접 경로는 억제하며 도파민 소실은 파킨슨증, 간접 경로 손상은 무도증을 만든다.
  • 소뇌는 동측 증상을 일으키며 퍼킨예 세포 LTD를 통한 오차 기반 운동 학습을 담당한다.
  • 보행은 척수 CPG, 뇌간, 소뇌, 기저핵, 피질이 함께 조절하며 보행 양상이 병변 부위를 시사한다.

자가 평가

  1. 중추성 안면마비에서 이마 주름이 보존되는 이유는?

    해설 보기

    안면신경핵의 상부(이마·눈 주위 담당)는 양측 대뇌 반구에서 피질연수로 입력을 받지만, 하부(입 주위)는 반대측 반구에서만 입력을 받는다. 따라서 일측 피질·피질하 병변에서는 반대측 하부 안면만 마비되고 이마는 보존된다. 말초 안면신경 병변(벨 마비)은 핵 이후이므로 같은 쪽 얼굴 전체가 마비된다.

  2. 소뇌 병변이 반대측이 아니라 같은 쪽 증상을 일으키는 이유는?

    해설 보기

    소뇌 출력은 상소뇌각에서 교차해 반대측 시상·운동피질로 간 뒤, 그 피질에서 나온 피질척수로가 추체에서 다시 교차해 원래 소뇌와 같은 쪽 신체를 지배한다. 두 번 교차하므로 결과적으로 병변과 동측에 실조가 나타난다.

  3. 비케톤성 고혈당 환자에서 갑작스러운 편측 거친 던지는 듯한 불수의 운동이 생겼다. 기전과 영상 소견은?

    해설 보기

    반대측 시상하핵(또는 선조체) 기능 이상에 의한 편측무도증·반무도증이다. 시상하핵은 간접 경로에서 GPi를 흥분시켜 운동을 억제하는데, 이 억제가 사라지면 시상이 과도하게 탈억제되어 큰 진폭의 불수의 운동이 나타난다. MRI T1에서 반대측 선조체 고신호가 특징적이며 혈당 교정으로 호전된다.

  4. 감각성 실조와 소뇌성 실조를 침상에서 감별하는 방법은?

    해설 보기

    로멜버그 검사가 핵심이다. 감각성(후삭) 실조는 시각으로 보상하므로 눈을 뜨면 비교적 안정되다가 눈을 감으면 크게 흔들린다(양성). 소뇌성 실조는 눈을 떠도 이미 불안정하고 눈을 감아도 뚜렷이 악화되지 않는다. 감각성은 진동·위치 감각 소실과 발을 내리찍는 보행, 소뇌성은 안진·구음장애·측정이상을 동반한다.
