학습 목표

  1. 퓨린 de novo 합성(PRPP, IMP)과 조절을 설명한다.
  2. 퓨린 재활용 경로(HGPRT, APRT)와 레쉬-나이한 증후군을 설명한다.
  3. 퓨린 분해와 요산, 통풍·종양용해증후군의 병태생리와 치료 약물을 설명한다.
  4. 피리미딘 합성(CAD, DHODH, UMPS)과 리보뉴클레오타이드 환원효소, 티미딜산 합성효소를 설명한다.
  5. 항대사제(메토트렉세이트, 5-FU, 하이드록시유레아, 6-MP, 레플루노마이드, 마이코페놀레이트)의 표적과 면역결핍(ADA, PNP)을 연결한다.

1뉴클레오타이드의 기본과 PRPP

  • 뉴클레오타이드 = 염기 + 오탄당 + 인산. 퓨린(A, G; 이중고리), 피리미딘(C, T, U; 단일고리).
  • 기능: 핵산 단량체, 에너지 화폐(ATP, GTP), 보조인자 구성(NAD⁺, FAD, CoA), 활성화 중간체(UDP-포도당, CDP-콜린, SAM), 신호(cAMP, cGMP, c-di-GMP/cGAMP).
  • PRPP: 리보스-5-인산 + ATP → (PRPP 합성효소, PRPS1) PRPP. 퓨린·피리미딘 de novo·재활용, NAD⁺ 합성에 모두 필요.
임상 연계

PRPS1 기능획득 변이(X연관)는 퓨린 과생산 → 소아 통풍·요산 결석 및 감각신경성 난청을 일으키고, 기능소실 변이는 아츠 증후군, CMTX5 등 신경학적 질환을 일으킨다.

2퓨린 de novo 합성

  • 퓨린 고리는 PRPP 위에 조립된다. 원자 공급원: 글리신(C4, C5, N7), 아스파르트산(N1), 글루타민(N3, N9), CO₂(C6), 10-포밀-THF(C2, C8).
  • 1단계(속도결정): PRPP + 글루타민 → (글루타민-PRPP 아미도전이효소, GPAT/PPAT) 5-포스포리보실아민. AMP·GMP·IMP가 되먹임 억제, PRPP가 활성화.
  • 10단계를 거쳐 IMP(이노신산) 생성 → 분기:
    • IMP → (아데닐로숙신산 합성효소, GTP 사용, Asp) → AMP
    • IMP → (IMP 탈수소효소 IMPDH, NAD⁺) XMP → (Gln, ATP 사용) GMP
    • 교차 에너지 사용이 A와 G 풀의 균형을 맞춘다.
  • 퓨린 합성 효소들은 세포질에서 일시적 복합체 '퓨리노좀'을 형성한다.

임상 연계

티오퓨린은 TPMT와 NUDT15 활성이 낮은 사람(동아시아인에서 NUDT15 변이 흔함)에서 치명적 골수억제를 일으키므로 유전형 검사 후 용량을 조절한다(CPIC 지침). 6-MP는 크산틴 산화효소로도 분해되므로 알로퓨리놀 병용 시 6-MP 용량을 1/3–1/4로 줄여야 한다.

3퓨린 재활용과 레쉬-나이한 증후군

de novo 합성은 에너지 비용이 크므로(IMP 1개에 ATP 약 6–7) 세포는 분해된 염기를 재활용한다. 뇌·골수는 재활용 의존도가 높다.

  • HGPRT(HPRT1, X연관): 하이포잔틴 + PRPP → IMP; 구아닌 + PRPP → GMP.
  • APRT: 아데닌 + PRPP → AMP. 결손 시 2,8-다이하이드록시아데닌(DHA) 결석·신병증 → 알로퓨리놀/페북소스타트로 치료.
  • 뉴클레오사이드 키나아제(아데노신 키나아제, 데옥시사이티딘 키나아제 — 항암제 시타라빈·젬시타빈 활성화).

4퓨린 분해와 요산

  • AMP → (AMP 탈아미노효소; 근육) IMP → 이노신 / 아데노신 → (아데노신 탈아미노효소 ADA) 이노신 → (퓨린 뉴클레오사이드 포스포릴라아제 PNP) 하이포잔틴 → (크산틴 산화효소 XO; 몰리브덴) 크산틴 → (XO) 요산.
  • 사람과 유인원은 우리카아제(urate oxidase)가 없어 요산이 최종 산물이다(혈중 3–7 mg/dL; 항산화 기능 가설). 요산은 pH 7.4에서 주로 요산나트륨(monosodium urate)으로 존재하며 약 6.8 mg/dL에서 포화된다.
  • 배설: 신장 약 2/3(근위세뇨관 URAT1(SLC22A12)·GLUT9(SLC2A9) 재흡수, ABCG2 분비), 장 약 1/3(ABCG2).

6피리미딘 합성과 분해

  • 피리미딘 고리를 먼저 만든 뒤 PRPP에 붙인다.
  • ① CAD(다기능 단백질; 세포질): 글루타민 + CO₂ + 2ATP → (CPS II; 속도결정, UTP 억제·PRPP 활성) 카바모일인산 → (아스파르트산 트랜스카바모일라아제) → (다이하이드로오로타아제) 다이하이드로오로트산.
  • ② DHODH(미토콘드리아 내막; CoQ에 전자 전달) → 오로트산.
  • ③ UMPS(이기능): 오로트산 + PRPP → OMP → UMP.
  • UMP → UDP → UTP → (CTP 합성효소, Gln) CTP.
  • 리보뉴클레오타이드 환원효소(RNR): NDP → dNDP (티오레독신/글루타레독신, 라디칼 기전). 알로스테릭 활성 부위(ATP 활성, dATP 억제)와 특이성 부위로 4종 dNTP 균형 유지. 하이드록시유레아가 티로실 라디칼을 소거해 억제(겸상적혈구병 HbF 유도, 골수증식질환).
  • 티미딜산 합성효소(TS): dUMP + 5,10-메틸렌-THF → dTMP + DHF → (DHFR, NADPH) THF 재생.

시타라빈, 젬시타빈DNA 중합 사슬 종결, RNR 억제
  • 분해: 시토신·우라실 → (DPD, DPYD) → β-알라닌; 티민 → β-아미노이소부티르산. 퓨린과 달리 수용성 산물로 쉽게 배설된다.
임상 연계

DPYD 결함(예: c.1905+1G>A, c.2846A>T) 보유자는 5-FU/카페시타빈 표준용량에서 치명적 점막염·골수억제가 생기므로 2020년 이후 유럽은 투여 전 유전형/표현형 검사를 권고한다. 독성 시 해독제 우리딘 트라이아세테이트.

7뉴클레오타이드 대사와 면역결핍·빈혈

  • ADA 결핍: dATP 축적 → RNR 억제 → 림프구 dNTP 고갈 + 데옥시아데노신의 S-아데노실호모시스테인 가수분해효소 억제 → 중증복합면역결핍(SCID)(T, B, NK 모두 감소). 치료: 조혈모세포이식, PEG-ADA(엘라페가데마아제), 레트로바이러스 유전자 치료(Strimvelis; 최초 승인 체외 유전자치료 중 하나).
  • PNP 결핍: dGTP 축적 → T세포 결핍 우세 + 신경학적 증상, 요산 매우 낮음.
  • 유전성 오로트산뇨증(UMPS 결핍): 거대적모구빈혈(엽산·B12에 반응 없음), 성장 지연, 오로트산 결정뇨 → 우리딘 투여로 CPS II 되먹임 억제 + UMP 공급.
  • 거대적모구빈혈의 생화학: 엽산·B12 결핍 → dTMP 합성 저하 → dUTP 오삽입 → DNA 수선 반복·절단 → 핵 성숙 지연(핵-세포질 비동기).
  • SAMHD1(dNTP 가수분해효소) 결손 → 아이카르디-구티에레 증후군(cGAS–STING 인터페론 병증).
핵심

DNA 합성 차단 전략은 '빨리 분열하는 세포'를 표적하므로 항암제·면역억제제·항바이러스제·항균제가 같은 경로의 서로 다른 효소를 겨냥하며, 독성(골수억제, 점막염, 탈모)도 공통적이다.

연구 최전선

  • 피리미딘 합성 효소 DHODH가 미토콘드리아 호흡사슬과 직접 연결된다는 점 때문에, 호흡사슬 결함이 있는 종양이 DHODH 억제에 취약하다는 '합성치사' 전략과 급성골수성백혈병의 분화 유도(DHODH 억제 → 분화) 연구가 진행 중이다.
  • 2′3′-cGAMP 등 비정형 뉴클레오타이드 2차 전령의 선천면역 기능(cGAS–STING), 세균 CBASS 방어계와의 진화적 연결이 밝혀졌다.
  • 요산 저하가 만성콩팥병·심혈관질환 진행을 늦추는지에 대한 RCT(CKD-FIX, PERL)는 대부분 음성이었다 → 요산의 '표지자 vs 인과인자' 논쟁.
  • 메틸화된 뉴클레오사이드(m1A, m6A) 등 RNA 수식 대사가 '에피트랜스크립톰' 분야로 확장되고 있다(B02 L08).

요약

  • 퓨린은 PRPP 위에 고리를 조립해 IMP를 만들고(Gly, Asp, Gln, 10-포밀-THF), 피리미딘은 고리를 먼저 만든 뒤 PRPP에 붙인다(CAD–DHODH–UMPS).
  • HGPRT 결손(레쉬-나이한)은 재활용 실패와 퓨린 과생산으로 고요산혈증과 자해 행동을 일으킨다.
  • 요산은 XO가 만드는 최종 산물이며, 통풍은 MSU 결정–NLRP3–IL-1β 염증이다. 알로퓨리놀 전 HLA-B*58:01 확인.
  • RNR, TS, DHFR, IMPDH, DHODH는 항암·면역억제·항미생물 약물의 핵심 표적이다.
  • ADA·PNP 결핍은 dNTP 불균형으로 면역결핍을, UMPS 결핍은 우리딘 반응성 거대적모구빈혈을 일으킨다.

자가 평가

  1. 버킷림프종 환자가 항암치료 시작 24시간 후 소변량 감소, 부정맥을 보였다. 예상되는 검사 소견 4가지와 G6PD 결핍 환자에게 피해야 할 약물은?

    해설 보기

    종양용해증후군: 고요산혈증, 고칼륨혈증, 고인산혈증, 저칼슘혈증(인산칼슘 침착), 크레아티닌 상승. 라스부리카아제는 요산을 알란토인으로 산화하면서 H₂O₂를 만들어 G6PD 결핍 환자에서 용혈·메트헤모글로빈혈증을 일으키므로 금기이다.

  2. 레쉬-나이한 증후군에서 요산이 증가하는 두 가지 기전을 설명하라.

    해설 보기

    (1) HGPRT 결손으로 하이포잔틴·구아닌이 재활용되지 못하고 요산으로 분해된다. (2) 재활용에 쓰이지 않은 PRPP가 축적되어 퓨린 de novo 합성의 속도결정 효소(PPAT)를 활성화하고, 재활용 산물(IMP, GMP)에 의한 되먹임 억제가 줄어 퓨린 생산이 폭증한다.

  3. 거대적모구빈혈 소아가 엽산과 B12에 반응하지 않으며 소변에 결정이 보인다. 진단과 치료 원리는?

    해설 보기

    유전성 오로트산뇨증(UMPS 결핍). 피리미딘 합성 실패로 DNA 합성이 저하되어 거대적모구빈혈이 생기고 오로트산이 소변에 배설된다. 우리딘 경구 투여로 UMP를 재활용 경로로 공급하고, UTP 증가가 CPS II를 되먹임 억제해 오로트산 생산을 줄인다. OTC 결핍과 달리 고암모니아혈증이 없다.

  4. 아자티오프린 복용 중 알로퓨리놀을 추가한 환자에게 심한 범혈구감소증이 생겼다. 기전은?

    해설 보기

    아자티오프린의 활성 대사물 6-MP는 크산틴 산화효소로 불활성화된다. 알로퓨리놀이 XO를 억제하면 6-MP가 HGPRT를 통해 세포독성 티오구아닌 뉴클레오타이드로 과도하게 전환되어 골수가 억제된다. 병용이 불가피하면 티오퓨린 용량을 25–33%로 줄인다.
