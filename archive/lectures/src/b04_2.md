### L05
group: 내분비와 대사학
title: 인슐린·글루카곤과 당뇨병의 생화학
en: Insulin, Glucagon and the Biochemistry of Diabetes

@obj
- 인슐린 생합성과 β세포의 포도당 자극 인슐린 분비(GSIS) 기전, 인크레틴 효과를 설명한다.
- 인슐린 수용체 신호와 조직별 대사 작용, 글루카곤의 작용을 설명한다.
- 1형·2형·단일유전자 당뇨(MODY, 신생아 당뇨)의 병태생리와 분류를 설명한다.
- 인슐린 저항성의 분자 기전과 당뇨 합병증의 생화학을 설명한다.
- 당뇨 약물의 작용 기전과 최신 치료(인크레틴 다중작용제, 세포치료)를 정리한다.

@sec 인슐린의 합성과 분비
- *INS* → 프레프로인슐린(ER 신호서열 제거) → 프로인슐린(A–C–B; 이황화결합 3개) → 분비과립에서 **PC1/3·PC2**와 카복시펩티다아제 E가 절단 → 인슐린 + **C-펩타이드**(동몰; 내인성 분비 지표). 과립 내 아연-육량체 결정.
- **GSIS 경로**: 포도당 → GLUT1/2 → **글루코키나아제**(β세포 포도당 센서; Km ~8 mM) → 해당·산화 → **ATP/ADP 비↑** → **K_ATP 통로(Kir6.2/SUR1) 폐쇄** → 막 탈분극 → 전압개폐 L형 Ca²⁺ 통로 개방 → Ca²⁺ 유입 → 과립 세포외유출(SNARE).
  - 이상성 분비: 1상(즉시 방출 가능 과립, 5–10분 — 2형 당뇨 초기에 먼저 소실), 2상(지속).
  - 증폭 경로: 아미노산(류신 → GDH 활성; 아르기닌 탈분극), 지방산(FFAR1/GPR40), 부교감(ACh → M3 → Gq).
- **인크레틴 효과**: 경구 포도당이 정맥 포도당보다 인슐린을 2–3배 더 분비 — 장 L세포 **GLP-1**, K세포 **GIP** → β세포 GPCR → cAMP–PKA/EPAC2 → 포도당 의존적 분비 증폭. DPP-4가 수 분 내 분해. 2형 당뇨에서 인크레틴 효과 감소(GIP 반응 특히 저하).
- 억제: 소마토스타틴, α₂-아드레날린(교감; 스트레스 시 분비 억제), 렙틴.
| 약물 | 표적 |
|---|---|
| 설폰요소(글리메피리드), 메글리티나이드 | SUR1 결합 → K_ATP 폐쇄 (포도당 비의존 → 저혈당) |
| 디아족사이드 | K_ATP 개방 → 분비 억제 (고인슐린혈증) |
| GLP-1 RA, DPP-4 억제제 | 인크레틴 경로 (포도당 의존 → 저혈당 적음) |
> **신생아 당뇨**(생후 6개월 이내): *KCNJ11*/*ABCC8* 활성 변이(K_ATP가 닫히지 않음)가 약 50% → 인슐린 대신 **고용량 설폰요소**로 전환 가능(혈당 조절·신경발달 개선; Pearson et al., NEJM 2006) — 유전 진단이 치료를 바꾼 대표 예. 6q24 각인 이상은 일과성.

@sec 인슐린 신호와 대사 작용
- 인슐린 수용체(IR; α₂β₂ 수용체 티로신 키나아제) 자가인산화 → **IRS1/2** → **PI3K–AKT** 대사 경로 / Grb2–SOS–**Ras–MAPK** 성장 경로(B02 L02).
| 조직 | 작용 | 분자 |
|---|---|---|
| 골격근 | 포도당 흡수, 글리코겐 합성, 단백 합성 | AKT → AS160 → **GLUT4** 막 이동; GSK3 억제; mTORC1 |
| 지방조직 | 포도당 흡수, TG 합성, **지방분해 억제**(가장 민감) | GLUT4; PDE3B → cAMP↓ → HSL 억제; LPL 유도 |
| 간 | **포도당 생산 억제**(포도당신생↓, 글리코겐 분해↓), 글리코겐 합성, 지방 합성 | AKT → **FOXO1** 인산화·핵 배제 → PEPCK·G6Pase 전사↓; SREBP-1c↑; GCK 유도 |
| 뇌 | 섭식 억제, 말초 대사 조절 | 시상하부 |
- 인슐린은 문맥으로 분비되어 간이 처음 50–60%를 제거(간 '선점') → 간은 말초보다 고농도 인슐린에 노출. 피하 주사 인슐린은 이 생리적 기울기를 재현하지 못한다.
- **글루카곤**(α세포; 저혈당·아미노산이 자극, 인슐린·소마토스타틴·포도당이 억제) → 간 GCGR → Gs–cAMP–PKA → 글리코겐 분해·포도당신생↑, 해당·지방합성↓, 케톤 생성↑(B01 L01–L02), **아미노산 이화·요소 생성**(간-α세포 축: 아미노산↑ → 글루카곤↑ → 아미노산 제거; GCGR 차단 시 고아미노산혈증·α세포 증식).
- 반조절 호르몬 위계(저혈당 시): 인슐린 분비 감소(~80 mg/dL) → 글루카곤·에피네프린(~65–70) → 코르티솔·GH(지속 시) → 증상(~55) → 인지 장애(<50).

@sec 당뇨병의 분류와 병태생리
| 유형 | 병태생리 | 특징 |
|---|---|---|
| **1형** | T세포 매개 β세포 파괴; 자가항체 **GAD65, IA-2, ZnT8, 인슐린(IAA)**; HLA-DR3-DQ2/DR4-DQ8 | 3단계(자가항체 2개 이상 정상혈당 → 이상혈당 → 증상); DKA 경향; C-펩타이드 낮음; **테플리주맙**(항CD3)이 2단계에서 발병 약 2–3년 지연(2022 승인) |
| 성인 잠복 자가면역 당뇨(LADA) | 1형의 느린 형 | 성인, 초기 경구약 반응 후 인슐린 의존 |
| **2형** | 인슐린 저항성 + **진행성 β세포 기능부전**(β세포 탈분화·소실, 아밀린(IAPP) 아밀로이드, 지질·당독성, ER 스트레스) | 다유전자(*TCF7L2*가 가장 강한 흔한 변이), 비만·내장지방; 아시아인은 낮은 BMI에서 발병·β세포 기능 저하 우세 |
| **MODY** | 단일유전자 β세포 기능 이상(AD, 25세 이전, 비비만, 자가항체 음성, C-펩타이드 유지) | *HNF1A*(가장 흔함; **저용량 설폰요소 극민감**, 신장 당역치 낮음), *GCK*(경도 안정 공복고혈당 — 치료 불필요, 임신 시 태아 유전형 고려), *HNF4A*(신생아 거대아·저혈당 → 이후 당뇨), *HNF1B*(신장 낭종 + 당뇨 + 생식기 이상) |
| 기타 | 췌장 외분비 질환(췌장염, CF 관련 당뇨, 혈색소증, 췌장암), 내분비병증(쿠싱, 말단비대, 갈색세포종), 약물(글루코코르티코이드, 칼시뉴린 억제제, 면역관문억제제 → 급성 1형 유사, 비정형 항정신병약, 티아자이드), 미토콘드리아(m.3243A>G MIDD), 리포디스트로피 |
- 2형 당뇨의 새로운 아형화(스웨덴 ANDIS): 중증 자가면역(SAID), 중증 인슐린 결핍(SIDD — 망막병증 위험↑), 중증 인슐린 저항(SIRD — 신병증·MASLD↑), 경도 비만 관련(MOD), 경도 연령 관련(MARD).
- 진단 기준(ADA/대한당뇨병학회): HbA1c ≥6.5%, 공복 ≥126, OGTT 2시간 ≥200, 무작위 ≥200 + 증상. 당뇨 전단계: HbA1c 5.7–6.4%, 공복 100–125.

@sec 인슐린 저항성의 분자 기전
- **이소성 지질·DAG–PKCε 가설**(Shulman): 간 DAG 축적 → PKCε → 인슐린 수용체 Thr1160 인산화 → 키나아제 활성↓; 근육 DAG → PKCθ → IRS1 세린 인산화.
- **세라마이드**: PP2A 활성화·AKT 억제, 미토콘드리아 기능 저하 → 세라마이드 합성 억제가 동물에서 인슐린 감수성 회복.
- **염증**: 비만 지방조직의 M1 유사 대식세포·크라운 구조 → TNF-α·IL-1β → JNK·IKKβ → IRS1 세린 인산화; 장 투과성·LPS.
- **ER 스트레스·UPR**, **미토콘드리아 기능 저하**(근육 산화 능력↓; 원인인지 결과인지 논쟁), **고인슐린혈증 자체**가 저항성을 유발하는 '닭과 달걀' 문제.
- **선택적 인슐린 저항성**: 간에서 FOXO1 경로(포도당 생산 억제)는 저항, SREBP-1c 경로(지방 합성)는 유지 → 고혈당 + 고중성지방(B01 L06).
- 극단적 인슐린 저항성 증후군: *INSR* 변이(도노휴/레프리코니즘, 랍손-멘덴홀), B형(항인슐린 수용체 항체), 지방이영양증 — **흑색극세포증**, 고안드로겐(난소 인슐린 → 테카세포).
- **다낭성 난소 증후군(PCOS)**: 인슐린 저항성·고인슐린혈증 → 난소 안드로겐 합성↑ + 간 SHBG↓ → 고안드로겐, 무배란; 메트포르민·체중 감량 효과(B04 L07).

@sec 당뇨 합병증의 생화학
- **미세혈관**(망막병증, 신병증, 신경병증): 인슐린 비의존 포도당 유입 세포(내피, 메산지움, 슈반세포, 망막 주피세포)에서 고혈당 → 미토콘드리아 초과산화물 → **폴리올 경로, AGE–RAGE, PKC(DAG; PKCβ), 헥소사민(O-GlcNAc)** 4대 경로 활성화(Brownlee 통합 가설; B01 L04) → VEGF↑(증식망막병증, 황반부종 → 항VEGF 주사), TGF-β↑(사구체 경화, 알부민뇨), 신경 미세혈관·축삭 손상.
- **대사 기억(legacy effect)**: 초기 철저한 혈당 조절의 이득이 수십 년 지속(DCCT/EDIC, UKPDS 추적) — 후성유전 변화(NF-κB p65 프로모터 H3K4me1) 설명 가설.
- **대혈관**: 가속 죽상경화(이상지질, 인슐린 저항성, 고혈압, 염증, 혈소판 활성) — 당뇨는 관상동맥질환 위험 2–4배.
- **신경병증**: 원위부 대칭성 다발신경병증(장갑-양말형), 자율신경병증(위마비, 기립성 저혈압, 무증상 저혈당), 당뇨발(신경병증 + 허혈 + 감염).
- **신병증 진행 지연**: RAAS 차단, **SGLT2 억제제**(CREDENCE, DAPA-CKD), **피네레논**(비스테로이드성 MRA; FIDELIO), **세마글루타이드**(FLOW, 2024).

@sec 당뇨 치료의 기전
| 약물 | 기전 | 핵심 |
|---|---|---|
| 메트포르민 | 간 포도당 생산↓ — 복합체 I 약한 억제 → 에너지 전하·AMPK, 미토콘드리아 GPD2 억제(산화환원), 장 GDF-15·GLP-1↑ | 1차 약제, 체중 중립, B12 결핍, 젖산산증(eGFR <30 금기) |
| SGLT2 억제제 | 신장 포도당 재흡수 억제 | 심부전·CKD·심혈관 보호; 정상혈당 DKA, 생식기 감염 |
| GLP-1 RA(세마글루타이드, 둘라글루타이드) / GIP/GLP-1(티르제파타이드) | 인슐린 분비↑, 글루카곤↓, 위배출 지연, 중추 식욕 억제 | 체중 10–20% 감소, 심혈관 이득(SUSTAIN-6, SELECT), 위장관 부작용, 췌장염·담석 |
| DPP-4 억제제 | 내인성 GLP-1/GIP 보존 | 체중 중립, 저혈당 적음 |
| 티아졸리딘디온(피오글리타존) | PPARγ → 지방 재분포, 아디포넥틴↑ | 인슐린 감수성↑, MASH 개선; 부종·심부전·골절 |
| 설폰요소 | K_ATP 폐쇄 | 저렴, 저혈당·체중 증가 |
| α-글루코시다아제 억제제(아카보스) | 장 이당류 분해 지연 | 식후 혈당↓, 방귀 |
| 인슐린 | 기저(글라진, 데글루덱, 주 1회 아이코덱) + 식사(리스프로, 아스파트) | 1형 필수; 저혈당 |
- **기술**: 연속혈당측정(CGM; TIR >70%, TBR <4%), 자동 인슐린 주입(**하이브리드 폐쇄회로**, 인공췌장) — 1형 당뇨 관리의 표준으로 정착.
- **세포 치료**: 사체 췌도 이식(**도니슬레셀**, 2023 FDA 승인 — 면역억제 필요), 줄기세포 유래 췌도(VX-880/질리셀 — 1/2상에서 다수 인슐린 독립), 면역 회피 편집 세포(저면역원성 HIP 세포, 2025 면역억제 없이 생존 보고).

@frontier
- 삼중 작용제(레타트루타이드; GIP/GLP-1/글루카곤) 3상에서 체중 약 24% 감소, 경구 소분자 GLP-1 RA(오르포글리프론)가 승인 단계에 이르렀으며, 아밀린 유사체 병용(카그릴린타이드 + 세마글루타이드)이 개발 중이다.
- 1형 당뇨 예방: 자가항체 선별 프로그램(Fr1da, TrialNet), 테플리주맙, 베라파밀(β세포 TXNIP 억제), JAK 억제제(바리시티닙 BANDIT 시험 — C-펩타이드 보존)가 연구 중이다.
- 2형 당뇨 관해: 집중 체중 감량(DiRECT; 15 kg 감량 시 약 86% 관해)과 비만대사수술은 간·췌장 지방 감소로 β세포 기능을 회복시킨다는 '쌍둥이 순환(twin cycle)' 가설을 지지한다.

@summary
- β세포는 글루코키나아제–ATP/ADP–K_ATP–Ca²⁺ 축으로 인슐린을 분비하고, GLP-1·GIP가 이를 포도당 의존적으로 증폭한다.
- 인슐린은 PI3K–AKT를 통해 근육·지방의 포도당 흡수, 간의 포도당 생산 억제(FOXO1), 지방분해 억제를 일으키며 글루카곤은 반대로 작용한다.
- 1형(자가면역), 2형(저항성 + β세포 부전), MODY·신생아 당뇨(단일유전자; 설폰요소 반응)로 분류하며 유전 진단이 치료를 바꾼다.
- 인슐린 저항성은 이소성 지질(DAG–PKC, 세라마이드), 염증, ER 스트레스로 설명되고, 합병증은 고혈당 유도 4대 경로와 대사 기억으로 설명된다.
- 메트포르민·SGLT2i·GLP-1 RA·티르제파타이드·인슐린·폐쇄회로·세포치료가 현재와 미래의 치료 축이다.

@quiz
Q: 생후 3개월 영아의 당뇨가 *KCNJ11* 활성 변이로 확인되었다. 인슐린에서 설폰요소로 바꿀 수 있는 이유는?
A: 활성 변이로 Kir6.2 K_ATP 통로가 ATP에 의해 닫히지 않아 β세포가 탈분극하지 못해 인슐린이 분비되지 않는다. 설폰요소는 SUR1 소단위에 결합해 ATP와 독립적으로 통로를 닫으므로 β세포 탈분극과 인슐린 분비를 회복시킨다. 고용량이 필요하지만 혈당 조절이 개선되고, 뇌에도 K_ATP가 있어 일부 신경발달 증상도 호전될 수 있다.
Q: 25세 비비만 환자, 3대에 걸친 당뇨 가족력, 자가항체 음성, C-펩타이드 정상, 저용량 글리클라자이드에 저혈당이 생겼다. 의심 진단은?
A: HNF1A-MODY(MODY3). 상염색체 우성, 젊은 발병, 비비만, 자가항체 음성, 인슐린 분비 유지가 특징이며 설폰요소에 매우 민감하다. 신장 포도당 역치가 낮아 고혈당 이전에 요당이 나올 수 있다. *HNF1A* 유전자 검사로 확진하고 가족 검사를 시행한다.
Q: 메트포르민이 간 포도당 생산을 줄이는 기전으로 제시되는 가설 두 가지를 설명하라.
A: (1) 미토콘드리아 복합체 I을 약하게 억제해 세포 에너지 전하를 낮추고 AMP를 증가시켜, 글루카곤–cAMP 신호(아데닐산 고리화효소 억제)와 포도당신생의 에너지 공급을 줄이며 AMPK를 활성화한다. (2) 미토콘드리아 글리세롤인산 탈수소효소를 억제해 세포질 산화환원 상태(NADH/NAD⁺)를 바꿔 젖산·글리세롤로부터의 포도당신생을 억제한다. 장에서 GLP-1·GDF-15 분비 증가도 기여한다.
Q: 2형 당뇨 환자가 철저한 혈당 조절 후에도 수년간 망막병증이 진행했다. '대사 기억' 개념으로 설명하라.
A: 장기간의 고혈당이 혈관세포에 후성유전 변화(염증 유전자 프로모터 히스톤 메틸화 등), AGE에 의한 장수명 단백질 변형, 미토콘드리아 손상을 남겨, 혈당이 정상화된 이후에도 염증·산화 스트레스 경로가 지속 활성화되기 때문이다. 반대로 초기의 철저한 조절은 수십 년간 이득을 남긴다(legacy effect).

### L06

title: 갑상선·부신 호르몬의 대사 작용

@obj
- 갑상선호르몬의 합성(요오드 포획·유기화·결합)과 탈요오드효소에 의한 활성 조절을 설명한다.
- T3의 핵수용체 작용과 기초대사·열생성·지질·심장에 대한 대사 효과를 설명한다.
- 갑상선 기능 이상의 생화학적 진단과 약물 기전을 설명한다.
- 부신피질 스테로이드 합성 경로와 효소 결손(CAH)을 설명한다.
- 코르티솔·알도스테론·카테콜아민의 대사 작용과 쿠싱·애디슨·갈색세포종의 생화학을 설명한다.

@sec 갑상선호르몬의 합성
- **요오드 포획**: 기저측 **NIS**(Na⁺/I⁻ 공동수송체; TSH 자극) — 과염소산염·티오시안산염 경쟁 억제; 방사성 요오드 치료·스캔의 원리. 정단막 펜드린(*SLC26A4* — 펜드레드 증후군: 갑상선종 + 감각신경 난청)으로 여포강 이동.
- **유기화**: 여포강 경계에서 **갑상선 과산화효소(TPO)**가 H₂O₂(DUOX2 생성)로 I⁻ 산화 → 티로글로불린(Tg)의 티로신에 결합 → MIT, DIT.
- **결합(coupling)**: TPO가 DIT + DIT → T4, MIT + DIT → T3.
- 저장: 여포 콜로이드에 Tg 결합 형태로 수개월분.
- 분비: TSH → Tg 세포내섭취 → 리소좀 분해 → T4(~90%)·T3 방출(MCT8 수송체), MIT/DIT의 요오드는 **탈할로겐효소(IYD)**로 재활용.
- **볼프-차이코프 효과**: 고용량 요오드가 일시적으로 유기화를 억제(갑상선 수술 전 루골 용액); 탈출 실패 시 갑상선기능저하(자가면역 갑상선염 기저). **요드-바세도우**: 결절성 갑상선종에서 요오드 부하 후 항진(아미오다론, 조영제).
- 혈중 운반: TBG(~70%), 트랜스티레틴, 알부민; 유리형 T4 0.03%, T3 0.3%. 에스트로겐(임신·경구피임약)은 TBG↑ → 총 T4↑, 유리 T4 정상.

@sec 탈요오드효소와 T3의 작용
| 효소 | 반응 | 분포·의의 |
|---|---|---|
| **D1** | T4 → T3 (외환), rT3 분해 | 간·신장·갑상선; PTU가 억제 |
| **D2** | T4 → T3 (외환) | 뇌·뇌하수체·갈색지방·근육; 국소 T3 공급, 뇌하수체 TSH 되먹임 |

- 셀레노시스테인 함유 효소(셀레늄 결핍 → 기능 저하).
- **비갑상선 질환 증후군(정상 갑상선 병증후군)**: 중증 질환·기아 시 D1↓·D3↑ → T3↓, rT3↑, 중증 시 T4·TSH↓ → 에너지 절약 적응; 일반적으로 치료하지 않는다.
- **T3 작용**: 핵 갑상선호르몬 수용체(TRα — 심장·뼈, TRβ — 간·뇌하수체; RXR 이형이량체) → 유전자 전사:
  - 기초대사율↑: Na⁺/K⁺-ATPase·SERCA 발현, 미토콘드리아 생합성, UCP 발현 → 열생성.
  - 탄수화물: 장 흡수↑, 포도당신생·글리코겐 분해↑, 인슐린 분해↑.
  - 지질: **LDL 수용체 발현↑**(갑상선기능저하 → LDL↑), 지방분해↑(β수용체 증가), 콜레스테롤의 담즙산 전환.
  - 단백: 합성·분해 모두 증가(항진 시 근육 소모).
  - 심장: α-MHC↑·β-MHC↓, SERCA2↑·포스포람반↓, β₁ 수용체↑ → 빈맥·수축력↑, 심방세동.
  - 발달: 뇌 수초화·신경 이동(크레틴병), 골성숙.
- 갑상선호르몬 수송체 **MCT8**(*SLC16A2*) 결손 → **앨런-헌든-더들리 증후군**(X연관; 뇌는 저갑상선 — 중증 신경발달 장애, 말초는 고T3 — 체중 감소·빈맥) → T3 유사체 **티라트리콜(Triac)**로 말초 항진 교정.
- TRβ 선택 작용제 **레스메티롬**(MASH; B03 L03).

- **점액부종 혼수**: 저체온, 저나트륨, 저환기 → 정주 T4(± T3) + 하이드로코르티손(부신 기능저하 공존 배제 전).

@sec 코르티솔·알도스테론·카테콜아민의 대사 작용
- **코르티솔**(GR; 일주기 — 새벽 정점): 
  - 간 포도당신생↑(PEPCK·G6Pase 전사), 글리코겐 저장↑(공복 대비), 근육 단백 분해(아미노산 공급), 지방분해 허용·체간 지방 재분포, 인슐린 저항성.
  - 항염·면역억제(NF-κB·AP-1 억제, 림프구 자멸, 호산구 감소), 골 형성 억제(골다공증), 콜라겐 합성 억제(피부 얇아짐·자색선조), 혈관 카테콜아민 반응 허용.
  - **11β-HSD1**(간·지방; 코르티손 → 코르티솔 재활성) vs **11β-HSD2**(신장·태반; 코르티솔 → 코르티손 불활성 → MR 보호). 감초(글리시르레틴산)·이소성 ACTH의 과량 코르티솔은 11β-HSD2를 넘어 MR 자극 → 가성 알도스테론증.
- **알도스테론**(MR): 집합관 주세포 ENaC·Na⁺/K⁺-ATPase·ROMK ↑ → Na⁺ 재흡수, K⁺·H⁺ 배설; 비상피 작용(심근·혈관 섬유화).
- **카테콜아민**(부신수질; B01 L11): 에피네프린 β₂ → 간 글리코겐 분해·포도당신생, 근육 글리코겐 분해, β₁/β₃ 지방분해, α₂ 인슐린 분비 억제 → '투쟁-도피' 연료 동원.

| **쿠싱 증후군** | 선별: 1 mg 야간 덱사메타손 억제검사(아침 코르티솔 >1.8 µg/dL), 24시간 소변 유리 코르티솔, 심야 타액 코르티솔 → ACTH 측정: 낮음(부신 선종·과형성) / 높음 → 고용량 덱사메타손·CRH·하추체정맥동 채혈로 쿠싱병(뇌하수체) vs 이소성 ACTH(소세포 폐암, 카르시노이드) 감별; 치료제 오실로드로스타트(CYP11B1 억제), 메티라폰, 케토코나졸, 파시레오타이드, 미페프리스톤 |
| **애디슨병(1차 부신 기능저하)** | 아침 코르티솔↓ + ACTH↑ + 레닌↑, 저Na·고K, 과색소(POMC → α-MSH); 원인: 자가면역(21-수산화효소 항체; APS-1 *AIRE*), 결핵, 출혈(워터하우스-프리데릭센), X-ALD(남성 — VLCFA 확인), 면역관문억제제; 250 µg ACTH 자극검사 → 하이드로코르티손 + 플루드로코르티손, 스트레스 용량 교육 |
| 2·3차 부신 기능저하 | ACTH↓, 알도스테론 보존(고K 없음); 외인성 스테로이드 중단이 가장 흔한 원인 |
| **원발성 알도스테론증** | 고혈압 + (저칼륨) → 알도스테론/레닌 비(ARR) 선별 → 식염 부하 확진 → CT + **부신정맥채혈**(편측 선종 수술 vs 양측 과형성 MRA); *KCNJ5* 체세포 변이(선종 ~40%, 동아시아 더 흔함); 고혈압의 5–10%로 저평가됨 |
| 갈색세포종 | 혈장 유리 메타네프린 (B01 L11) |

@frontier
- 갑상선호르몬의 비전사적(non-genomic) 작용(인테그린 αvβ3 매개)과 TRβ 선택 작용제, T3 유사체(Triac, 소베티롬)의 대사·희귀질환 응용이 확대되고 있다.
- 알도스테론 합성효소(CYP11B2) 선택 억제제 **박스드로스타트·로르운드로스타트**가 난치성 고혈압 3상에서 혈압을 유의하게 낮췄다(2025).
- 일주기·초일주기 코르티솔 리듬을 모사하는 하이드로코르티손 방출 조절 제제·펌프가 부신 기능저하 환자의 대사 결과를 개선하는지 연구 중이다.

@summary
- 갑상선호르몬은 NIS 포획 → TPO 유기화·결합 → Tg 분해로 분비되며, 탈요오드효소(D1–D3)가 조직별 T3 활성을 정한다.
- T3는 핵수용체를 통해 기초대사·열생성·LDL 수용체·심장 유전자를 조절하며, MCT8 결손은 뇌와 말초의 갑상선 상태를 분리시킨다.
- TSH–FT4 패턴과 항체로 갑상선 질환을 진단하고 메티마졸·PTU·요오드·β차단제의 기전을 이해한다.
- 부신 스테로이드는 StAR–CYP11A1에서 시작해 층별 효소로 분기하며, CAH 효소 결손은 코르티솔·알도스테론·안드로겐·혈압 패턴으로 구분된다.
- 코르티솔은 포도당신생·단백 분해·면역억제를, 알도스테론은 Na⁺ 재흡수·K⁺ 배설을 담당하며 쿠싱·애디슨·원발성 알도스테론증의 생화학적 진단 흐름을 따른다.

@quiz
Q: 갑상선기능저하증 환자에서 LDL 콜레스테롤이 상승하는 기전은?
A: T3는 TRβ를 통해 간 LDL 수용체 유전자 발현을 증가시키고(SREBP-2 경로 포함), 콜레스테롤의 담즙산 전환(CYP7A1)도 촉진한다. 갑상선호르몬이 부족하면 LDL 수용체가 줄어 LDL 제거가 감소하므로 LDL-C가 상승한다. 따라서 이상지질혈증 평가 시 갑상선 기능을 확인해야 한다.
Q: 고혈압·저칼륨혈증·남성화를 보이는 여아의 CAH 효소 결손과 그 이유는?
A: 11β-수산화효소(CYP11B1) 결핍. 코르티솔 합성이 막혀 ACTH가 증가하고, 상류의 11-데옥시코르티솔과 DOC가 축적된다. DOC는 미네랄로코르티코이드 활성이 있어 고혈압·저칼륨을 일으키고, 축적된 전구체가 안드로겐 경로로 흘러 남성화가 생긴다. 21-수산화효소 결핍은 염류소실·저혈압을 보인다는 점에서 감별된다.
Q: 감초를 다량 섭취한 사람에게 고혈압과 저칼륨혈증이 생기지만 알도스테론과 레닌은 모두 낮다. 기전은?
A: 감초의 글리시르레틴산이 신장 11β-HSD2를 억제해 코르티솔이 코르티손으로 불활성화되지 못한다. 코르티솔은 알도스테론보다 훨씬 고농도로 존재하며 MR에 같은 친화도로 결합하므로 MR이 과활성화되어 Na⁺ 재흡수와 K⁺ 배설이 증가한다(가성 알도스테론증). 혈압 상승이 레닌·알도스테론을 억제한다.
Q: 갑상선 폭풍 치료에서 항갑상선제를 요오드보다 먼저 투여해야 하는 이유는?
A: 요오드를 먼저 주면 TPO 유기화가 차단되지 않은 상태에서 갑상선 내 요오드 기질이 늘어나 오히려 호르몬 합성이 증가할 수 있다. 메티마졸·PTU로 유기화를 먼저 차단한 뒤(약 1시간 후) 요오드를 투여하면 볼프-차이코프 효과와 Tg 분해·분비 억제로 이미 합성된 호르몬의 방출을 빠르게 줄일 수 있다.

### L07
group: 호르몬과 대사학
title: 성호르몬과 생식 대사: 사춘기, 임신, 폐경
en: Sex Steroids and Reproductive Metabolism

@obj
- 성스테로이드(테스토스테론, DHT, 에스트라디올, 프로게스테론)의 합성 경로와 핵심 효소(CYP19, 5α-환원효소)를 설명한다.
- 시상하부-뇌하수체-생식선 축과 키스펩틴, 사춘기 개시를 설명한다.
- 성호르몬의 대사 작용(지질, 포도당, 체성분, 뼈)과 성차를 설명한다.
- 성 발달 차이(DSD)와 PCOS의 생화학적 기전을 설명한다.
- 폐경·안드로겐 결핍과 호르몬 치료, 성호르몬 관련 약물의 기전을 이해한다.

@sec 성스테로이드 합성
- 콜레스테롤 → 프레그네놀론 → (Δ5 경로) DHEA → **17β-HSD3**(고환 라이디히) → 테스토스테론.
- **5α-환원효소**: 테스토스테론 → **DHT**(AR 친화도 2–10배) — SRD5A2(생식기 피부·전립선), SRD5A1(피부·간). 피나스테리드(2형), 두타스테리드(1·2형) → BPH, 남성형 탈모.
- **방향족화효소(CYP19A1)**: 안드로스테네디온 → 에스트론, 테스토스테론 → **에스트라디올** — 과립막세포(FSH 유도), 지방조직(폐경 후 주된 에스트로겐 원천 — 비만 여성 자궁내막암 위험), 뼈, 뇌, 태반.
  - 방향족화효소 억제제(아나스트로졸, 레트로졸 — 폐경 후 HR⁺ 유방암, 배란 유도), 결핍(*CYP19A1*) → 남성 골단 폐쇄 지연·큰 키·골다공증 → **뼈 성숙에 에스트로겐이 필수**임을 보여줌(남성에서도).
- **2-세포 2-성선자극호르몬 모델**: 난포막세포(LH → 안드로겐) + 과립막세포(FSH → 방향족화) → 에스트라디올.
- 운반: SHBG(테스토스테론·DHT 고친화; 에스트로겐·갑상선호르몬이 증가시키고 인슐린·안드로겐·비만이 감소시킴), 알부민. 생물학적 이용 가능 = 유리 + 알부민 결합.
- **역방향 경로(backdoor pathway)**: 17-OHP → DHT (테스토스테론 경유 없이) — 21-수산화효소 결핍 여아 남성화, 거세 저항성 전립선암 종양 내 안드로겐 합성(아비라테론 = CYP17A1 억제).

@sec 시상하부-뇌하수체-생식선 축과 사춘기
- 시상하부 **GnRH** 박동 분비(60–90분) → 뇌하수체 LH·FSH → 생식선. 지속적 GnRH 노출은 수용체 탈감작 → **GnRH 작용제(류프롤라이드) 지속 투여 = 억제**(중추성 성조숙증, 전립선암, 자궁내막증), GnRH 길항제(엘라골릭스, 렐루골릭스) — 즉시 억제.
- **키스펩틴(KISS1)–KISS1R**: GnRH 신경세포의 상위 조절자; KNDy 신경세포(키스펩틴·뉴로키닌 B·다이노르핀)가 GnRH 박동 생성기. 
  - *KISS1R*·*TACR3* 결손 → 저성선자극호르몬성 성선기능저하증(HH); *MKRN3* 기능소실(부계 각인) → 중추성 성조숙증(가장 흔한 유전 원인).
  - 칼만 증후군(*ANOS1*, *FGFR1*, *CHD7* 등): GnRH 신경세포 이동 실패(후각 기원판에서) → HH + **후각 상실**.
  - 뉴로키닌 B 수용체 길항제 **페졸리네탄트**(2023): 폐경기 혈관운동 증상(안면홍조) 비호르몬 치료.
- 사춘기 개시: 중추 GnRH 재활성(소아기 '휴지기' 해제) — 영양 상태(**렙틴** 허용 신호; 렙틴 결핍 → 사춘기 없음), 체지방, 유전(사춘기 시기 GWAS — *LIN28B*), 환경(내분비 교란물질).
- 사춘기 단계(태너), 성장 급증(에스트로겐 → GH–IGF-1 증폭, 결국 골단 폐쇄), 부신 사춘기(adrenarche; DHEA-S 증가 — 6–8세)와 생식선 사춘기의 구분.
- 성조숙증: 여아 8세·남아 9세 이전. 중추성(GnRH 의존; LH 반응↑) vs 말초성(맥큔-올브라이트, CAH, 생식선·부신 종양, *LHCGR* 활성 변이 '가족성 남성 제한 성조숙증').

| 성염색체 DSD | 45,X/46,XY 모자이크 등 | 다양 |
- DSD 관리: 다학제 팀, 성별 지정·수술 시기의 윤리, 생식세포종양 위험 평가.
- **PCOS**(가임기 여성 6–13%; 로테르담 기준 — 희발배란, 고안드로겐증, 다낭성 난소 중 2개):
  - 신경내분비: GnRH 박동 빈도↑ → LH/FSH 비↑ → 난포막 안드로겐↑.
  - 인슐린 저항성·고인슐린혈증 → 난포막 CYP17 활성↑ + 간 SHBG↓ → 유리 안드로겐↑; 난포 성숙 정지(AMH↑).
  - 장기 위험: 2형 당뇨, MASLD, 이상지질, 자궁내막 증식·암(무배란 → 프로게스테론 없는 에스트로겐), 수면무호흡, 우울.
  - 치료: 체중 감량, 경구피임약(SHBG↑, LH↓), 스피로노락톤(항안드로겐), 메트포르민, **레트로졸**(배란 유도 1차), GLP-1 RA.

@sec 임신·수유와 폐경의 내분비 대사
- 임신: hCG → 황체 프로게스테론(7–9주 태반 전환), 에스트리올(태아-태반 단위), hPL·프로락틴 → 인슐린 저항성(B04 L01), 갑상선 결합단백↑.
- 수유: 프로락틴(도파민이 억제; 항정신병약 → 고프로락틴혈증), 옥시토신(사출 반사), 칼슘 — 수유 중 PTHrP → 골흡수(일시적 골밀도 감소 후 회복).
- **폐경**(평균 50세; 12개월 무월경): 난포 고갈 → 인히빈 B·에스트라디올↓ → **FSH↑**. 
  - 대사 변화: LDL·Lp(a)↑, 내장지방↑, 인슐린 저항성↑, 골흡수 급증(폐경 후 5–7년 연 2–3% 골소실), 비뇨생식 위축, 혈관운동 증상(KNDy 신경세포 과활성).
  - 조기 난소부전(<40세): 터너, *FMR1* 전돌연변이(55–200 CGG), 자가면역, 갈락토스혈증, 항암치료 → 호르몬 대체가 심혈관·뼈 보호에 필요.
- **폐경 호르몬 요법(MHT)**: WHI(2002) 이후 재평가 — **'시기 가설'**: 60세 미만 또는 폐경 10년 이내 시작 시 혈관운동 증상·골절 이득이 위험보다 큼; 자궁 있으면 프로게스토겐 병용(자궁내막암 예방); 경피 에스트라디올은 정맥혈전·뇌졸중 위험 낮음(간 초회통과 회피); 에스트로겐 + 프로게스틴 병용은 유방암 위험 소폭↑.
- **남성 성선기능저하**: 아침 총 테스토스테론 반복 저하 + 증상 → LH/FSH로 1차/2차 구분 → 테스토스테론 대체(TRAVERSE 시험 2023: 심혈관 위험 증가 없음, 심방세동·폐색전 소폭↑); 헤마토크리트 >54% 시 중단; 불임 원하면 외인성 테스토스테론 금기(정자형성 억제) → hCG·클로미펜.

@frontier
- 성호르몬 수용체의 비전사 작용(막 ER — GPER)과 X 염색체 유전자 용량·불활성화 탈출 유전자가 면역 질환의 여성 우세(루푸스 90%)를 설명하는 기전으로 연구된다(*XIST* 리보핵단백 복합체가 자가항원으로 작용한다는 2024 Cell 보고).
- 성인 성별 확정 호르몬 요법의 장기 심혈관·골 대사 결과에 대한 코호트 연구가 축적되고 있다.
- 난소 노화의 분자 기전(난자 미토콘드리아·NAD⁺, 난포 세포 노화)과 난소 수명 연장(라파마이신 VIBRANT 시험) 연구가 시작되었다.

@summary
- 성스테로이드는 콜레스테롤에서 CYP17·17β-HSD·5α-환원효소·CYP19로 합성되며, DHT와 에스트라디올이 각각 강력한 활성형이다.
- GnRH 박동(키스펩틴·KNDy)이 사춘기와 생식을 조절하고, 지속 GnRH 작용제는 역설적으로 축을 억제한다.
- 에스트로겐은 지질·인슐린 감수성·뼈를 보호하고 안드로겐은 근육·적혈구를 늘리며, 대사 효과에 성 이형성이 있다.
- DSD는 성 결정·스테로이드 합성·수용체 결함의 생화학으로 분류되며, PCOS는 GnRH 박동 이상과 인슐린 저항성이 고안드로겐을 만든다.
- 폐경은 FSH 상승과 대사·골 위험 증가를 동반하며 MHT는 시기 가설에 따라 개별화하고, 남성 테스토스테론 대체는 생화학적 확인 후 시행한다.

@quiz
Q: 출생 시 여성형 외부생식기로 키워진 46,XY 아이가 사춘기에 음경이 커지고 목소리가 굵어졌다. 진단과 생화학적 확인 방법은?
A: 5α-환원효소 2형(*SRD5A2*) 결핍. 태아기에는 DHT가 부족해 외부생식기 남성화가 불완전하지만, 사춘기에 테스토스테론이 크게 증가하고 1형 효소가 일부 DHT를 만들어 남성화가 진행된다. 혈청 테스토스테론/DHT 비 상승(hCG 자극 후 더 명확)과 소변 5β/5α 대사물 비, 유전자 검사로 확진한다.
Q: PCOS에서 인슐린 저항성이 고안드로겐증을 악화시키는 두 가지 기전은?
A: (1) 고인슐린혈증이 LH와 협력해 난포막세포의 CYP17A1 활성을 높여 안드로겐 합성을 증가시킨다. (2) 인슐린이 간의 SHBG 합성을 억제해 유리(생물학적 활성) 테스토스테론 분율이 증가한다. 그래서 체중 감량과 인슐린 감수성 개선(메트포르민)이 안드로겐을 낮춘다.
Q: 방향족화효소 결핍 남성이 20대에도 키가 계속 자라고 골다공증이 생기는 이유는?
A: 골단판 폐쇄와 골흡수 억제는 테스토스테론이 아니라 방향족화로 만들어진 에스트로겐(ERα)에 의해 매개된다. 에스트로겐이 없으면 테스토스테론이 정상·높아도 골단이 닫히지 않아 선형 성장이 지속되고 골밀도가 낮아진다. 에스트로겐 투여 시 골단이 닫히고 골밀도가 개선된다.
Q: 폐경 호르몬 요법을 고려하는 58세 여성(폐경 6년, 정맥혈전 위험인자 있음)에게 경피 에스트라디올을 선호하는 이유는?
A: 경구 에스트로겐은 간 초회통과로 응고인자·CRP·SHBG·TG를 증가시켜 정맥혈전 위험을 높이지만, 경피 투여는 간 노출이 적어 혈전·뇌졸중 위험이 거의 증가하지 않는다. 60세 미만·폐경 10년 이내로 시기 가설상 이득이 큰 군이며, 자궁이 있으면 미분화 프로게스테론을 병용한다.

@sec 칼슘·인 항상성의 구조
- 칼슘: 체내 약 1 kg의 99%가 뼈(하이드록시아파타이트). 혈청 Ca 8.5–10.5 mg/dL = 이온화(~50%, 생리적 활성) + 알부민 결합(~40%) + 음이온 복합(~10%). 알칼리증은 알부민 결합↑ → 이온화 Ca↓(과환기 테타니).
- 인: 약 85%가 뼈, 세포 내 ATP·핵산·인지질·2,3-BPG. 혈청 2.5–4.5 mg/dL(소아 더 높음).
- 기관별 흐름: 장 흡수(Ca — 능동 TRPV6·칼빈딘(1,25-D 의존) + 수동 세포 사이; 인 — NaPi-IIb), 신장(Ca — 원위 TRPV5, 두꺼운 상행지 세포 사이(CaSR·클라우딘16/19); 인 — 근위 **NaPi-IIa/IIc**), 뼈(저장·완충).
- 센서: 부갑상선 **칼슘감지수용체(CaSR)** — Ca²⁺↑ → Gq/i → PTH 분비↓ (역 S자 관계; 설정점).

- 단일세포 아틀라스로 성장판 줄기세포(PTHrP⁺ 휴지대 세포), 골막 줄기세포가 정의되고, 노인 골절 치유를 높이는 표적이 탐색되고 있다.

@summary
- 칼슘·인 항상성은 CaSR–PTH, 비타민 D(CYP2R1 → CYP27B1 → CYP24A1), FGF23–Klotho가 장·신장·뼈에서 통합 조절한다.
- PTH는 Ca↑·인↓·1,25-D↑, FGF23은 인↓·1,25-D↓를 일으키며 25(OH)D가 비타민 D 영양 지표이다.
- 뼈 재형성은 RANKL/OPG(흡수)와 Wnt/스클레로스틴(형성)으로 조절되며 단일유전자 질환이 약물 표적을 알려주었다.
- 구루병·골연화증은 Ca 결핍형과 인 결핍형(FGF23 과잉 — XLH, TIO)으로 감별하고, 부갑상선 질환은 Ca–인–PTH–소변 Ca 패턴으로 진단한다.
- 골다공증 치료는 비스포스포네이트·데노수맙(흡수 억제), 테리파라타이드·로모소주맙(동화)이며 초고위험군은 동화제 우선이다.

@quiz
Q: 고칼슘혈증(10.9 mg/dL), PTH 경도 상승, 소변 Ca/Cr 청소율 비 0.006, 가족 중 같은 소견. 진단과 관리는?
A: 가족성 저칼슘뇨성 고칼슘혈증(FHH; *CASR* 기능소실). CaSR 설정점이 높아져 부갑상선과 신장이 높은 칼슘을 '정상'으로 인식하므로 PTH가 억제되지 않고 신장의 칼슘 배설이 낮다. 대개 양성으로 부갑상선 절제술이 효과가 없으므로 원발성 부갑상선기능항진과 감별해 불필요한 수술을 피하는 것이 핵심이다.
Q: 저인산혈증 구루병 소아에서 1,25-D가 '부적절하게 정상'인 것이 XLH 진단에 중요한 이유는?
A: 정상적으로 저인산혈증은 CYP27B1을 강하게 자극해 1,25-D를 높여야 한다. XLH에서는 *PHEX* 결손으로 FGF23이 과다해 CYP27B1을 억제하고 CYP24A1을 유도하므로 저인산혈증에도 1,25-D가 오르지 않는다. 이 패턴(저인산 + 인산뇨 + 정상/낮은 1,25-D + 높은 FGF23)이 FGF23 매개 질환을 시사하며 부로수맙 치료로 이어진다.
Q: 데노수맙을 5년 투여한 환자가 임의로 중단한 후 수개월 내 여러 척추 골절이 생겼다. 기전과 예방법은?
A: 데노수맙은 RANKL을 가역적으로 차단하며 뼈에 결합해 남지 않으므로, 중단 후 억제되어 있던 파골전구세포가 한꺼번에 활성화되어 골흡수가 기저치보다 크게 증가(반동)한다. 이로 인해 골밀도가 빠르게 소실되고 다발 척추골절이 생긴다. 중단 시 6개월 시점에 비스포스포네이트(졸레드론산 등)로 이어서 치료해야 한다.
Q: CKD 3기 환자에서 혈청 인과 PTH가 정상인데도 FGF23이 이미 상승해 있다. 의미는?
A: 네프론 수가 줄어들면 남은 네프론이 인을 더 배설해야 하므로 골세포가 FGF23을 초기부터 증가시켜 인 균형을 유지한다(보상). 이 때문에 혈청 인은 늦게까지 정상이다. 그러나 FGF23 상승은 1,25-D를 낮춰 2차 부갑상선기능항진을 시작시키고, 그 자체로 좌심실 비대·사망 위험과 연관되어 CKD-MBD의 가장 이른 표지가 된다.
