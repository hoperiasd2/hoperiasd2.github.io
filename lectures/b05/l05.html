학습 목표

  1. 발작의 대사적 비용과 발작 중·후 뇌 에너지 변화를 설명한다.
  2. 흥분/억제 균형의 생화학(글루탐산, GABA, 아데노신)과 항경련제 표적을 설명한다.
  3. 치료 가능한 대사성 뇌전증(GLUT1 결핍, 피리독신 의존, 세린·크레아틴 결핍 등)을 감별한다.
  4. 케톤생성식이의 처방·작용 기전·부작용을 설명한다.
  5. 항경련제의 대사 부작용(발프로산 고암모니아·간독성, 효소 유도)을 설명한다.

1발작의 대사적 비용

  • 발작 중 신경 발화가 수 배 증가 → ATP 소비·포도당·산소 요구 급증 → 국소 혈류 증가(발작 중 SPECT 고관류, 발작 간 FDG-PET 저대사 — 뇌전증 병소 국소화).
  • 뇌전증지속상태(SE): 30분 이상(실용적으로 5분) 지속 → 공급-수요 불일치 → 젖산 축적, ATP 고갈, Ca²⁺ 과부하, 흥분독성 신경세포 사멸(해마 CA1·CA3·문); 수용체 재배치 — 시냅스 GABA_A 수용체 내재화(벤조디아제핀 내성 증가) + NMDA 수용체 표면 증가 → 시간이 지날수록 치료 저항.
  • 치료 원칙: 5분 내 벤조디아제핀(로라제팜 정주, 미다졸람 근주/비강) → 2차(레비티라세탐, 포스페니토인, 발프로산 — ESETT: 동등) → 난치성 SE 마취제; 포도당·티아민 투여, 저나트륨·저칼슘·저마그네슘 확인.
  • 발작 후 대사 회복: 발작 후 억제기(postictal) — 아데노신 증가(내인성 항경련 신호), 저관류.
  • SUDEP(뇌전증 돌연사): 전신 강직간대 발작 후 호흡·심장 억제, 뇌간 세로토닌·아데노신 기능 이상 가설.

2흥분/억제 균형의 생화학

  • 글루탐산: 글루타민 → (글루타미나아제) 글루탐산 → VGLUT 소포 → 방출 → AMPA·NMDA·카이네이트·mGluR → EAAT1/2 재흡수 → 성상세포 글루타민 합성(B05 L01).
  • GABA: 글루탐산 → (GAD65/67, PLP) GABA → VGAT 소포 → GABA_A(Cl⁻ 통로)·GABA_B(GPCR) → GAT1 재흡수 → (GABA-T, PLP) 숙신산 세미알데하이드 → (SSADH) 숙신산(GABA 분로).
    • SSADH 결핍(ALDH5A1): γ-하이드록시부티르산(GHB) 축적 → 발달지연·경련·근긴장저하.
    • GABA-T 결핍: 드묾, 영아 뇌병증.
    • 신생아·발달 초기에는 NKCC1 우세로 세포 내 Cl⁻이 높아 GABA가 탈분극성(흥분성) → KCC2 성숙과 함께 억제성으로 전환 → 신생아 발작에 페노바르비탈 반응이 낮은 이유 중 하나(부메타니드 NKCC1 억제 시험은 음성).
  • 아데노신: ATP 분해 산물 → A1 수용체(시냅스 전 억제) — 내인성 항경련; 아데노신 키나아제(ADK) 과발현(반응성 성상세포)이 아데노신을 줄여 뇌전증 발생에 기여 → 케톤생성식이의 아데노신 증가 기전.

4케톤생성식이

  • 처방: 고전적 KD 4:1(지방 : 단백질+탄수화물 질량비; 열량의 ~90% 지방), MCT 식이(중쇄지방 — 더 강한 케톤 생성, 탄수화물 허용↑), 변형 앳킨스 식이(MAD; 탄수화물 10–20 g/일), 저혈당지수 치료(LGIT).
  • 효과: 약물 난치성 소아 뇌전증에서 약 절반이 발작 50% 이상 감소, 10–15% 무발작(Neal et al., Lancet Neurol 2008 RCT). 1차 적응증: GLUT1 결핍, PDH 결핍. 효과 좋은 증후군: 영아연축, 드라베, 도오세, TSC, 레트, CDKL5, FIRES(급성기).
  • 금기: 지방산 산화장애·카르니틴 수송 결함·피루브산 카복실화효소 결핍·포르피린증(케톤 생성·이용 불가) → 시작 전 아실카르니틴·소변 유기산 선별.
  • 작용 기전(다중):
    • 케톤체(βHB, 아세토아세트산) → 뇌 대체 연료·ATP 증가.
    • K_ATP 통로 개방(해당 감소 시 국소 ATP 감소) → 과흥분 억제.
    • 아데노신↑(ADK 감소) → A1 수용체.
    • 아세토아세트산이 VGLUT 억제(Cl⁻ 경쟁) → 글루탐산 방출↓.
    • GABA 합성↑(아스파르트산 → 글루탐산 → GABA 흐름 변화).
    • 다중불포화지방산(PPARα, 통로 조절), 데칸산(C10; AMPA 직접 억제 — MCT 식이), 미토콘드리아 생합성, 항염(βHB → NLRP3 억제), 장내 미생물(Akkermansia·Parabacteroides → 해마 GABA/글루탐산 비 상승, Olson et al., Cell 2018).
  • 부작용: 저혈당·산증(시작 시), 변비, 고지혈증, 신결석(산성 소변·저구연산뇨 → 구연산칼륨), 성장 지연, 골밀도 저하, 셀레늄·카르니틴 결핍, 토피라메이트·아세타졸라마이드 병용 시 산증 악화.

5항경련제의 대사 부작용

  • 발프로산:
    • 고암모니아혈증(정상 간기능에서도) — 발프로일-CoA의 NAGS/CPS1 억제, 카르니틴 고갈 → 무기력·뇌병증 → 카르니틴 보충; UCD 보인자 위험.
    • 간독성: 2세 미만·다약제·대사질환(POLG — 치명적), ω-산화 독성 대사물(4-en-VPA).
    • 체중 증가·인슐린 저항성, PCOS 유사, 혈소판 감소, 췌장염, 기형 유발(신경관 결손 1–2%, 자녀 IQ 저하·자폐 위험) → 가임 여성 처방 제한(PREVENT).
  • 효소 유도제(카르바마제핀, 페니토인, 페노바르비탈, 프리미돈): CYP3A4·UGT 유도 → 경구피임약·와파린·항암제 효과 감소, 비타민 D 대사 증가(골연화증), 엽산 감소, LDL↑.
  • 카르바마제핀·옥스카르바제핀: SIADH 유사 저나트륨혈증, HLA-B*15:02 SJS/TEN(B03 L10).
  • 토피라메이트·조니사마이드: 탄산탈수효소 억제 → 대사산증, 신결석, 저발한·고열(소아), 체중 감소.
  • 비가바트린: 망막 독성(GABA 축적 — 타우린 결핍 연관 가설) → 시야 감시.
  • 라모트리진: 임신 중 청소율 증가(B03 L10), 발프로산 병용 시 농도 2배(UGT 억제).
  • 페니토인: 0차 동역학(B03 L10), 잇몸 비대, 다모증, 소뇌 위축, 태아 히단토인 증후군.

연구 최전선

  • 정밀 뇌전증 치료: SCN1A 드라베 증후군의 ASO(조레베네르센 — 생산적 스플라이싱 증가 'TANGO', 3상), SCN2A·KCNQ2·STXBP1 표적 ASO와 유전자 치료(B06 L07).
  • 뇌 대사 영상(과분극 ¹³C, 중수소 대사 영상)으로 뇌전증 병소의 해당·산화 이상을 지도화하려는 연구가 진행 중이다.
  • 케톤 에스터·데칸산 단독 제제(K.Vita) 등 '식이 없는 케톤 치료'와 장내 미생물 기반 항경련 전략이 개발 중이다.

요약

  • 발작은 막대한 에너지를 소비하며 지속상태에서는 수용체 재배치로 벤조디아제핀 저항성이 생긴다.
  • 글루탐산–GABA–아데노신 균형과 Na⁺·Ca²⁺ 통로·SV2A·GABA 경로가 항경련제의 표적이다.
  • GLUT1 결핍, 피리독신·PLP 의존, 세린·크레아틴 결핍, 몰리브덴 보조인자 결핍 등은 원인 치료가 가능한 대사성 뇌전증이다.
  • 케톤생성식이는 GLUT1·PDH 결핍의 1차 치료이며 K_ATP·아데노신·VGLUT·미생물 등 다중 기전으로 작용하고 FAOD에는 금기이다.
  • 발프로산(고암모니아·간독성·기형), 효소 유도제(골·약물 상호작용), 토피라메이트(산증·결석) 등 대사 부작용을 감시한다.

자가 평가

  1. 아침 공복 시 악화되는 발작과 운동 후 발작성 이상운동을 보이는 아동의 CSF 포도당 32 mg/dL, 동시 혈당 90 mg/dL. 진단과 1차 치료는?

    해설 보기

    GLUT1 결핍 증후군(SLC2A1). CSF/혈당 비가 0.36으로 낮고(정상 >0.6), 혈액뇌장벽 포도당 수송 저하로 뇌 에너지가 부족해 공복·운동 시 증상이 악화된다. 케톤체는 MCT로 뇌에 들어가 대체 연료가 되므로 케톤생성식이가 1차 치료이며 조기 시작할수록 신경발달 결과가 좋다.

  2. 케톤생성식이 시작 전 혈장 아실카르니틴과 소변 유기산을 확인하는 이유는?

    해설 보기

    지방산 산화장애·카르니틴 수송 결함·피루브산 카복실화효소 결핍·포르피린증 환자는 고지방 식이에서 케톤을 만들거나 이용하지 못하고 독성 대사물이 쌓이거나 대사 위기(저혈당·횡문근융해·심근병증)가 생길 수 있어 금기이므로 사전 선별이 필요하다.

  3. 발프로산 복용 중 간기능이 정상인데 무기력과 혼동이 생긴 환자의 원인과 처치는?

    해설 보기

    발프로산 유발 고암모니아혈증 뇌병증. 발프로산 대사물이 요소회로 첫 단계(NAGS·CPS1)를 억제하고 카르니틴을 고갈시켜 미토콘드리아 기능을 떨어뜨린다. 혈중 암모니아를 측정하고 발프로산을 중단·감량하며 L-카르니틴을 투여한다. 요소회로 이상(특히 OTC 보인자) 가능성도 평가한다.

  4. 뇌전증지속상태가 길어질수록 벤조디아제핀이 잘 듣지 않는 분자적 이유는?

    해설 보기

    지속적 발작 활동으로 시냅스의 GABA_A 수용체(γ2 소단위 함유)가 세포내섭취되어 표면 수가 줄고, 동시에 NMDA·AMPA 수용체는 표면으로 이동해 흥분이 강화된다. 벤조디아제핀의 결합 부위인 시냅스 GABA_A 수용체가 줄어 효과가 감소하므로, 조기(5분 내) 충분한 용량 투여와 NMDA 길항(케타민) 등 다른 기전 약물의 조기 병용이 고려된다.
