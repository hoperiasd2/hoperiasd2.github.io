학습 목표

  1. 선천·적응 면역의 기본 요소를 신경계 맥락에서 정리한다.
  2. 미세아교세포·경계 대식세포·성상세포의 면역 기능과 상태 전환을 설명한다.
  3. 중추신경계로의 면역세포 유입 경로와 장벽을 설명한다.
  4. 사이토카인·보체·인터페론이 신경 기능에 미치는 영향을 설명한다.
  5. 신경면역 질환의 분류와 진단 접근(항체, CSF, 영상)을 개관한다.

1면역의 기본 요소 복습

  • 선천면역: 패턴 인식 수용체(TLR, NLR — 인플라마좀, cGAS–STING, RIG-I/MDA5)가 PAMP(병원체)와 DAMP(손상 — HMGB1, ATP, mtDNA, 요산)를 인식 → NF-κB·인터페론 반응 → 사이토카인·보체·탐식.
  • 적응면역: T세포(CD4 — MHC II, 도움/조절; CD8 — MHC I, 세포독성), B세포·형질세포(항체), 기억 세포.
  • CD4 T 아형: Th1(IFN-γ — 세포내 병원체·조직 손상), Th2(IL-4/5/13), Th17(IL-17/GM-CSF — 자가면역 탈수초의 핵심), Tfh(B세포 도움), Treg(FOXP3, IL-10/TGF-β — 자가 관용).
  • 관용: 중추(흉선 — AIRE에 의한 조직 특이 항원 제시; 결손 시 APS-1), 말초(Treg, 무반응, 억제).
  • 보체: 고전(C1q — 항체·아폽토시스 세포), 렉틴, 대체 경로 → C3 전환효소 → C3b(옵소닌)·C3a/C5a(아나필라톡신) → 막공격복합체 C5b-9(에쿨리주맙·라불리주맙의 표적 C5).

2중추신경계의 면역 세포

세포기원·위치면역 기능
미세아교세포난황낭, 실질감시, 탐식, 항원 제시(제한적), 사이토카인, 시냅스 가지치기 (B07 L04)
경계 연관 대식세포태생기 + 일부 순환 보충; 수막·혈관 주위·맥락얼기항원 포획·제시, 유입 통제
성상세포신경외배엽장벽 유지, 사이토카인·케모카인 생산, 흉터, A1/A2 이분법은 폐기 — 질환별 상태
올리고덴드로사이트·OPCMHC I 발현 가능, 면역 신호 반응
수막·맥락얼기 면역세포수막 틈새, 두개골 골수 통로상주 T·B세포, 수지상세포 — CSF 면역 감시
순환 유래단핵구, T·B세포, 호중구염증 시 유입
  • 두개골 골수-수막 직결 통로(2018–2021 발견): 두개골 판간층 골수에서 미세 혈관 통로를 통해 수막으로 골수세포가 직접 공급 → 혈액을 거치지 않는 국소 면역 공급원.

3면역세포의 중추신경계 유입

  • 세 경로:

1. 혈액–CSF(맥락얼기, 창문 모세혈관) → CSF → 지주막하 공간: 정상 면역 감시(CSF에 상주 기억 T세포 존재). 2. 연수막 혈관(지주막하) → 재활성화된 T세포가 실질 진입. 3. 실질 후모세혈관 정맥(혈액뇌장벽) → 염증 시.

  • 유입 단계: 포획(셀렉틴) → 구름 → 활성화(케모카인 — CCL19/21, CXCL12) → 굳은 부착(VLA-4–VCAM-1, LFA-1–ICAM-1) → 통과 → 혈관 주위 공간에서 항원 재인식 → 실질 진입.
    • 나탈리주맙(항-α4 인테그린, VLA-4 차단) = 다발성 경화증 치료; 면역 감시 저하 → 진행성 다초점 백질뇌병증(PML, JC 바이러스) 위험.
    • 핀골리모드 등 S1P 조절제: 림프절에서 림프구 유출 차단(B01 L08).
  • 중추신경계 배출: 수막 림프관(상시상정맥동·횡정맥동 따라) → 경부 심부 림프절 → 항원 제시(자가면역 개시 장소 후보) (B08 L02).

4사이토카인·보체와 신경 기능

  • IL-1β: 인플라마좀 산물 — 발열(시상하부 PGE₂), 통증 감작, 수면 조절, 해마 LTP 억제(고농도) → 질병 행동(sickness behavior).
  • TNF: 시냅스 스케일링(항상성 가소성), 과잉 시 흥분독성·탈수초; 항TNF는 류마티스에 쓰이지만 다발성 경화증은 악화(역설) → 중추·말초 면역의 차이.
  • IL-6: 급성기 반응, Th17 분화, 시신경척수염에서 형질아세포 생존 → 사트랄리주맙·토실리주맙.
  • IFN-I(α/β): 항바이러스, 과잉 시 인터페론병증(아이카르디-구티에레); 역설적으로 IFN-β가 다발성 경화증 치료제.
  • IFN-γ: MHC 상향, 미세아교세포 활성.
  • 보체: 발달기 시냅스 가지치기(C1q–C3–CR3), 질환에서 재활성(AD·조현병·녹내장), NMOSD·중증 근무력증의 조직 손상 매개 → C5 억제제.
  • '질병 행동'과 섬망: 전신 감염 → 사이토카인·미주 신경 → 중추 미세아교세포 활성 → 인지·행동 변화(특히 취약한 노인·치매).

5신경면역 질환의 분류와 진단

범주예
탈수초·중추다발성 경화증, NMOSD, MOGAD, ADEM (B08 L03, L08)
자가항체 매개 뇌·시냅스NMDAR·LGI1·CASPR2·GABA_B 뇌염 (B08 L10)
부신생물 증후군항-Hu, Yo, Ma2, CV2 (세포 내 항원 — T세포 매개, 치료 반응 나쁨)
신경근 접합부·말초중증 근무력증, 램버트-이튼, 길랭-바레·CIDP, MMN (B08 L09)
근육피부근염, 다발근염, 봉입체 근염, 면역매개 괴사성 근병증(항HMGCR·SRP)
혈관·전신중추신경계 혈관염, 신경사르코이드, 베체트, 루푸스, 쇼그렌, IgG4
감염 후·백신 후ADEM, 길랭-바레, 무도증(시덴함)
치료 관련면역관문억제제 신경독성, CAR-T 관련 ICANS, 면역재구성 염증증후군
  • 진단 도구: CSF(세포·단백·포도당, 올리고클론 밴드, IgG 지수, 세포학, PCR, 항체), 혈청·CSF 자가항체(세포 기반 분석이 표준), MRI(조영 증강 = 장벽 붕괴), 전기생리, 종양 선별(부신생물), 조직 생검.
  • 원칙: 항체는 혈청과 CSF를 함께(일부는 CSF에서만 양성 — NMDAR; 일부는 혈청이 더 민감 — MOG, AQP4), 세포 기반 분석 사용, 임상 표현형과 합치할 때만 해석(위양성 주의).

연구 최전선

  • 뇌 면역의 '구획' 개념이 정교해지며, 실질·수막·맥락얼기·두개골 골수가 각기 다른 면역 생태를 가진다는 것이 밝혀졌다.
  • 단일세포·공간 분석으로 질환별 미세아교세포·T세포 상태가 정의되어, 특정 상태만 표적하는 치료가 모색된다.
  • CSF 단일세포 분석이 다발성 경화증·자가면역 뇌염의 클론 확장 B·T세포를 포착해 진단·치료 반응 지표로 연구되고 있다.

요약

  • 선천면역의 PRR–DAMP 인식과 적응면역의 Th1/Th17/Treg 균형이 신경면역 질환의 기본 틀이다.
  • 미세아교세포(실질), 경계 대식세포(수막·혈관 주위), 성상세포가 중추 면역을 구성하며 두개골 골수가 국소 공급원이다.
  • 면역세포는 맥락얼기·연수막·실질 혈관의 세 경로로 들어오며 VLA-4·S1P가 치료 표적이다.
  • IL-1β·TNF·IL-6·인터페론·보체는 면역뿐 아니라 시냅스·행동·인지에도 직접 작용한다.
  • 진단은 혈청·CSF 자가항체(세포 기반 분석), 올리고클론 밴드, MRI, 전기생리와 임상 표현형의 합치로 이루어진다.

자가 평가

  1. 항TNF 치료가 류마티스 관절염에는 효과적이지만 다발성 경화증은 악화시킬 수 있는 사실이 시사하는 바는?

    해설 보기

    같은 사이토카인이라도 중추신경계와 말초에서 기능이 다르며, TNF는 중추에서 조절 T세포 유도·재수초화·항상성 가소성 등 보호적 역할도 한다는 것을 시사한다. 따라서 전신 면역 표적을 중추 질환에 그대로 적용할 수 없고, 구획별 면역 생물학을 고려해야 한다.

  2. 나탈리주맙 사용 환자에서 진행성 다초점 백질뇌병증 위험이 증가하는 기전은?

    해설 보기

    나탈리주맙은 α4 인테그린(VLA-4)을 차단해 림프구가 혈관 내피에 굳게 부착·통과하는 단계를 막는다. 그 결과 중추신경계 염증은 줄지만 동시에 면역 감시도 사라져, 잠복 JC 바이러스가 올리고덴드로사이트에서 재활성화되어도 제어되지 않는다. 항JCV 항체 역가, 치료 기간, 이전 면역억제제 사용이 위험을 층화한다.

  3. 자가면역 뇌염이 의심될 때 혈청만이 아니라 CSF에서도 항체를 검사해야 하는 이유는?

    해설 보기

    항체마다 민감도가 다르기 때문이다. 항NMDA 수용체 항체는 CSF에서 민감도와 특이도가 더 높아 혈청 음성인 경우에도 CSF 양성일 수 있고, 반대로 MOG·AQP4 항체는 혈청이 더 민감하다. 또한 혈청 단독 저역가 양성은 위양성일 수 있어 임상 표현형과 함께 해석해야 한다.

  4. 전신 감염을 앓는 치매 노인에게 섬망이 잘 생기는 신경면역학적 설명은?

    해설 보기

    전신 염증으로 생긴 IL-1β·TNF·IL-6가 체액성 경로(뇌실주위기관·내피), 신경 경로(미주 구심), 세포 경로(혈액뇌장벽 변화)를 통해 뇌에 전달되어 미세아교세포를 활성화한다. 이미 변성으로 '준비된(primed)' 미세아교세포는 과장된 반응을 보여 시냅스 기능과 신경전달을 급격히 교란하므로 섬망이 쉽게 유발된다.
