@sec 독성 기전의 분자 분류
| 기전 | 예 | 결과 |
|---|---|---|
| 효소 활성 부위 결합 | 유기인계(아세틸콜린에스터라아제), 시안화물(시토크롬 c 산화효소), 일산화탄소(헴) | 급성 기능 마비 |

| 반응성 대사물의 공유 결합 | 아세트아미노펜(NAPQI), 사염화탄소, 아플라톡신 B1(DNA 부가물) | 조직 괴사, 발암 |
| 산화 스트레스·지질 과산화 | 파라쿼트(산화환원 순환), 철 과용, 독소루비신 | 막·미토콘드리아 손상 |
| 단백 합성 차단 | 리신, 디프테리아 독소(EF-2 ADP-리보실화), 아마톡신(RNA 중합효소 II) | 세포 사멸, 지연성 간부전 |
| 세포골격·미세관 | 콜키신 과용, 빈카 알칼로이드 | 다장기 실패 |
| 치환·모방 | 메토트렉세이트(엽산), 와파린계 쥐약(비타민 K), 플루오로아세테이트(아코니타아제) | 경로 봉쇄 |
| 침전·결정 | 에틸렌글리콜(옥살산칼슘), 요산(종양용해) | 신손상 |
- 독성동태학: 흡수(위장관, 흡입, 피부), 분포(지질 용해도·단백 결합), 대사(활성화 vs 해독), 배출. **치명적 합성(lethal synthesis)** — 메탄올·에틸렌글리콜·플루오로아세테이트처럼 대사에 의해 독성이 생기는 경우 대사 차단이 치료가 된다.
- 접근의 틀: 기도·호흡·순환 안정화 → **독성 증후군(toxidrome)** 인식 → 제거(활성탄, 상황에 따른 위세척·전장 세척) → 해독제 → 증강 배출(알칼리뇨, 투석) → 지지 치료.

|---|---|---|
| 항콜린성 | 고열·건조·홍조·산동·요정체·착란 | 항히스타민, TCA, 아트로핀 |
| 콜린성 | DUMBBELS(침·눈물·설사), 서맥, 기관분비 과다, 근섬유다발수축 | 유기인계, 카바메이트 |
| 교감신경 흥분 | 고혈압·빈맥·발한·산동 | 코카인, 암페타민 |
| 오피오이드 | 호흡 억제·동공 축소·의식 저하 | 오피오이드 |
| 진정-수면 | 의식 저하, 활력 징후 비교적 보존 | 벤조디아제핀, 알코올 |
| 세로토닌 | 과반사·클로누스·하지 우세 경직·고열 | SSRI 조합, 리네졸리드 + 세로토닌성 약물 |

@sec 세포 호흡 차단 독성
- **시안화물**: 시토크롬 c 산화효소(복합체 IV)의 Fe³⁺에 결합 → 전자전달 정지 → 세포가 산소를 쓰지 못하는 **"세포 수준 질식"** → 젖산 산증 급증, 정맥혈 산소 포화도 상승(조직이 산소를 소모하지 못함), 동맥-정맥 산소차 감소.
  - 노출: 화재 연기(폴리우레탄·실크 연소), 공업(도금·제련), 니트로프루사이드 장기 고용량, 아미그달린.
  - 해독: **하이드록소코발라민**(시안을 직접 결합 → 시아노코발라민; 피부·요 적색 변화, 혈압 상승 — 화재 피해자에게 안전), 또는 아질산나트륨(메트헤모글로빈 생성 → 시안 포획) + **티오황산나트륨**(로다네아제의 황 공여체 → 티오시아네이트로 배출). 화재 연기 흡입에서는 CO 동반 가능성 때문에 아질산염 사용에 주의한다.
- **황화수소**: 같은 복합체 IV 억제 + 점막 자극. "썩은 달걀" 냄새지만 고농도에서 후각이 마비된다(즉시 의식 상실 — 분뇨·하수 밀폐 공간 사고). 치료는 즉시 대피·고농도 산소, 아질산나트륨 고려.
- **일산화탄소**: 헴 결합 + 좌측 이동(B10 L03) + 미토콘드리아 복합체 IV 억제 + 염증·지질 과산화 → 지연성 신경학적 후유증(기저핵·백질). 치료 고농도 산소, 고압산소는 의식 소실·임신·심한 산증 등에서 고려.
- **메트헤모글로빈 생성 물질**: 아질산염(우물물·가공육), 답손, 벤조카인, 니트로벤젠, 프릴로카인. 특징적 **초콜릿 갈색 혈액**, 산소 불응성 청색증 → 메틸렌블루(NADPH 메트헤모글로빈 환원효소 경로 이용; **G6PD 결핍에서는 용혈 위험 — 교환 수혈·고압산소 고려**).
- **파라쿼트**: 폐 상피세포가 폴리아민 수송체로 농축 → NADPH 소모형 산화환원 순환 → 폐섬유화로 지연 사망. 산소 투여가 오히려 해로울 수 있다(산소 의존적 ROS 생성).

@sec 중금속과 킬레이션
| 금속 | 분자 표적 | 임상 | 킬레이트 |
|---|---|---|---|
| **납** | ALA 탈수효소·ferrochelatase(헴 합성), 칼슘 모방(NMDA·PKC) | 소아 인지·행동, 빈혈(염기성 반점), 복통, 신장, 치은 납선 | 숙시머(경구), **CaNa₂EDTA + 디메르카프롤**(뇌증) |
| **수은** — 무기 | 신세관 설프하이드릴 | 급성 신부전, 위장관 부식 | 숙시머, DMPS |
| 수은 — 메틸(유기) | 중추신경·태아 뇌 | 미나마타병, 감각·보행·시야 장애; 태아 가장 취약 | 킬레이션 효과 제한 — 노출 차단 |
| **비소** | 피루브산 탈수소효소 리포산, ATP 유사체 치환 | 급성 — 위장관·QT 연장·쇼크; 만성 — 과각화·보웬병·말초신경병·피부·폐·방광암 | 디메르카프롤, 숙시머 |
| 카드뮴 | 신세관(β2-마이크로글로불린뇨), 골 | 이타이이타이병, 골연화 | 효과적 킬레이트 없음 |
| 구리 | 과잉 — 산화 손상 | **윌슨병**(B03 연계), 급성 용혈 | 페니실라민, 트리엔틴, 아연 |
| 철 | 자유 라디칼, 미토콘드리아 | 소아 과용 — 5단계 경과, 위장관 출혈 후 쇼크·간부전 | **데페록사민** |
| 탈륨 | K⁺ 모방, 리보플라빈·리포산 간섭 | 통증성 신경병 + **탈모** | 프러시안 블루 |
| 망간 | 기저핵 축적 | 파킨슨 유사(용접공, 간부전, 총정맥영양) | 노출 차단 |
- 킬레이션의 원칙: 혈중 농도 + 증상 + 노출 지속성을 함께 본다. 무증상 경도 상승에서는 **노출 제거가 치료**이며, 킬레이션 자체가 필수 금속(아연·구리) 소모와 신독성, 그리고 조직에서 뇌로의 재분포를 일으킬 수 있다. 소아 납 노출은 혈중 농도 기준에 따라 환경 조사·주거 개선이 핵심 개입이다.
- 납의 생화학적 지표: 적혈구 **아연 프로토포르피린**과 요 ALA 상승(헴 합성 차단의 직접 증거).

@sec 주요 해독제와 기전
| 독성 | 해독제 | 기전 |
|---|---|---|
| 아세트아미노펜 | **N-아세틸시스테인** | 글루타티온 전구체, NAPQI 결합 |
| 오피오이드 | 날록손 | μ 수용체 경쟁 길항(반감기 짧음 — 재투여·주입) |
| 벤조디아제핀 | 플루마제닐 | GABA-A 경쟁 길항(만성 복용·TCA 동반 시 발작 위험으로 제한적) |
| 유기인계 | **아트로핀**(무스카린 차단, 기관 분비 조절이 목표) + **프랄리독심**(에스터라아제 재활성화 — 노화 전에) | 아세틸콜린 축적 해소 |
| 베타차단제 | 글루카곤, 고용량 인슐린-포도당 | cAMP 우회, 심근 대사 지원 |
| 칼슘통로차단제 | 칼슘, 고용량 인슐린-포도당, 바소프레신 | 수축력·대사 지원 |
| 디곡신 | **디곡신 특이 Fab** | 항체 결합 제거(총 디곡신 측정 무의미해짐) |
| 삼환계 항우울제 | **중탄산나트륨** | Na⁺ 통로 차단 역전(QRS >100 ms, 알칼리화 + Na 부하) |
| 메탄올·에틸렌글리콜 | **포메피졸** + 투석 | 알코올 탈수소효소 억제 |
| 살리실산 | 중탄산(요 알칼리화 pH 7.5–8) + 투석 | 이온 포획으로 뇌 유입 감소·배출 증가 |
| 국소마취제 전신 독성 | **지질 유탁액** | 지질 침강 효과 |
| 메트헤모글로빈 | 메틸렌블루 | 환원효소 보조 전자 운반 |
| 와파린·슈퍼와파린 | 비타민 K₁(장기 고용량) + PCC | 카르복실화 회복 |
| 항응고제 역전 | 이다루시주맙·안덱사네트 | B10 L04 |
| 보툴리눔·뱀독·전갈독 | 항독소·항사독 | 독소 중화 |
- **살리실산 중독**의 특징적 생화학: 호흡 중추 직접 자극(호흡 알칼리증) + 산화적 인산화 짝풀림·대사 산증 → **혼합 장애**. 산증이 심해지면 비이온형이 늘어 중추 침투가 증가하므로 **절대 산증을 방치하지 않는다**. 저혈당 없이도 중추 포도당 결핍이 생길 수 있어 포도당을 공급한다. 삽관과 과도한 저환기는 급격한 악화를 부른다.
- **알코올 금단·영양**: 모든 중독·알코올 환자에게 **티아민을 포도당 전후로** 투여(베르니케 예방, B05 연계).
- **아마톡신(독우산광대버섯)**: RNA 중합효소 II 억제 → 6–24시간 잠복 후 위장관 증상 → 일시적 호전 → 2–4일에 간부전. 실리비닌·N-아세틸시스테인·페니실린 G가 사용되나 근거는 제한적이며 간이식 평가가 핵심이다.

@sec 환경·직업 독성과 생체 지표
- 노출 평가의 세 축: 환경 농도(작업환경 측정), **생체 노출 지표**(혈중·요중 물질 또는 대사물), **생물학적 효과 지표**(콜린에스터라아제 활성, 아연 프로토포르피린, DNA 부가물, 염색체 이상).
| 노출 | 지표 | 주의 |
|---|---|---|
| 납 | 혈중 납, 적혈구 ZPP | 골 반감기 수십 년 — 임신 시 재동원 |
| 유기인계 | 적혈구 아세틸콜린에스터라아제(혈장 가성보다 신뢰) | 기저치 비교가 중요 |
| 벤젠 | 요중 S-페닐머캅투르산, *trans,trans*-뮤콘산 | **백혈병** 위험 |
| 트리클로로에틸렌·염화비닐 | 요 대사물 | 간 혈관내피종(염화비닐) |
| 석면 | 영상·조직 석면체 | 중피종(잠복 20–40년), 흡연과 상승 작용 |
| 실리카 | 영상 | 규폐증, 결핵·자가면역 위험 |
| 다환방향족탄화수소 | 요중 1-하이드록시피렌 | CYP1A1 유도, 발암 |
| 내분비 교란물질(비스페놀 A, 프탈레이트, PFAS) | 요·혈중 농도 | 저용량·혼합 노출·발달기 민감성 |
- 발암 기전의 분류: **유전독성**(DNA 부가물·돌연변이 — 아플라톡신 B1의 *TP53* R249S, 벤조피렌의 흡연 서명, 아리스톨로크산의 요로상피암) vs **비유전독성**(수용체 매개·증식 촉진·만성 염증 — 다이옥신의 AhR, 과산화물체 증식제). IARC 분류는 증거의 강도이지 위험도의 크기가 아니다.
- 용량-반응의 예외들: 발달기 창(태아 알코올, 메틸수은), 비단조 반응(일부 내분비 교란물질), 유전적 감수성(NAT2 느린 아세틸화와 방광암, GSTM1 결손), 혼합 노출과 상승 작용(석면 + 흡연).
> 임상 상관: 원인 불명의 말초신경병, 인지 저하, 빈혈, 피부 변화, 신기능 이상에서 **직업·취미·거주 환경·보조식품 병력**을 구조적으로 묻는 것이 진단의 열쇠가 될 수 있다. "어떤 일을 하십니까, 언제부터, 무엇에 노출됩니까, 같은 작업장에 비슷한 증상을 가진 사람이 있습니까"라는 네 질문이 집단 노출을 찾아내고, 한 환자의 진단이 작업장 전체의 예방으로 이어진다.

@quiz
Q: 화재 현장에서 구조된 환자가 심한 젖산 산증을 보이고 중심정맥 산소포화도가 매우 높다. 무엇을 의심하고 어떻게 치료하는가?
A: 시안화물 중독이다. 시토크롬 c 산화효소가 차단되어 조직이 산소를 추출하지 못하므로 정맥혈 산소포화도가 높고 혐기성 대사로 젖산이 급증한다. 하이드록소코발라민을 즉시 투여하고 고농도 산소를 공급한다. 일산화탄소가 동반될 가능성이 높아 메트헤모글로빈을 만드는 아질산염은 산소 운반을 더 악화시킬 수 있으므로 피하고, 티오황산나트륨은 병용할 수 있다.
Q: 유기인계 중독에서 프랄리독심을 조기에 투여해야 하는 이유는?
A: 유기인계는 아세틸콜린에스터라아제를 인산화해 억제하는데, 시간이 지나면 알킬기가 떨어지며 결합이 비가역적으로 안정화된다(노화). 프랄리독심은 노화되지 않은 효소에서 인산기를 떼어 활성을 복원하므로 노화가 진행되기 전에 투여해야 효과가 있다. 아트로핀은 무스카린 증상을 조절하지만 근섬유다발수축과 호흡근 약화 같은 니코틴 증상은 막지 못하므로 두 약을 함께 쓴다.
Q: 살리실산 중독 환자에게 삽관과 과환기 억제를 피해야 하는 이유는?
A: 환자의 자발적 과환기는 대사 산증에 대한 필수적 보상이다. 진정·마비로 환기가 줄면 pH가 급격히 떨어지고, 산성 환경에서 비이온형 살리실산이 늘어 중추신경계로 더 많이 들어가 발작과 사망 위험이 커진다. 중탄산으로 혈액과 요를 알칼리화해 이온 포획을 유도하고, 중증에서는 조기에 혈액투석을 고려한다.
Q: 혈중 납 농도가 경도로 상승한 무증상 소아에게 킬레이션이 1차 치료가 아닌 이유는?
A: 킬레이션은 혈중 농도를 일시적으로 낮추지만 골에 축적된 납이 재동원되어 다시 오르며, 필수 금속 소모와 신독성 위험이 있다. 무작위 시험에서 경도 상승 소아의 인지 결과를 개선하지 못했다. 따라서 노출원 조사와 제거, 주거 환경 개선, 영양(철·칼슘) 보충, 발달 추적이 핵심 개입이고 킬레이션은 높은 농도나 증상이 있을 때로 제한된다.

@sec 우울·불안: 모노아민을 넘어서
- 고전적 모노아민 가설의 한계: SSRI는 수시간 내 시냅스 세로토닌을 올리지만 효과는 2–6주 뒤 나타난다 → **적응적 변화**(5-HT1A 자가수용체 둔감화, BDNF-TrkB 상향, 해마 신경생성, 시냅스 리모델링)가 실제 치료 기전에 가깝다.
- **가소성 가설**: 스트레스·코르티솔이 해마 BDNF와 수상돌기 분지를 줄이고 편도는 오히려 강화 → 항우울 치료가 BDNF-TrkB-mTORC1 경로를 통해 시냅스를 회복시킨다. **케타민**이 수시간 내 효과를 내는 것이 이 모형의 가장 강력한 근거다(NMDA 차단 → 탈억제·AMPA 활성 → mTORC1 → 시냅스 단백 합성; 대사물 하이드록시노르케타민의 역할도 제안됨).
- **염증·대사 가설**: 일부 우울증 환자에서 CRP·IL-6 상승, **키누레닌 경로** 전환(트립토판이 세로토닌 대신 키누레닌으로 — IDO 활성화; 퀴놀린산은 NMDA 작용성 신경독성, 키누렌산은 길항성) → 항염 치료가 고염증 아형에서 효과 가능성.
- HPA 축: CRH-ACTH-코르티솔의 음성 피드백 둔화, 글루코코르티코이드 수용체 저항. 조기 역경이 후성유전학적 각인(*NR3C1* 메틸화)을 남긴다.

- 긴급 상황: **신경이완제 악성 증후군**(고열·납관 경직·CK 상승·자율신경 불안정 — 원인 약 중단, 냉각, 단트롤렌·브로모크립틴)과 세로토닌 증후군(클로누스·과반사 — 사이프로헵타딘)의 구분이 중요하다.

@sec 양극성장애와 중독
- **리튬**: 기전은 다중 — 이노시톨 모노포스파타아제 억제(이노시톨 고갈), **GSK-3β 억제**(WNT·세포 보호), 신경보호·BDNF, 자가포식 조절. 자살 감소 효과가 입증된 소수의 약물. 치료 범위가 좁아 **농도 감시**가 필수이며, 신장(요농축 장애·요붕증·만성 신질환), 갑상선·부갑상선, 체중, 임신 중 심장 기형(에브스타인) 고려. **NSAID·티아지드·ACEi·탈수**가 농도를 올린다.
- 발프로산(HDAC 억제, GABA ↑ — 가임기 여성에서 신경관 결손·인지 영향으로 회피), 라모트리진(우울 삽화 예방, 발진·SJS — 서서히 증량), 카르바마제핀(자가 유도·상호작용), 2세대 항정신병약물(쿠에티아핀, 루라시돈, 카리프라진).
- **중독의 신경생물학**: 급성 보상(VTA → 중격측좌핵 도파민) → 반복 노출로 **보상 역치 상승**(쾌감 감소)과 유인 민감화 → 습관 회로(배측 선조체)로 이동 → 금단·부정 감정 상태(CRH, 노르에피네프린, 다이놀핀) → 전전두 조절 기능 저하. 즉 "의지의 문제"가 아니라 회로 질환이다.

@sec 정신약물의 대사와 감시
- CYP 연관(B10 L09): 2D6(아리피프라졸, 리스페리돈, 아토목세틴, 벤라팍신), 1A2(**클로자핀·올란자핀 — 흡연이 유도하므로 금연 시 농도 급등**), 3A4(쿠에티아핀, 일부), 2C19(시탈로프람 — QT 때문에 용량 상한).
- 감시 항목: 대사(체중·허리·혈당·지질 — 2세대 시작 시 기저치와 추적), QTc(지프라시돈·시탈로프람·메타돈·할로페리돈 정주), 프로락틴(리스페리돈·아미설프리드), 리튬·발프로산·카르바마제핀 농도, 클로자핀 절대호중구수, 추체외로 증상 평가(AIMS).
- 중요한 상호작용·위험: 세로토닌성 약물 + MAOI·리네졸리드·메틸렌블루(세로토닌 증후군), SSRI + NSAID·항응고제(출혈), SSRI와 저나트륨(SIADH, 특히 노인), 항정신병약물과 치매 환자 사망 위험 증가(행동 증상에 1차 약물이 아니다), 임신 중 위험-이득 평가(치료되지 않은 질환의 위험도 함께 고려).
> 임상 상관: 조현병 환자의 평균 수명 단축은 주로 **심혈관 대사 질환**에 의한 것이다. 2세대 항정신병약물의 체중·지질·혈당 영향, 흡연율, 신체 질환 진료 접근성 저하가 겹친다. 따라서 정신과적 안정만이 치료 목표가 아니라, 기저 대사 지표 측정과 추적, 메트포르민 병용 고려, 금연 지원, 1차 의료 연계가 정신과 치료의 일부여야 한다 — 생화학과 정신의학이 임상에서 만나는 지점이다.

@quiz
Q: SSRI가 시냅스 세로토닌을 즉시 올리는데도 임상 효과가 2–6주 뒤 나타나는 이유는?
A: 초기에는 라페핵의 5-HT1A 자가수용체가 활성화되어 세로토닌 뉴런의 발화를 줄이므로 투사 영역의 전달 증가가 제한된다. 수주에 걸쳐 자가수용체가 둔감화되면서 전달이 실제로 늘고, 동시에 BDNF-TrkB와 mTORC1 경로를 통한 시냅스 리모델링과 해마 신경생성이 일어난다. 임상 반응은 이 적응적 가소성 변화의 시간 척도를 따른다.
Q: 항정신병약물이 D2를 차단할 때 네 가지 도파민 경로에서 각각 어떤 결과가 생기는가?
A: 중뇌변연 경로 차단은 양성 증상을 개선하는 치료 효과를 낸다. 중뇌피질 경로 차단은 음성·인지 증상을 악화시킬 수 있다. 흑색질-선조체 차단은 급성 추체외로 증상과 장기적으로 지연성 운동이상을 일으킨다. 결절누두 차단은 프로락틴 억제를 풀어 유즙분비, 성기능 장애, 골밀도 감소를 유발한다.
Q: 클로자핀을 복용하던 환자가 금연했다. 무엇을 예상하고 어떻게 대응하는가?
A: 담배 연기의 다환방향족탄화수소가 CYP1A2를 유도하므로 금연하면 유도가 사라져 클로자핀 농도가 크게 상승한다. 진정, 기립성 저혈압, 발작, 침흘림, 변비 악화가 나타날 수 있다. 금연 시점에 용량을 줄이고 혈중 농도와 임상 증상을 추적하며, 니코틴 대체 요법 자체는 CYP1A2에 영향을 주지 않는다는 점을 함께 고려한다.
Q: 치료 저항성 조현병에서 클로자핀을 쓰기 위해 감수해야 하는 감시 항목과 그 이유는?
A: 무과립세포증 위험 때문에 절대호중구수를 정해진 일정으로 반복 측정해야 한다. 그 외 초기 수주의 심근염(흉통·발열·빈맥·트로포닌·CRP), 발작 위험(용량 의존), 심한 변비와 마비성 장폐색, 기립성 저혈압, 체중·혈당·지질 변화를 감시한다. 이런 부담에도 클로자핀을 쓰는 이유는 치료 저항성에서 유일하게 우월한 효과와 자살 위험 감소가 입증되었기 때문이다.

@sec 스트레스 대사 반응
- 고전적 두 단계(Cuthbertson): **쇠퇴기(ebb, 0–24시간)** — 관류 저하, 대사율 감소; **만조기(flow, 수일)** — 이화 우세, 대사율·체온·산소 소비 증가, 이후 **회복기(anabolic)**.
- 호르몬 환경: 카테콜아민·코르티솔·글루카곤 ↑, 인슐린 작용 저하(저항), 성장호르몬 ↑ 그러나 IGF-1 ↓(GH 저항), T3 저하(저T3 증후군 — 적응적 반응이므로 일상적 보충은 하지 않는다).
| 변화 | 기전 | 결과 |
|---|---|---|
| 스트레스 고혈당 | 당신생 ↑(코르티솔·글루카곤), 말초 흡수 ↓(TNF·IL-6가 IRS-1 세린 인산화) | 감염·산화 손상 위험, 그러나 과도한 교정도 해롭다 |
| 단백 이화 | 유비퀴틴-프로테아좀(아트로진-1, MuRF1), 자가포식 | 근육 소실(일 1% 이상 가능), 급성기 단백 합성 위한 아미노산 공급 |
| 지방 분해 ↑ | 카테콜아민·코르티솔 | 유리지방산 ↑, 케톤은 인슐린 때문에 상대적으로 억제 |
| 급성기 반응 | IL-6 → CRP·피브리노겐·헵시딘·페리틴 ↑, 알부민·트랜스페린 ↓ | **알부민은 영양 지표가 아니라 염증 지표** |
| 미토콘드리아 기능 저하 | NO·ROS, 생합성 저하 | "세포 저산소증", 장기 기능 저하 |
!> 중환자의 이화는 "영양 부족" 때문이 아니라 **염증-호르몬 환경의 결과**다. 그래서 초기에 열량·단백을 과다 공급해도 근육 소실을 막지 못하며, 오히려 자가포식 억제와 과영양 합병증을 만든다.

@sec 패혈증과 장기 기능장애
- 정의(Sepsis-3): 감염에 대한 **조절되지 않는 숙주 반응으로 생긴 생명을 위협하는 장기 기능장애**(SOFA 2점 이상 증가), 쇼크는 수액에 불응하는 저혈압 + 젖산 >2 mmol/L로 승압제 필요.
- 분자 캐스케이드: PAMP·DAMP(HMGB1, 미토콘드리아 DNA, 히스톤) → TLR·인플라마좀 → 사이토카인 폭풍과 동시에 **면역 마비**(T세포 아폽토시스, HLA-DR 감소, 과도한 PD-1) → 내피 손상(글리코칼릭스 탈락, 안지오포이에틴-2 ↑, 혈관 투과성 ↑) → 미세순환 이질성, 응고 활성과 항응고 결핍(DIC) → **미토콘드리아 기능 저하**.
| 장기 | 기전 |
|---|---|
| 순환 | 혈관 확장(NO·프로스타사이클린·ATP 민감 K⁺ 통로 개방), 카테콜아민 감수성 저하, 패혈증 심근 기능 저하(가역적) |
| 신장 | 염증·미세순환·세관 대사 적응(세포주기 정지) — 단순 저관류 모형만으로 설명되지 않는다 |
| 폐 | ARDS(B10 L06) |
| 간 | 담즙정체, 당신생 변화, 약물 대사 변동 |
| 장 | 장벽 기능 저하, 미생물군 붕괴(병원체 우세) |
| 뇌 | 패혈증 관련 뇌병증 — 염증·내피·신경전달 이상, 섬망 |
- 치료의 축: **조기 적절한 항생제와 감염원 제거**, 균형 결정질 수액(과다 수액은 해롭다), 승압제(노르에피네프린 1차, 바소프레신 추가, 필요 시 스테로이드), 폐 보호 환기, 신대체요법은 적응증 기반, 수혈 역치 7 g/dL. 대부분의 특정 분자 표적 치료(항-TNF, 항-내독소, 활성 단백 C)는 실패했다 — **이질적 환자군의 문제**로 이해되고 있으며 아형(표현형) 기반 설계로 옮겨가고 있다.
- 젖산 해석의 정교화: 저관류 외에도 β2 자극에 의한 해당과정 증가, 간 청소 저하, 티아민 결핍, 메트포르민이 기여한다. 젖산 자체보다 **추세와 임상 소견의 결합**이 중요하다.

@sec 중환자 영양 지원
- 경로: 가능하면 **장관 영양**(장벽·면역 유지) 24–48시간 내 시작. 금기는 쇼크 미안정, 장폐색·허혈. 정맥 영양은 장관이 불가능하거나 불충분할 때 — 초기 1주에 공격적 정맥영양을 추가하는 것은 **이득이 없거나 해로웠다**(EPaNIC).
- 열량·단백: 급성기에는 측정 또는 추정 에너지의 **일부만**(약 70% 이하, 경우에 따라 더 적게) 공급하고 점진적으로 늘린다. 단백은 1.2–2.0 g/kg/일을 목표로 하나 초기 고용량의 이득은 최근 시험(EFFORT Protein)에서 확인되지 않았다 — **단백을 많이 주면 근육이 보존된다는 단순한 가정은 성립하지 않는다.**
- **재급식 증후군**: 장기 금식·영양실조 상태에서 탄수화물을 공급하면 인슐린 급증으로 인·칼륨·마그네슘·티아민이 세포 내로 이동 → **저인산혈증**(ATP·2,3-BPG 생산 불가), 부정맥, 호흡근 약화, 심부전, 베르니케. 위험군(BMI 낮음, 10% 이상 체중 감소, 알코올, 10일 이상 섭취 부족, 신경성 식욕부진, 재수술)에서는 **티아민 선투여 + 저열량으로 시작 + 전해질 교정과 감시**가 필수다.
- 과영양의 해: 고혈당, 간 지방증과 담즙정체, 고CO₂(호흡 부담), 고트리글리세라이드(프로포폴의 지질 부하 포함), 자가포식 억제.
- 특수 상황: 간부전(단백 제한은 권장되지 않음 — 분지쇄 아미노산 고려), 신대체요법(아미노산·수용성 비타민 손실 보충), 비만(저열량·고단백), 복부 개방(단백 손실), ECMO·지속 투석 중 약물·영양소 손실.
- 장관 영양 모니터링: 위 잔류량 단독 기준의 유용성은 제한적이며, 흡인 예방(상체 상승), 운동성 약물, 유문 후 급식을 상황에 맞춰 사용한다.

@sec 혈당·전해질·미량영양소
- **혈당**: NICE-SUGAR 시험에서 목표 81–108 mg/dL의 엄격한 조절은 180 이하 목표에 비해 사망률이 더 높았고 중증 저혈당이 많았다 → 일반적 목표 **140–180 mg/dL**, 변동성과 저혈압 중 저혈당을 피하는 것이 핵심. 당뇨 환자는 개별화(만성 고혈당 적응).
- 전해질: 인(호흡근·ATP), 마그네슘(부정맥·불응성 저칼륨), 칼슘(패혈증에서 흔한 이온화 저칼슘 — 일상적 교정의 이득은 불확실), 나트륨(교정 속도 — B10 L05), 칼륨.
- 미량영양소·비타민: **티아민**(젖산 산증·베르니케 — 투여 임계값을 낮게 둔다), 비타민 D(결핍 흔함, 대량 보충의 사망률 이득은 입증되지 않음), 아연·셀레늄(장기 손실·창상), 비타민 C(패혈증에서 대규모 시험 결과 일관되지 않으며 LOVIT에서는 해로운 경향), 엽산·B12(장기 영양 지원).
- 산염기: 중환자에서 여러 장애가 겹치므로 음이온차·델타비 접근(B10 L05)과 함께 수액 조성(생리식염수 대량 → 고염소성 산증)을 고려한다.
| 흔한 함정 | 올바른 해석 |
|---|---|
| 알부민 낮음 = 영양실조 | 염증과 분포 변화의 결과 — 영양 지표로 쓰지 않는다 |
| 저T3 = 갑상선 치료 필요 | 적응 반응 — 일상적 호르몬 보충은 권장되지 않는다 |
| 크레아티닌 정상 = 신기능 정상 | 근육 소실로 생성이 줄어 과대평가 — 요량·추세·시스타틴 C 고려 |
| CK 정상 = 근육 손상 없음 | 중환자 근병증은 CK 정상일 수 있다 |
| 젖산 상승 = 저관류 | 다인성 — 추세와 임상 평가 결합 |

@sec 중환자 후 증후군과 회복
- **중환자실 획득 약화(ICU-AW)**: 중환자 다발신경병증 + 근병증. 기전은 염증, 부동, 미세순환·막 흥분성 변화, 단백 분해 활성, 고혈당·스테로이드·근이완제의 기여. 결과는 인공호흡기 이탈 지연과 장기 기능 저하 → **조기 재활과 진정 최소화**가 핵심 예방.
- **섬망**: 염증·혈액뇌장벽 투과·콜린성 결핍·수면 붕괴·약물. 예방은 다요소 비약물 묶음(지남력, 수면, 조기 거동, 감각 보조기구, 통증 조절, 벤조디아제핀 회피). 항정신병약물의 예방·치료 효과는 입증되지 않았으며 일상적 사용은 권장되지 않는다. **ABCDEF 묶음**이 표준 틀이다.
- **중환자 후 증후군(PICS)**: 신체(근력·체력), 인지(기억·집행기능 — 장기 추적에서 경도 인지장애 수준), 정신(불안·우울·PTSD)의 지속 장애. 가족에게도 나타난다(PICS-F). 추적 클리닉, 중환자 일기, 단계적 재활, 영양·수면 회복, 약물 재검토(퇴원 시 불필요한 약 정리)가 개입 지점.
- 회복기 대사: 동화 상태로 전환되며 단백·열량 요구가 실제로 높아지는 시기이므로, **급성기보다 회복기에 영양 지원이 더 중요**할 수 있다. 근력 운동과 단백 공급의 결합, 빈혈·비타민 결핍 교정, 재입원 예방이 목표다.
> 임상 상관: 중환자 진료에서 "더 많이, 더 빨리, 더 엄격하게"가 반복적으로 틀렸다는 것이 지난 20년의 교훈이다. 엄격한 혈당 조절, 조기 공격적 정맥영양, 대량 수액, 조기 신대체요법, 고용량 비타민 요법은 모두 생리학적으로 매력적이었으나 무작위 시험에서 이득이 없거나 해로웠다. 생화학적 추론은 가설을 세우는 데 필수적이지만, 그 가설은 임상시험으로 검증되어야 한다 — 이 묶음 전체를 관통하는 원칙이다.

@frontier
- 패혈증의 생물학적 아형(전사체·단백체 기반)에 따른 맞춤 면역조절 치료가 전향적으로 시험되고 있다.
- 미토콘드리아 기능 회복과 세포 대사 복원을 겨냥한 치료가 장기 기능장애의 근본 개입으로 탐색되고 있다.
- 중환자 후 증후군의 기전 연구와 구조화된 회복 프로그램이 생존 이후의 결과를 중심 지표로 끌어올리고 있다.

@summary
- 중증 질환의 이화는 염증-호르몬 환경의 결과이므로 초기 과다 영양 공급으로 되돌릴 수 없다.
- 패혈증은 과염증과 면역 마비, 내피·미토콘드리아 손상이 동시에 일어나는 조절 실패 상태다.
- 재급식 증후군은 인슐린에 의한 인·칼륨·마그네슘·티아민의 세포 내 이동이며 티아민 선투여로 예방한다.
- 혈당 목표는 140–180 mg/dL이고 엄격한 조절은 저혈당으로 오히려 해롭다.
- 알부민·저T3·크레아티닌은 중환자에서 통상적 의미와 다르게 해석해야 한다.

@quiz
Q: 중환자에서 혈청 알부민이 낮은 것을 영양 상태의 지표로 쓸 수 없는 이유는?
A: 염증 시 IL-6가 간의 단백 합성 우선순위를 CRP·피브리노겐 같은 급성기 단백으로 바꾸어 알부민 합성을 줄이고, 동시에 혈관 투과성 증가로 알부민이 간질로 이동하며 수액 희석도 더해진다. 즉 알부민 저하는 염증과 분포 변화의 결과이지 단백 섭취 부족의 지표가 아니다. 영양 평가는 체중 추세, 근육량, 섭취량, 기능 평가로 한다.
Q: 3주간 거의 먹지 못한 알코올 사용 환자에게 영양을 시작할 때 무엇을 먼저 하고 왜인가?
A: 탄수화물 투여 전에 티아민을 투여하고 인·칼륨·마그네슘을 측정·교정한 뒤 저열량으로 천천히 시작한다. 당 공급으로 인슐린이 급증하면 인·칼륨·마그네슘이 세포 내로 이동해 심한 저인산혈증과 부정맥, 호흡근 약화를 일으키고, 티아민이 고갈된 상태에서 포도당 대사가 늘면 베르니케 뇌증이 촉발된다. 첫 수일간 전해질을 매일 추적한다.
Q: NICE-SUGAR 시험 결과가 중환자 혈당 관리를 어떻게 바꾸었는가?
A: 목표 81–108 mg/dL의 엄격한 조절군이 180 이하 목표군보다 90일 사망률이 높고 중증 저혈당이 훨씬 많았다. 고혈당이 해롭다는 생화학적 추론이 타당해도, 뇌가 포도당에 절대적으로 의존하는 상황에서 저혈당의 위험이 더 크다는 것이다. 이후 표준은 140–180 mg/dL 목표와 혈당 변동 최소화가 되었다.
Q: 중환자실 획득 약화를 예방하기 위한 가장 근거 있는 개입은 무엇이며 그 이유는?
A: 진정 최소화와 조기 거동·재활이다. 부동과 깊은 진정은 유비퀴틴-프로테아좀 경로를 통한 근단백 분해를 가속하고 신경근 흥분성 변화를 악화시킨다. 반대로 매일 진정 중단과 조기 운동은 인공호흡기 사용 기간과 섬망을 줄이고 퇴원 시 기능을 개선한다. 고혈당 회피와 불필요한 근이완제·스테로이드 제한도 함께 작용한다.
