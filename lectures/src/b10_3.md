### L07

@obj
- 골격근의 수축·에너지 대사와 근육 질환의 생화학적 분류를 설명한다.

@sec 골격근의 에너지 대사와 운동 생화학
- 수축: 활동전위 → T관 **DHPR(CACNA1S)** → **RYR1** Ca²⁺ 방출 → 트로포닌 C 결합 → 트로포미오신 이동 → 액틴-미오신 교차교 순환(ATP 가수분해) → **SERCA**가 Ca²⁺ 재흡수(ATP 소모 — 이완도 에너지를 쓴다).
| 에너지 체계 | 시간 범위 | 핵심 반응 |
|---|---|---|
| 포스포크레아틴 | 0–10초 | 크레아틴 키나아제: PCr + ADP → Cr + ATP |
| 무산소 해당 | 10초–2분 | 글리코겐 → 젖산, 근육에는 G6P 가수분해효소가 없어 포도당을 혈중으로 내보내지 못한다 |
| 산화적 인산화 | 2분 이후 | 지방산·포도당·케톤, 지속 운동에서 지방산 비중 ↑ |
- **근육은 글루코스-6-인산분해효소가 없다** → 글리코겐은 근육 자체 소비용. 젖산은 간으로 가서 당신생(코리 회로), 알라닌은 질소 운반(알라닌 회로).
- 운동 적응: AMPK(에너지 센서) + PGC-1α → 미토콘드리아 생합성; 저항 운동은 mTORC1 → 근단백 합성. 마이오카인(이리신, IL-6, 마이오스타틴 억제)이 전신 대사에 작용(B04 연계).
| 운동 유발 증상의 감별 | 결함 | 특징 |
|---|---|---|
| **맥아들병(근 글리코겐 포스포릴라아제, PYGM)** | 해당과정 | 초기 운동 통증, **세컨드 윈드** 현상, 운동 시 젖산 상승 없음 |
| 인산과당분해효소 결핍(타루이) | 해당과정 | 용혈 동반, 당분 섭취가 오히려 악화 |
| **CPT2 결핍** | 긴사슬 지방산 산화 | 장시간 운동·금식·추위 후 근육분해, 근긴장성 아니라 지연성 |
| VLCAD, TFP 결핍 | 지방산 산화 | 신생아형은 심근병·저혈당 |
| 미토콘드리아 근병(MELAS 등) | 호흡사슬 | 운동 불내성, 젖산 ↑, 누더기 적색 섬유 |
| 악성 고열증(RYR1·CACNA1S) | Ca²⁺ 방출 과다 | 휘발성 마취제·숙시닐콜린 → 대사 폭주, **단트롤렌** |
- **횡문근분해증**: CK 수천~수만, 미오글로빈뇨(요 딥스틱 혈액 양성·적혈구 없음), 고칼륨·고인·저칼슘·대사 산증 → 급성 신손상. 원인은 외상·압박, 과도한 운동, 발작, 열사병, 약물(스타틴 — 특히 상호작용, 고용량; 코카인), 유전성 대사 근병, 감염. 치료는 **적극적 수액**이 핵심.

@sec 근육막 복합체와 근육병
- **디스트로핀-당단백 복합체(DGC)**: 디스트로핀이 액틴 세포골격과 β-디스트로글리칸-α-디스트로글리칸-라미닌(기저막)을 잇는다. 사르코글리칸, 디스트로브레빈, 신트로핀, **nNOS**가 함께 결합 — 수축력 전달과 막 보호.
| 질환 | 유전자·단백 | 특징 |
|---|---|---|
| **뒤센 근육병** | *DMD* 틀이동 → 디스트로핀 부재 | 3–5세 발병, 가워스 징후·종아리 가성비대, CK 매우 높음, 심근병, 스테로이드로 진행 지연; **엑손 스킵**(에테플리르센 등), 유전자 치료 |
| 베커 근육병 | *DMD* 틀 유지 → 단축 단백 | 경증·후기 발병, 심근병이 주 문제일 수 있다 |
| 지대근육병 | 사르코글리칸, 디스펄린, 칼파인-3, 당화 효소(FKRP) | 상염색체, 아형별 심·호흡 침범 차이 |
| **근긴장성 근육병 1형** | *DMPK* 3′UTR **CTG 반복** → 독성 RNA가 MBNL 격리 → 광범위 잘못된 스플라이싱 | 근긴장증, 전두 탈모, 백내장, 전도 장애(돌연사), 인슐린 저항, 다장기 |
| 2형 | *CNBP* CCTG 반복 | 근위 우세, 경증 |
| 안면견갑상완 근육병 | 4q35 D4Z4 수축 → **DUX4** 탈억제 | 비대칭 안면·견갑 약화 |
| 폼페병 | 산성 α-글루코시다아제(리소좀 글리코겐) | 영아형 심근병, 성인형 근육·호흡 약화 — **효소 대체** |
| 염증성 근육병 | 면역 매개(B10 L02) | 피부근염(I형 IFN), 면역매개 괴사성(HMGCR·SRP 항체 — 스타틴 연관) |
- 중증근육경직·신경근접합부 질환은 B08에서 다룬다. 여기서는 **근육 자체**의 구조·대사 결함에 초점을 둔다.

@sec 골 재형성의 분자 조절
!> 골은 대사 기관이다. 칼슘·인 저장고이면서 FGF23·오스테오칼신을 분비해 인 대사와 전신 에너지 대사에 참여한다.
- 핵심 축: 골세포(osteocyte)가 기계적 부하를 감지 → **스클레로스틴(SOST)** 분비 조절 → WNT-β-카테닌(LRP5/6)을 통한 골형성 조절. 부하가 있으면 스클레로스틴 ↓ → 골형성 ↑.
- 골흡수: 골형성세포 계열이 **RANKL**을 발현 → 전구세포의 RANK → NF-κB·NFATc1 → 골파괴세포 성숙·활성(H⁺-ATPase + 염소 통로로 산성화, **카텝신 K**가 콜라겐 분해, TRAP). **OPG**가 RANKL을 중화하는 내재 브레이크.
| 질환 | 기전 | 치료 |
|---|---|---|
| **골다공증** | 에스트로겐 감소 → RANKL ↑, 노화·스테로이드·부동 | 비스포스포네이트(파네실 경로 억제 → 골파괴세포 아폽토시스), **데노수맙**(항-RANKL), **로모소주맙**(항-스클레로스틴 — 형성 ↑ 흡수 ↓), PTH 유사체(테리파라타이드·아발로파라타이드 — 간헐 투여가 형성 우위) |
| 구루병·골연화 | 비타민 D 결핍, 저인(**X-연관 저인성 — FGF23 과다**) | 비타민 D·인, **부로수맙**(항-FGF23) |
| 골석화증 | 골파괴세포 산성화·분화 결함(CLCN7, TCIRG1, RANKL) | 이식(일부) |
| 파제트병 | 국소 골 재형성 과다(SQSTM1) | 졸레드론산 |
| 골형성이상증(OI) | **I형 콜라겐**(COL1A1/2) 또는 가공 효소 | 비스포스포네이트, 항-스클레로스틴 연구 |
| 저인산효소증 | 조직 비특이 알칼리 인산분해효소(TNSALP) → 피로인산 축적 | **아스포타아제 알파** |
| 가성·진성 부갑상선 질환 | PTH-GNAS 신호 | B04 연계 |
- 치료 중단의 생화학: **데노수맙 중단 시 반동적 골흡수 폭발**로 다발성 척추 골절 위험 — 중단할 때 비스포스포네이트로 전환해야 한다. 비스포스포네이트는 골에 결합해 효과가 지속되므로 약물 휴지기가 가능하다. 턱뼈 골괴사·비전형 대퇴골 골절은 장기 사용 시 드물게 발생.

@sec 콜라겐·엘라스틴과 유전성 결합조직질환
- 콜라겐 생합성: 전구 사슬 → 소포체에서 **프롤린·라이신 수산화**(비타민 C 의존 — 결핍 시 괴혈병: 잇몸 출혈, 모세혈관 취약, 창상 치유 지연) → 당화 → 삼중 나선 → 분비 → 프로펩타이드 절단 → 섬유 조립 → **라이실 산화효소(구리 의존)**의 교차결합.
| 질환 | 결함 | 특징 |
|---|---|---|
| **마르팡 증후군** | *FBN1* 피브릴린-1 → TGF-β 격리 실패 | 대동맥근 확장·박리, 수정체 상방 전위, 긴 사지; **β차단제·ARB**, 대동맥 직경 기준 수술 |
| **혈관형 엘러스-단로스** | *COL3A1* | 동맥·장·자궁 파열 — 가장 치명적; 셀리프롤롤 |
| 고전형 EDS | *COL5A1/2* | 피부 과신전, 위축성 흉터 |
| 로이스-디츠 | *TGFBR1/2*, *SMAD3*, *TGFB2* | 더 공격적 대동맥 질환, 구개열·내반족 |
| **골형성이상증** | *COL1A1/2* | 골 취약, 청색 공막, 난청 |
| 알포트 증후군 | *COL4A3/4/5* | 사구체 기저막 — 혈뇨·신부전·난청 |
| 윌리엄스 증후군 | *ELN* 결실 포함 7q11.23 | 대동맥판상부 협착, 특징적 인지·사회성 |
| 가성탄력섬유종 | *ABCC6* | 미네랄화 이상 — 피부·망막(각막선)·혈관 |
| 괴혈병 | 비타민 C | 수산화 실패 → 불안정 콜라겐 |
| 멘케스병 | *ATP7A* 구리 수송 | 라이실 산화효소 실패 → 혈관·모발(꼬인 모발) |
- 마르팡의 개념 전환: 단순한 구조 결함이 아니라 **피브릴린-1이 잠재 TGF-β를 붙잡아 두는 기능**의 상실로 TGF-β 신호가 과다해진다는 모형이 ARB 치료의 근거가 되었다.

@sec 결정 유발 관절염과 골관절염
- **통풍**: 요산은 퓨린 분해의 최종 산물(사람은 요산분해효소가 없다). 과포화 → 요산일나트륨 결정 → **NLRP3 인플라마좀** → IL-1β → 급성 관절염.
  - 생산 증가: 세포 전환 증가(혈액암, 종양용해), 과당·알코올(ATP 소모 → AMP → 요산), *PRPS1* 과활성, HGPRT 결핍(레쉬-니한).
  - 배출 감소(대부분): 신기능, **URAT1(SLC22A12)·GLUT9(SLC2A9)·ABCG2** 변이, 이뇨제·저용량 아스피린·사이클로스포린, 젖산·케톤 경쟁.
  - 치료: 급성 — NSAID·콜키신(미세관 중합 억제 → 호중구 이동·인플라마좀 억제)·스테로이드, 불응 시 IL-1 차단. 요산 저하 — **알로푸리놀/페북소스타트**(잔틴 산화효소), 배출 촉진(프로베네시드, 레시누라드), 페글로티카제(재조합 요산분해효소). 목표 요산 <6 mg/dL(결정 용해 임계).
  - 중요 원칙: 요산 저하 치료 **시작 시 급성 발작이 늘어나므로 예방약(콜키신 저용량)을 동반**하고, 발작 중이라도 이미 복용 중이면 중단하지 않는다. 알로푸리놀은 HLA-B*58:01에서 중증 과민반응 위험(아시아인 선별).
- **칼슘 피로인산 침착(CPPD)**: 연골에서 ATP → 피로인산(ENPP1) 과다, ANKH 수송, 알칼리 인산분해효소 부족 → 이수화물 결정. 이차 원인: 혈색소증, 부갑상선기능과다, 저마그네슘, 저인산효소증, 길버트형 가족성. 양굴절성 약한 막대·마름모 결정.
- **골관절염**은 "마모"가 아니라 대사·염증 질환: 연골세포가 MMP-13·ADAMTS-5를 분비해 II형 콜라겐·아그리칸을 분해하고, 활막 염증(IL-1, IL-6), 골하 골 재형성, 통증 감작(NGF)이 동반된다. 비만은 기계적 부하와 전신 염증(렙틴·아디포카인) 양쪽으로 작용한다. 현재 치료는 증상 중심(운동·체중·NSAID)이며 **타네주맙(항-NGF)** 등은 관절 안전성 문제로 제한되었다.
> 임상 상관: 발열과 단일 관절 종창에서 결정 관절염과 **화농성 관절염**은 임상만으로 구분할 수 없다. 관절 천자로 세포수·배양·결정 검사를 모두 보내야 하며, 결정이 보여도 감염이 동반될 수 있다. 또 급성 발작 중의 혈청 요산은 정상이거나 낮을 수 있어 통풍을 배제하는 근거가 되지 않는다 — 진단은 결정 확인이다.

@frontier
- 항-스클레로스틴 항체와 골형성 우위 약물의 순차 치료 전략이 골다공증 치료의 순서를 바꾸고 있다.
- 디스트로핀 미니유전자 전달과 염기 편집이 뒤센 근육병의 근본 치료로 임상 단계에 들어섰으며 용량 의존 간·면역 독성이 과제다.
- 골관절염에서 구조 변화를 늦추는 질병 조절 약물(WNT 조절, ADAMTS-5 억제, 연골세포 노화 표적)이 탐색되고 있다.

@summary
- 근육은 글루코스-6-인산분해효소가 없어 글리코겐을 자체 소비하며 운동 단계별로 에너지 체계가 전환된다.
- 해당과정 결함은 단시간 고강도 운동에서, 지방산 산화 결함은 지속 운동·금식 후에 증상을 일으킨다.
- 골 항상성은 RANKL-RANK-OPG와 WNT-스클레로스틴 두 축으로 조절되며 각각이 약물 표적이다.
- 데노수맙 중단 시 반동 골흡수로 골절 위험이 커지므로 비스포스포네이트 전환이 필요하다.
- 통풍은 요산 결정이 NLRP3를 활성화하는 자가염증이며 배출 감소가 대부분의 원인이다.

@quiz
Q: 맥아들병의 세컨드 윈드 현상을 생화학적으로 설명하라.
A: 근 글리코겐 포스포릴라아제 결핍으로 운동 초기에는 근육 글리코겐을 쓸 수 없어 ATP가 부족하고 통증·경직이 생긴다. 몇 분 뒤 심박과 혈류가 늘고 간 당신생과 지방 분해로 공급되는 혈중 포도당과 지방산이 산화 대사로 들어오면 운동 수행이 다시 개선된다. 그래서 환자는 가벼운 준비 운동으로 증상을 줄일 수 있고, 운동 중 젖산은 오르지 않고 암모니아는 오른다.
Q: 스타틴 복용 환자의 근육 증상에서 면역매개 괴사성 근육병을 의심할 단서는?
A: 스타틴을 중단해도 CK가 떨어지지 않고 근력 약화가 진행하면 단순 근육통이 아니다. 항-HMGCR 자가항체 검사와 근 MRI·생검을 고려하며, 생검에서 염증 침윤은 적고 괴사·재생 섬유와 보체 침착이 보인다. 치료는 스타틴 중단만으로 부족하고 스테로이드·IVIG·메토트렉세이트 등 면역치료가 필요하다.
Q: 데노수맙을 2년 투여한 환자가 자의로 중단하려 한다. 무엇을 설명해야 하는가?
A: 데노수맙은 RANKL을 중화해 골파괴세포를 억제하지만 골에 잔류하지 않아 효과가 가역적이다. 중단하면 억제되어 있던 골파괴세포 전구세포가 한꺼번에 활성화되어 반동적 골흡수가 일어나고, 수개월 내 다발성 척추 골절이 보고된다. 치료를 끝낼 때는 비스포스포네이트로 전환해 골에 남는 억제 효과를 확보해야 한다.
Q: 통풍으로 알로푸리놀을 시작하자 발작이 더 생겼다. 약을 끊어야 하는가?
A: 끊지 않는다. 요산이 낮아지면 조직에 침착된 결정이 녹아 나오면서 일시적으로 발작이 증가하는 것은 예상되는 반응이다. 시작 시 저용량 콜키신이나 NSAID로 수개월간 예방하고, 요산을 6 mg/dL 미만으로 유지하며 용량을 점진적으로 올린다. 이미 복용 중이라면 급성 발작 중에도 중단하지 않고 발작 치료를 병행한다.

@sec 피부 장벽의 생화학
- 각질층은 "벽돌과 모르타르": 벽돌 = 각질세포(케라틴 + **필라그린**으로 응집), 모르타르 = 세포간 지질층(**세라마이드 ~50%**, 콜레스테롤, 유리지방산). 층판체가 이 지질과 가공 효소를 분비한다.
- 천연보습인자: 필라그린 분해 산물(유로칸산, 피롤리돈 카복실산) — **필라그린 결손이 건조·pH 상승·알레르겐 투과를 동시에 일으킨다**.
- 각질층 pH는 약산성(~5)이어서 세린 단백분해효소를 억제하고 항균 환경을 만든다. 비누·반복 세정이 pH를 올리면 단백분해효소가 활성화되어 코르네오데스모좀을 과도히 분해한다.
| 질환 | 결함 | 특징 |
|---|---|---|
| **아토피피부염** | *FLG* 결손 + 2형 염증(IL-4/13 → 장벽 단백·세라마이드 ↓) | 장벽-염증 악순환; 보습 + 항염 + 두필루맙 |
| 보통 비늘증 | *FLG* | 미세한 비늘, 아토피 동반 |
| X-연관 비늘증 | 스테로이드 설파타아제(*STS*) | 콜레스테롤 설페이트 축적 → 각질 응집, 각막 혼탁, 산모 분만 지연 |
| 할리퀸·판상 비늘증 | *ABCA12*(지질 수송), *TGM1*(트랜스글루타미나아제-1) | 중증 신생아 장벽 실패 |
| 네덜톤 증후군 | *SPINK5*(LEKTI — 단백분해효소 억제자) | 단백분해효소 과활성 → 박리, 중증 알레르기 |
| **건선** | IL-23/IL-17, 과증식, HLA-C*06:02 | IL-17·IL-23 차단제가 극적 효과 |
| 수장족저 각화증·다윈형 | 케라틴 유전자 | 특정 케라틴 쌍의 발현 부위와 표현형 일치 |
- 접착 구조와 질환: **데스모좀**(데스모글레인 1/3) → 수포성 질환 중 **파열창 수포증**과 자가면역 **펨피구스**(항-데스모글레인 — 표피 내 수포, 니콜스키 징후); **헤미데스모좀·기저막**(BP180/BP230, 라미닌-332, VII형 콜라겐) → **수포성 펨피고이드**(긴장성 수포, 고령, DPP-4 억제제 연관), **상피박리증**(유전성 — 단순형 케라틴5/14, 접합형 라미닌-332, 이형성형 **COL7A1**). 이형성형에는 유전자 치료 젤(베레미노진)과 세포 치료가 도입되었다.
- 포도알균 열상 피부 증후군은 외독소가 **데스모글레인-1을 절단**해 펨피구스 폴리아세우스와 같은 층에서 박리를 만든다 — 분자 표적이 같다.

@sec 멜라닌 대사와 광생물학
- 멜라닌 합성: 타이로신 → (**타이로시나아제**, 구리 의존) 도파 → 도파퀴논 → 유멜라닌(갈흑색) 또는 시스테인 결합 → 페오멜라닌(적황색). 멜라노좀이 케라틴세포로 전달된다.
- **MC1R**: α-MSH 자극 → cAMP → MITF → 유멜라닌 우위. MC1R 기능 저하 변이(적발·주상 피부)는 페오멜라닌 우위로 광보호가 약하고 **흑색종 위험**이 높다.
| 질환 | 결함 |
|---|---|
| 백색증 1형 | 타이로시나아제(*TYR*) |
| 백색증 2형 | *OCA2*(멜라노좀 pH) |
| 헤르만스키-푸들락 / 체디아크-히가시 | 소기관 생합성(HPS 유전자) / *LYST* — 출혈·면역 결함 동반 |
| 백반증 | 멜라노사이트 자가면역(CD8, IFN-γ-CXCL10) — **JAK 억제제**(룩솔리티닙 크림) |
| 기미·염증 후 색소침착 | 멜라닌 생성·전달 증가 |
- 자외선 생화학: UVB(280–315 nm)는 DNA에 직접 흡수되어 **사이클로부테인 피리미딘 이량체**를 만든다(NER로 복구; *XP* 유전자 결함 → 색소성 건피증, 피부암 다발·신경 퇴행). UVA는 ROS를 통해 간접 손상과 광노화(MMP-1로 콜라겐 분해). 비타민 D 합성은 UVB가 7-디하이드로콜레스테롤을 전환.
- 광민감성의 생화학: 포르피린증(B10 L03), 약물 광독성(독시사이클린, 보리코나졸, 하이드로클로로티아지드 — 피부암 위험), 펠라그라(나이아신 결핍 — 햇빛 노출 부위 피부염·설사·치매).

@sec 망막의 대사와 망막 질환
- 광전달: 11-*cis*-레티날 + 옵신 = 로돕신 → 광자 → 올-*trans*-레티날 → 트랜스듀신 → PDE6 → cGMP ↓ → CNG 통로 닫힘 → **과분극**(어두울 때 탈분극, 빛에서 과분극이라는 역설적 신호).
- **시각 회로(visual cycle)**: 올-*trans*-레티놀 → RPE에서 LRAT로 에스터화 → **RPE65**가 이성체화 → 11-*cis*-레티날 재공급. *RPE65* 양쪽 변이 실명에는 **보레티진 네파보벡**(AAV 유전자 치료)이 승인되었다.
- 망막은 체내 최고 수준의 산소·에너지 소비 조직이며 광수용체는 호기성 해당과정에 크게 의존한다 → 미토콘드리아·대사 취약성이 질환으로 이어진다.
| 질환 | 기전 | 치료 |
|---|---|---|
| **당뇨망막병증** | 고혈당 → 폴리올(알도스 환원효소), AGE, PKC, 헥소사민, ROS → 모세혈관 소실·VEGF ↑ | 혈당·혈압 관리, 항-VEGF, 레이저 |
| **연령관련 거대변성** | 드루젠(지질·보체), **보체 조절 이상(CFH Y402H, C3)**, 산화 손상, 리포푸신 | 항-VEGF(신생혈관형), 지리적 위축에 **보체 억제제**(페그세타코플란·아바시캅타드), AREDS2 보충 |
| 망막색소변성 | 100개 이상 유전자(로돕신, PDE6, USH2A 등) | 유전자·세포 치료 연구, 인공망막 |
| 스타르가르트병 | *ABCA4* → 비스레티노이드(A2E) 축적 | 비타민 A 유도체 회피, 치료 연구 중 |
| 레베르 유전성 시신경병증 | mtDNA 복합체 I(11778G>A 등) | 이데베논, 유전자 치료 연구 |
| 미숙아망막병증 | 산소 노출 후 상대적 저산소 → VEGF 급등 | 산소 목표 관리, 항-VEGF·레이저 |
| 망막혈관폐색·고혈압망막병증 | 혈역학·내피 | 전신 위험 관리 |
- 비타민 A 결핍은 야맹증 → 각막건조·각막연화로 진행하는 세계적 실명 원인이며, 지방 흡수 장애·담도 질환에서도 발생한다.

@sec 각막·수정체·안내압
- 각막 투명성은 규칙적 콜라겐 배열 + **내피의 Na⁺/K⁺-ATPase 펌프**로 유지되는 상대적 탈수에 의존한다. 내피 세포가 감소하면(푹스 내피각막병증, 수술 손상) 부종·시력 저하 → 내피 이식.
- 수정체: 세포 교체 없이 **크리스탈린**(α-크리스탈린은 샤페론)이 평생 유지. 백내장의 생화학 — 산화(글루타티온 고갈), 당화·소르비톨(당뇨), 자외선, 스테로이드, 칼슘 유입·단백 응집. 갈락토키나아제 결핍은 소아 백내장.
- 안내압: 섬유주와 쉴렘관을 통한 유출 저항이 주 결정 요인. 녹내장 약물 — 프로스타글란딘 유사체(공막포도막 유출 ↑), β차단제·탄산탈수효소 억제제·α2 작용제(생성 ↓), **Rho 키나아제 억제제·라타노프로스텐 부노드(NO 공여)**(섬유주 유출 ↑). 녹내장은 결국 **망막 신경절세포의 축삭 손상**이며 안압은 조절 가능한 위험인자다.
- 전신 약물과 눈: 하이드록시클로로퀸 망막독성(용량·체중 기준 선별), 에탐부톨 시신경병증, 아미오다론 각막 침착, 토피라메이트 급성 근시·폐쇄각, 비스포스포네이트 공막염.

@sec 내이와 난청·평형
- 와우: 기저막 진동 → 외유모세포의 **프레스틴(SLC26A5)**이 전압 의존 길이 변화로 신호를 증폭 → 내유모세포 섬모의 기계전기 변환 통로(**TMC1**, PCDH15·CDH23 팁링크) → K⁺ 유입. 와우 내림프의 높은 K⁺와 +80 mV 내림프 전위는 **GJB2(코넥신 26)** 등 K⁺ 재순환 경로가 유지한다.
| 난청 | 유전자·기전 |
|---|---|
| 비증후군성 상염색체 열성 | **GJB2**(가장 흔함), *SLC26A4*(펜드레드 — 전정수관 확장·갑상선) |
| 증후군성 | 어셔(*MYO7A*, *USH2A* — 난청 + 망막색소변성), 알포트, 와르덴부르크, 제르벨-랑에-닐센(KCNQ1 — QT 연장) |
| 미토콘드리아 | **m.1555A>G** — **아미노글리코사이드 극도 민감** |
| 노인성·소음성 | 유모세포·시냅스 소실, 산화 스트레스, 재생 불가 |
| 이독성 | 아미노글리코사이드(외유모세포 ROS), 시스플라틴, 루프 이뇨제(혈관조) |
- 재생이 되지 않는 포유류 유모세포의 한계가 인공와우의 근거이며, Atoh1·Notch 억제를 통한 유모세포 재생과 *OTOF* 유전자 치료(선천성 청각신경병)가 임상에 진입했다.
- 평형: 반고리관(각가속도) + 이석기관(선형·중력). **양성 체위성 현훈**은 이석 조각이 반고리관에 들어간 기계적 문제 → 이석 치환술이 치료. **메니에르병**은 내림프 수종(압력·이온 항상성 이상), **전정편두통**과의 중첩이 흔하다.
> 임상 상관: 아미노글리코사이드를 투여할 때 가족 중 "항생제 주사 후 청력을 잃은" 사람이 있는지 물어야 한다. 미토콘드리아 m.1555A>G 보유자는 통상 용량·정상 혈중 농도에서도 비가역적 난청이 생길 수 있다. 모계 유전이므로 한 명의 병력이 가족 전체의 투약 금기를 의미한다. 같은 맥락에서 하이드록시클로로퀸·에탐부톨 사용 시 안과 선별 일정을 처방 시점에 함께 계획해야 한다.

@frontier
- 보체 표적 치료가 지리적 위축의 진행을 늦추는 첫 치료로 도입되면서 AMD의 보체 가설이 치료로 입증되었다.
- 망막·내이의 유전자 치료가 조직 접근성과 면역 격리라는 이점으로 유전자 의학의 선두 영역이 되었다.
- 피부에 국소 도포하는 유전자 치료 젤이 이형성형 상피박리증에서 승인되어 국소 유전자 전달의 선례를 만들었다.

@summary
- 피부 장벽은 세라마이드 지질층과 필라그린 유래 보습인자, 약산성 pH로 유지되며 필라그린 결손이 아토피의 축이다.
- 멜라닌 아형은 MC1R-cAMP-MITF 신호가 결정하고 UVB는 피리미딘 이량체를 직접 만든다.
- 시각 회로의 RPE65와 보체 조절 이상은 각각 유전자 치료와 보체 억제제의 표적이 되었다.
- 각막 투명성은 내피 펌프에 의한 탈수에, 수정체 투명성은 크리스탈린 유지에 의존한다.
- 코넥신 26 변이가 가장 흔한 유전성 난청이고 m.1555A>G는 아미노글리코사이드 금기를 의미한다.

@quiz
Q: 아토피피부염에서 보습제가 단순한 대증 치료가 아닌 이유는?
A: 필라그린 결손과 IL-4/IL-13에 의한 세라마이드·장벽 단백 감소로 각질층 지질 구조와 천연보습인자가 부족해지고 pH가 올라가 세린 단백분해효소가 활성화된다. 그 결과 알레르겐·미생물 투과가 늘어 2형 염증이 더 심해진다. 세라마이드·콜레스테롤·지방산을 보충하는 보습은 이 악순환의 상류를 교정하며, 신생아기 조기 보습이 발병 자체를 줄일 가능성도 연구되었다.
Q: 포도알균 열상 피부 증후군과 펨피구스 폴리아세우스가 같은 피부 층에서 박리를 일으키는 이유는?
A: 두 질환 모두 데스모글레인-1의 기능을 잃게 한다. 포도알균의 박리독소는 데스모글레인-1을 단백분해로 절단하고, 펨피구스 폴리아세우스는 같은 분자에 대한 자가항체가 접착을 방해한다. 데스모글레인-1은 표피 상층에 주로 분포하므로 두 질환 모두 과립층 수준의 표면 박리를 보인다.
Q: 미숙아망막병증에서 산소 투여 전략이 중요한 이유를 VEGF 생물학으로 설명하라.
A: 미숙아의 망막 혈관은 미완성 상태이며, 고농도 산소에 노출되면 HIF와 VEGF가 억제되어 혈관 성장이 멈추고 일부는 소실된다. 이후 산소 농도가 낮아지면 혈관 없는 망막이 상대적 저산소에 빠져 VEGF가 급격히 과잉 생산되고, 비정상 신생혈관과 섬유 증식, 망막 박리로 이어진다. 그래서 산소 포화도를 과하지도 부족하지도 않게 목표 범위로 유지하는 것이 예방의 핵심이다.
Q: 가족 중 아미노글리코사이드 주사 후 청력을 잃은 사람이 있다는 병력이 왜 중요한가?
A: 미토콘드리아 12S rRNA의 m.1555A>G 같은 변이는 아미노글리코사이드에 대한 극도의 감수성을 만들어, 정상 용량과 정상 혈중 농도에서도 비가역적 양측 감각신경성 난청을 일으킨다. 모계 유전이므로 한 사람의 병력이 모계 친족 전체의 위험을 뜻한다. 가능하면 다른 계열 항생제를 선택하고, 불가피하면 유전자 검사와 청력 감시를 계획한다.

### L09

en: Drug Metabolism, Pharmacogenomics and Adverse Drug Reactions

@obj
- 1상·2상 약물대사와 수송체의 역할을 설명한다.
- 주요 CYP 효소의 기질·억제·유도와 임상 상호작용을 설명한다.
- 약물유전체학 지표를 임상 의사결정과 연결한다.
- 약물 유해반응을 기전별로 분류하고 특이반응의 면역 기전을 설명한다.
- 간·신장 기능과 특수 인구에서의 투여 조정 원리를 설명한다.

@sec 1상·2상 대사와 수송체
- **1상**(기능화): 주로 CYP450(산화), 그 외 플라빈 함유 모노옥시게나아제, 알코올·알데하이드 탈수소효소, 에스터라아제, 잔틴 산화효소. 결과물이 더 반응성인 경우가 많아 **독성 대사물**이 여기서 생긴다.
- **2상**(결합): UGT(글루쿠론산), SULT(황산), GST(글루타티온), NAT(아세틸), TPMT·COMT·TMPT(메틸), 아미노산 결합 → 수용성 증가, 배출 용이.
- **3상**(수송): 유출 — P-당단백(**ABCB1**), BCRP(ABCG2), MRP; 유입 — **OATP1B1(SLCO1B1)**, OCT, OAT. 수송체가 조직 노출을 결정하므로 상호작용의 큰 부분을 차지한다.
| 수송체 | 임상 의미 |
|---|---|
| P-당단백 | 디곡신·DOAC 농도 변화(베라파밀·아미오다론·리팜핀), 혈액뇌장벽 배출 |
| **OATP1B1** | 스타틴 간 유입 — *SLCO1B1* 기능 저하 변이에서 심바스타틴 근육병 위험 ↑ |
| BCRP | 로수바스타틴, 메토트렉세이트 |
| OCT2·MATE | 메트포르민 신배출 — 시메티딘·돌루테그라비르 상호작용 |
| 담즙산 수송체(BSEP) | 약물 유발 담즙정체 |
- 초회 통과 효과와 생체이용률: 장 CYP3A4 + P-당단백 + 간 대사. 자몽주스가 장 CYP3A4를 비가역 억제해 일부 약물(펠로디핀, 일부 스타틴, 타크로리무스)의 농도를 크게 올린다.

| 유형 | 기전 | 예 |
|---|---|---|

- **면역 매개 피부 반응의 기전**: 약물 또는 대사물이 HLA 분자의 결합 홈에 끼어들어 자기 펩타이드 제시를 바꾸거나(아바카비르-HLA-B*57:01의 "변경된 자기 레퍼토리") 직접 TCR과 상호작용 → 약물 특이 CD8 T세포 활성 → 그랜자임·그래뉼리신 매개 표피 괴사(TEN). 치료는 즉시 중단, 화상 수준 지지 요법, 사이클로스포린·TNF 억제제·IVIG(근거는 제한적).
- **DRESS**: 2–8주 지연, 발열·발진·호산구·장기 침범(간·신·심), HHV-6 재활성화 동반. 중단 후에도 악화할 수 있어 장기 스테로이드 감량이 필요하고 갑상선 기능을 추적한다.
- **약물 유발 간손상(DILI)**: 내재형(용량 의존) — **아세트아미노펜**; 특이형 — 아목시실린-클라불란산, 이소니아지드, 보조식품(아나볼릭 스테로이드, 녹차 추출물). R 비(ALT/ULN ÷ ALP/ULN)로 간세포형·담즙정체형 구분, **하이의 법칙**(ALT 상승 + 빌리루빈 상승 + 다른 원인 배제)은 중증 위험 신호.
  - 아세트아미노펜의 생화학: 대부분 글루쿠론산·황산 결합, 소량이 **CYP2E1**로 **NAPQI** 생성 → 글루타티온이 중화. 과용·만성 알코올(CYP2E1 유도)·금식·영양실조(글루타티온 고갈)에서 NAPQI가 간세포 단백을 공유 결합 → 중심엽 괴사. 치료는 **N-아세틸시스테인**(글루타티온 전구체 + NAPQI 직접 결합) — 조기 투여가 결정적이며 럼액-매튜 노모그램으로 판단한다.
- 기타 중요 기전: QT 연장(hERG 통로 차단 — 전해질·서맥·CYP 억제가 가중), 세로토닌 증후군(과반사·근경직·고열·동공 확대), 신경이완제 악성 증후군(D2 차단 — 경직·서반사), 약물 유발 루푸스(하이드랄라진·프로카인아마이드 — 느린 아세틸화자), 횡문근분해(스타틴 조합).
> 임상 상관: 다약제 복용 노인에서 새로 생긴 혼돈, 낙상, 저나트륨, 신기능 악화는 "새 질병"보다 먼저 **약물**을 의심해야 한다. 처방 연쇄(한 약의 부작용을 다른 약으로 치료)를 끊는 것이 치료일 수 있고, 항콜린 부담 합산과 Beers·STOPP 기준 검토가 구체적 도구다. 반대로 어떤 약을 뺄 때는 중단 반응(E형)을 예상해 단계적으로 줄인다.

@sec 장기 기능과 특수 인구
- **신기능**: 수용성·신배출 약물(아미노글리코사이드, 반코마이신, DOAC, 메트포르민, 가바펜틴, 디곡신, 리튬) 용량 조정. eGFR 추정식의 한계(근육량, 급성 변화) — 급성 신손상에서는 추정이 과대평가될 수 있다. 투석 제거 여부(분자량·단백 결합·분포용적)를 고려해 투석 후 보충.
- **간기능**: 1상 대사가 2상보다 먼저 영향을 받고, 알부민 감소로 유리 분율이 증가하며(페니토인·와파린), 문맥 단락으로 초회 통과가 줄어 생체이용률이 커진다. 차일드-퓨 등급에 따라 감량하고, 간부전에서 진정제·NSAID·아세트아미노펜 고용량을 피한다.
- **임신·수유**: 분포용적·신혈류 증가(라모트리진·리튬 용량 증가 필요), 태반 통과, 기형유발 시기(기관 형성기). 금기 예: ACEi/ARB(2·3분기 신독성), 발프로산(신경관 결손·인지), 이소트레티노인, 와파린(1분기), 테트라사이클린. 수유 중에는 M/P 비와 영아 상대 용량으로 판단한다.
- **소아·노인**: 신생아는 UGT·CYP 미성숙(클로람페니콜 회색 증후군, 빌리루빈 경쟁), 소아는 체중 기준이지만 일부 효소 활성이 성인보다 높다. 노인은 체지방·수분 변화, 신기능 저하, 약력학적 민감도 증가(벤조디아제핀, 항콜린제).
- 치료적 약물 농도 감시(TDM)가 필요한 약: 반코마이신(AUC 기반), 아미노글리코사이드, 디곡신, 리튬, 페니토인(알부민 보정), 테오필린, 면역억제제, 일부 항암제·항생제.

@summary
- 1상 대사는 반응성 중간체를 만들고 2상 결합이 이를 해독하므로 균형이 깨질 때 독성이 발생한다.
- CYP3A4와 2D6, 그리고 OATP1B1·P-당단백 수송체가 임상 상호작용의 대부분을 설명한다.
- HLA 대립유전자 선별과 TPMT·NUDT15·DPYD 검사는 투여 전 필수적인 안전 조치다.
- 아세트아미노펜 독성은 CYP2E1 유래 NAPQI와 글루타티온 고갈의 문제이며 조기 N-아세틸시스테인이 해답이다.
- 다약제 노인의 새 증상은 질병보다 약물과 처방 연쇄를 먼저 의심해야 한다.

@quiz
Q: CYP2D6 초고속 대사자에게 코데인이 위험한 이유는?
A: 코데인 자체는 진통 효과가 약한 전구약물로 CYP2D6가 모르핀으로 전환해야 작용한다. 초고속 대사자는 같은 용량에서 모르핀 생성이 과도해 호흡 억제와 사망까지 일어날 수 있고, 수유부가 복용하면 모유를 통해 영아에게 전달된다. 반대로 저기능자는 진통 효과가 거의 없다. 이 양방향 위험 때문에 소아와 수유부에게는 코데인을 쓰지 않는다.
Q: 만성 알코올 사용자가 치료 용량의 아세트아미노펜에도 간독성을 보일 수 있는 기전은?
A: 만성 에탄올이 CYP2E1을 유도해 NAPQI 생성 비율이 커지는 동시에, 영양 불량과 금식으로 글루타티온 저장이 감소하고 글루쿠론산·황산 결합 능력도 떨어진다. 그 결과 통상 용량에서도 중화되지 않은 NAPQI가 중심엽 간세포 단백과 공유 결합해 괴사를 일으킨다. 이런 환자에서는 용량 상한을 낮추고 N-아세틸시스테인 투여 기준을 보수적으로 적용한다.
Q: 결핵 치료를 위해 리팜핀을 시작한 신장이식 환자에서 무엇을 어떻게 조정해야 하는가?
A: 리팜핀은 PXR을 통해 CYP3A4와 P-당단백을 강력히 유도해 타크로리무스·사이클로스포린·시롤리무스 농도를 급격히 떨어뜨리고 거부반응을 일으킨다. 농도를 자주 측정하며 용량을 크게 올려야 하고, 가능하면 리파부틴 같은 대체 약물을 고려한다. 또한 리팜핀 중단 후 유도 효과가 사라지며 농도가 급등하므로 중단 시점에도 같은 강도로 감시해야 한다.
Q: 플루오로우라실 투여 후 심한 점막염과 골수억제가 생겼다. 의심할 유전적 원인과 예방법은?
A: 디하이드로피리미딘 탈수소효소(DPYD) 결핍이다. 이 효소가 플루오로우라실의 80% 이상을 분해하므로 활성이 낮으면 노출이 급증해 치명적 독성이 생긴다. 투여 전 DPYD 주요 변이 유전형 검사나 우라실 농도 측정으로 선별해 용량을 감량하거나 대체 약물을 선택하며, 중증 독성 발생 시에는 우리딜 트리아세테이트를 해독제로 사용한다.
