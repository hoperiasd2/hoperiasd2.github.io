학습 목표

  1. 소리의 전도와 와우 변환(기저막 주파수 지도, 유모세포 기계전달)을 설명한다.
  2. 청각 경로와 난청의 분류·검사(웨버·린네, 청력도, 이음향방사)를 설명한다.
  3. 전정 기관의 구조와 전정안구반사·전정척수반사를 설명한다.
  4. 말초성과 중추성 어지럼을 감별하는 진찰(HINTS, 딕스-홀파이크)을 적용한다.
  5. 주요 어지럼 질환(BPPV, 전정신경염, 메니에르, 전정편두통, 뇌졸중)을 비교한다.

1소리의 전도와 와우 변환

  • 전도: 외이(이개·외이도 — 2–5 kHz 공명) → 고막 → 이소골(추골-침골-등골; 임피던스 정합 — 면적비 17배 + 지렛대 1.3배 ≈ 22배 증폭) → 난원창 → 와우 외림프.
  • 중이 근육 반사: 등골근(안면신경)·고막장근(삼차신경) — 큰 소리 보호; 안면신경 마비 시 청각과민.
  • 와우: 세 관(전정계·중간계·고실계), 중간계 내림프(K⁺ 150 mM — 혈관조에서 생성, +80 mV 내림프 전위) vs 외림프(Na⁺ 우세).
  • 기저막의 주파수 지도(tonotopy): 기저부(좁고 단단) — 고주파, 첨부(넓고 유연) — 저주파 → 진행파(von Békésy).
  • 유모세포 기계전달: 부동섬모가 덮개막에 의해 기울어짐 → 팁 링크(프로토카데린-15–카드헤린-23) 장력 → 기계전달 통로(TMC1/2) 개방 → K⁺ 유입(내림프 고K⁺ + 큰 전위차가 구동력) → 탈분극 → Ca²⁺ 유입 → 글루탐산 방출(리본 시냅스) → 나선신경절 → 와우신경.
  • 내유모세포(1열, 구심 95%) = 실제 감각 수용; 외유모세포(3열, 원심 지배) = 프레스틴으로 길이 변화 → 와우 증폭(민감도·주파수 선택성 100–1000배) → 이음향방사(신생아 청력 선별의 원리).
  • 유전성 난청: GJB2(코넥신 26 — K⁺ 재순환; 비증후군성 난청 최다, 한국 c.235delC), SLC26A4(펜드레드 — 전정수도관 확장), MYO7A·USH2A(어셔 — 난청 + 망막색소변성), MT-RNR1 m.1555A>G(아미노글리코사이드), OTOF(청각신경병증 — AAV-OTOF 유전자치료로 청력 회복 보고 2024).

2청각 경로와 난청

  • 경로: 와우신경 → 와우핵(연수) → (대부분 교차) 상올리브핵(소리 위치 파악 — 양이 시간·강도 차) → 외측섬유대 → 하구(중뇌) → 내측슬상체(시상) → 일차 청각피질(헤슬 이랑, 상측두회) — 양측성 표현이 커서 일측 피질 병변으로 난청이 생기지 않는다.
난청웨버(이마 음차)린네(공기 vs 뼈)원인
전음성병측으로 편위비정상(뼈 ≥ 공기)귀지, 삼출성 중이염, 고막 천공, 이경화증(등골 고정), 이소골 손상
감각신경성건측으로 편위정상(공기 > 뼈)노인성 난청(고주파 — 외유모세포 소실), 소음성(4 kHz 노치), 이독성(아미노글리코사이드·시스플라틴·루프 이뇨제), 메니에르(저주파), 돌발성 난청, 청신경초종
  • 검사: 순음 청력도, 어음 명료도(후미로성에서 불균형하게 나쁨), 고막운동도, 이음향방사(외유모세포), 청성뇌간반응(ABR — 신생아 선별·후미로 병변).
  • 돌발성 감각신경성 난청: 3일 이내 30 dB 이상 — 응급, 고용량 스테로이드(전신 ± 고막 내), MRI로 청신경초종 배제.
  • 노인성 난청과 인지: 치매의 수정 가능 위험인자 중 기여도가 큼(B05 L01) — 보청기·인공와우가 인지·사회 참여에 영향.
  • 이명: 말초 입력 소실 후 중추 과활성·가소성 — 소리 치료·인지행동치료.

3전정 기관과 반사

  • 반고리관(3개, 각가속도): 팽대부릉의 유모세포 — 머리 회전 시 내림프 관성 → 섬모 편위; 좌우 쌍이 밀고 당김(push-pull).
  • 이석기관(난형낭 — 수평 직선가속·머리 기울기, 구형낭 — 수직): 이석막의 탄산칼슘 결정.
  • 전정안구반사(VOR): 머리 회전 → 동측 반고리관 흥분 → 전정핵 → 반대측 외전신경핵 + MLF → 눈이 머리 반대 방향으로 이동 → 망막 상 안정(가장 빠른 반사, 지연 10 ms). 이득 = 눈 속도/머리 속도 ≈ 1.
  • 전정척수반사: 외측(항중력 신전근 — 자세), 내측(목).
  • 전정 보상: 일측 손상 후 수일–수주에 걸쳐 중추가 재조정 → 급성기 전정 억제제(메클리진·벤조디아제핀)를 길게 쓰면 보상을 방해하므로 단기간만 사용하고 전정 재활을 시작.
  • 어지럼 용어: 현훈(회전감 — 전정), 실신 전(순환), 불균형(소뇌·고유감각·파킨슨), 비특이 어지럼(약물·대사·심인성).

4어지럼의 진찰과 감별

  • 접근 전환: '어떤 느낌인지'보다 시간 경과와 유발 요인으로 분류(TiTrATE).

  • 소뇌 경색은 '단순 어지럼'으로 보일 수 있어 보행 평가(혼자 설 수 없으면 중추성 의심)가 중요하다.
  • 전정 재활: 적응(VOR 훈련), 습관화, 대치 — BPPV 외 대부분의 만성 어지럼에서 근거가 강하다.

연구 최전선

  • OTOF 유전자 치료로 선천성 난청 아동의 청력이 회복된 결과(2024)는 내이 유전자 치료의 임상 가능성을 열었으며 GJB2 등으로 확장이 시도된다.
  • 유모세포 재생(전구세포 재프로그래밍, 노치 억제)과 와우 유전자 전달 경로(정원창)가 연구 중이다.
  • 전정 임플란트(양측 전정 기능 소실)가 임상시험에서 자세·시야 안정 개선을 보이고 있다.

요약

  • 중이는 임피던스 정합으로 소리를 증폭하고, 와우 기저막은 주파수 지도를 형성하며, 유모세포는 팁 링크–기계전달 통로로 K⁺ 유입을 일으킨다.
  • 외유모세포의 프레스틴 기반 증폭이 민감도를 결정하며 이음향방사는 신생아 청력 선별의 기초이다.
  • 웨버·린네로 전음성과 감각신경성 난청을 구분하고, 일측 피질 병변은 난청을 일으키지 않는다.
  • 반고리관·이석기관은 VOR과 자세 반사를 매개하며 급성 일측 손상은 중추 보상으로 회복된다.
  • 어지럼은 시간·유발 요인으로 분류하고 HINTS와 딕스-홀파이크로 중추성과 BPPV를 감별한다.

자가 평가

  1. 급성 지속성 현훈 환자에서 두부 충동 검사가 '정상'인 것이 왜 더 위험한 소견인가?

    해설 보기

    전정신경염처럼 말초 전정 기능이 떨어지면 두부 충동 시 VOR 이득이 감소해 교정 단속운동이 나타난다(비정상). 반면 두부 충동이 정상이라면 말초 전정은 멀쩡하다는 뜻이므로, 지속적 현훈의 원인이 중추(소뇌·뇌간 경색)일 가능성이 높아진다. HINTS에서 방향 전환 안진이나 수직 사시가 동반되면 더욱 그렇다.

  2. 신생아 청력 선별에 이음향방사를 사용하는 원리는?

    해설 보기

    외유모세포는 프레스틴을 통해 능동적으로 길이를 변화시켜 소리를 증폭하는데, 이 과정에서 역으로 와우에서 외이도로 미세한 소리가 방출된다(이음향방사). 와우 기능이 정상이면 이 신호가 기록되므로 비침습적·빠른 선별이 가능하다. 다만 청각신경병증처럼 와우 이후 병변은 놓칠 수 있어 ABR을 병용한다.

  3. 좌측 귀가 전음성 난청일 때 웨버 검사에서 소리가 좌측으로 치우쳐 들리는 이유는?

    해설 보기

    전음성 난청에서는 외부 배경 소음이 차단되고 중이의 감쇠 효과가 사라져 골전도로 전달된 소리가 환측에서 더 크게 지각된다. 또한 골전도 에너지가 고정된 이소골계에서 밖으로 빠져나가지 못해 와우 자극이 증가한다. 반면 감각신경성 난청에서는 건측으로 치우친다.

  4. 급성 어지럼 환자에게 메클리진 같은 전정 억제제를 장기간 처방하지 않는 이유는?

    해설 보기

    전정 억제제는 급성기 증상을 줄이지만 중추 전정 보상 과정(비대칭 입력에 대한 재조정 학습)을 방해해 회복을 지연시킨다. 따라서 48–72시간 이내 단기간만 사용하고, 조기에 전정 재활 운동을 시작하는 것이 장기 예후에 유리하다.
