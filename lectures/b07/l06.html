학습 목표

  1. 망막의 세포층과 광전달(phototransduction) 과정을 설명한다.
  2. 시각 경로의 주행과 병변별 시야 결손을 정확히 국소화한다.
  3. 동공 반사 경로와 이상(구심성 동공 결손, 호르너, 아디, 동안신경 마비)을 설명한다.
  4. 눈운동의 종류(단속운동, 추종, 전정안구, 이접)와 조절 회로를 설명한다.
  5. 핵간안근마비·주시 마비·안진의 국소화를 적용한다.

1망막과 광전달

  • 세포층(빛이 지나는 순서): 신경절세포 → 쌍극세포 → 광수용체(뒤쪽) → 색소상피. 중심와는 광수용체 외 층이 밀려나 있어 빛이 직접 원뿔세포에 도달.
  • 막대세포(약 1억 2천만): 로돕신, 암순응·주변·무채색, 수렴이 커 민감도 높고 해상도 낮음. 원뿔세포(약 600만): S·M·L 옵신, 중심와 집중, 색·고해상도.
  • 광전달(암→명): 11-cis 레티날이 빛을 받아 all-trans로 이성질화 → 로돕신 활성 → 트랜스듀신(Gt) → cGMP 포스포디에스테라아제 활성 → cGMP 감소 → cGMP 개폐 양이온 통로 닫힘 → 과분극 → 글루탐산 방출 감소.
    • 어둠에서 광수용체는 탈분극 상태로 글루탐산을 지속 방출('암전류')한다 — 감각계 중 유일하게 자극이 과분극을 일으킨다.
    • 레티날 재생: 색소상피의 시각 회로(RPE65 — 레버 선천성 흑암시; 보레티진 유전자치료).
    • PDE6 변이 → 망막색소변성; 실데나필은 PDE5 선택성이 높으나 PDE6 교차 억제로 일시적 색각 이상(푸른 색조).
  • 쌍극세포: ON형(mGluR6 — 글루탐산에 과분극 → 빛에 탈분극), OFF형; 수평세포·아마크린세포가 측면 억제 → 중심-주변 길항 수용야(대비 강조).
  • 망막 질환: 당뇨망막병증(B05 L10), 연령 관련 황반변성(드루젠·보체 — 지도형 위축에 보체 억제제), 망막색소변성(야맹 → 터널 시야), 녹내장(신경절세포·시신경).
  • 내인성 광민감 신경절세포(ipRGC, 멜라놉신): 비영상 시각 — 동공 반사, 일주기 광동조(시교차상핵), 청색광 민감 → 전맹 환자의 비동조 수면(타시멜테온).

2시각 경로와 시야 결손

  • 망막 신경절세포 → 시신경 → 시신경교차(비측 망막 섬유 교차 — 양쪽 이측 시야) → 시삭 → 외측슬상체 → 시방사(측두엽 마이어 고리 — 상부 시야 / 두정엽 — 하부 시야) → 일차 시각피질(V1, 조거구 — 상부 시야는 아래 둑, 하부 시야는 위 둑).

  • 고위 시각: 배측 경로('어디/어떻게' — 두정; 발린트 증후군 — 시각실조·동시실인·눈운동 실행증), 복측 경로('무엇' — 측두; 얼굴실인증, 실독증).

3동공 반사와 이상

  • 빛 반사 경로: 망막(ipRGC 포함) → 시신경 → 시삭 → 시개앞핵(외측슬상체 우회) → 양측 에딩거-베스트팔 핵 → 동안신경 부교감 → 모양체 신경절 → 동공조임근 → 직접·간접(동의) 수축.
  • 상대적 구심성 동공 결손(RAPD, 마르쿠스 건): 흔들 전등 검사에서 병측 비출 때 양쪽 동공 산대 → 시신경·광범위 망막 병변(백내장·굴절 이상은 유발하지 않음).
  • 동안신경 마비: 안검하수 + 외하방 편위 + 동공 산대(부교감 섬유가 신경 표면에 위치) → 동공 침범 = 압박성(후교통동맥 동맥류 — 응급 혈관 영상); 동공 보존 = 허혈성(당뇨·고혈압; B05 L10).
  • 호르너 증후군: 동측 축동 + 부분 안검하수 + 무한증 — 교감 3차 뉴런 경로(시상하부 → 섬모양체척수중추 C8–T2 → 상경부 신경절 → 내경동맥 주위) 어디든; 원인 — 외측 연수 경색, 폐첨부 종양(판코스트), 경동맥 박리(통증 동반 — 응급), 신경모세포종(소아, 홍채 이색증).
  • 아디 긴장 동공: 모양체 신경절 손상 → 산대된 동공, 빛 반사 소실·근접 반사는 느리게 유지(빛-근접 해리), 희석 필로카르핀에 과민 — 양성(홈스-아디: + 반사 소실).
  • 아르길-로버트슨 동공(신경매독): 작은 불규칙 동공, 빛 반사 소실, 근접 반사 보존('매춘부 동공' — 조절은 되나 반응 안 함).
  • 약물: 아트로핀·스코폴라민(산동, 필로카르핀 무반응), 오피오이드(축동), 코카인·아프라클로니딘(호르너 진단).

4눈운동

종류기능발생기
단속운동(saccade)빠른 주시 이동(최대 700°/s)수평 — 교뇌 PPRF(방정중교뇌망상체) → 외전신경핵; 수직 — 중뇌 riMLF; 시작 — 전두안구영역(반대측), 상구; 억제 — 기저핵
추종(pursuit)움직이는 표적 추적후두-측두(MT/MST) → 뇌교핵 → 소뇌 벌레엽·타래 → 전정핵 (동측)
전정안구반사(VOR)머리 움직임 보상(가장 빠름)반고리관 → 전정핵 → 외전신경핵/MLF → 동안신경
시운동 안진큰 시야 이동 추적
이접(vergence)가까운 물체 — 수렴·조절·축동(근접 3징)중뇌
  • 내측세로다발(MLF): 외전신경핵 → 반대측 동안신경 내측직근 아핵 연결 → 핵간안근마비(INO): 병측 내전 장애 + 반대측 외전 안진; 양측 INO는 다발성 경화증(젊은), 단측은 교뇌 경색(노년).
  • 하나반 증후군: 교뇌 피개 병변(PPRF/외전신경핵 + MLF) → 동측 주시 마비 + INO → 유일하게 남는 운동은 반대측 눈 외전.
  • 주시 마비: 전두안구영역 병변 → 병변 쪽으로 눈이 쏠림(반대측으로 주시 못함, 대개 회복); 교뇌 PPRF 병변 → 병변 반대쪽으로 쏠림.
  • 파리노 증후군(배측 중뇌·송과체 종양): 상방 주시 마비, 빛-근접 해리, 수렴-후퇴 안진, 눈꺼풀 후퇴(콜리어 징후).
  • 안진: 말초성(수평-회선, 한 방향, 주시 고정으로 억제, 어지럼 심함) vs 중추성(수직·순수 회선·방향 전환, 고정으로 억제되지 않음) — HINTS 검사(두부 충동 정상 + 방향 전환 안진 + 교대 가림 사시 = 중추성, 뇌졸중 의심).

연구 최전선

  • 망막 유전자 치료(RPE65)와 광유전학 기반 시각 회복(ChrimsonR 발현 신경절세포 + 특수 고글 — 부분 시지각 회복 보고)이 실명 치료의 새 경로를 열었다.
  • 망막은 '뇌의 창'으로, 광간섭단층촬영(OCT)의 신경섬유층·망막 두께와 망막 혈관 분석이 다발성 경화증·알츠하이머·파킨슨병의 바이오마커로 연구된다.
  • 인공 시각(피질 임플란트, 망막 보철)과 시야 결손 재활(시야 훈련·프리즘)이 발전하고 있다.

요약

  • 광수용체는 빛에 과분극하며 로돕신–트랜스듀신–PDE–cGMP 경로로 신호를 전달한다.
  • 시신경교차 전은 단안 결손, 교차는 양이측 반맹, 교차 후는 동측 반맹을 만들며 측두엽·두정엽 시방사는 사분맹을 만든다.
  • RAPD는 시신경 병변을, 동공 침범 동안신경 마비는 압박성(동맥류)을, 호르너는 교감 경로 병변을 시사한다.
  • 단속운동(PPRF/riMLF), 추종(소뇌-후두), VOR(전정핵), 이접은 서로 다른 회로가 담당한다.
  • INO(MLF), 하나반 증후군, 파리노 증후군, 중추성 안진은 뇌간·중뇌 병변 국소화의 핵심 단서이다.

자가 평가

  1. 뇌하수체 거대선종 환자에게 양이측 반맹이 생기는 해부학적 이유는?

    해설 보기

    양측 비측 망막(즉 이측 시야를 담당)에서 나온 축삭이 시신경교차 중앙부에서 교차하는데, 뇌하수체에서 위로 자라는 종양이 바로 이 중앙 교차 섬유를 압박하기 때문이다. 상방 시야(하측 망막 섬유)가 먼저 침범되는 경향이 있다.

  2. 흔들 전등 검사에서 오른쪽 눈에 빛을 비출 때 양쪽 동공이 커지고, 왼쪽에 비추면 수축한다. 해석은?

    해설 보기

    오른쪽 상대적 구심성 동공 결손(RAPD)으로 오른쪽 시신경 또는 광범위 망막 병변을 시사한다(시신경염, 허혈성 시신경병증, 망막중심동맥폐쇄, 큰 망막박리). 굴절 이상이나 백내장 같은 매체 혼탁은 RAPD를 만들지 않는다.

  3. 급성 동안신경 마비 환자에서 동공 산대 유무가 왜 응급도를 결정하는가?

    해설 보기

    동공을 수축시키는 부교감 섬유는 동안신경의 표면 쪽에 주행해 외부 압박에 먼저 손상되고, 신경 중심부를 영양하는 미세혈관의 허혈에서는 보존되는 경향이 있다. 따라서 동공 침범은 후교통동맥 동맥류 등 압박성 병변을 시사해 즉시 혈관 영상이 필요하고, 동공 보존은 당뇨·고혈압성 허혈을 시사한다.

  4. 젊은 환자에서 양측 핵간안근마비가 보일 때 가장 의심되는 질환과 그 이유는?

    해설 보기

    다발성 경화증이다. 내측세로다발은 수초가 풍부한 뇌간 백질 경로로 탈수초 병변이 잘 생기며, 양측 침범은 혈관 병변보다 탈수초 질환에서 흔하다. 노년 환자의 단측 INO는 교뇌 열공 경색을 먼저 고려한다.
