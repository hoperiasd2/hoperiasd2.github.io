학습 목표

  1. 글리세로인지질의 종류와 막 비대칭성, 폐 계면활성제의 생화학을 설명한다.

  5. 지질 매개체(S1P, 리졸빈, 엔도카나비노이드)의 신호 기능을 이해한다.

1글리세로인지질과 막

  • 구조: 글리세롤 sn-1(대개 포화지방산), sn-2(대개 불포화, 아라키돈산 저장), sn-3 인산 + 머리기.

임상 연계

스콧 증후군(ANO6/TMEM16F 결손)은 혈소판 PS 외엽 노출이 실패해 응고인자 복합체가 조립되지 못하는 출혈 질환이다. 항인지질항체 증후군에서는 β2-당단백 I–음전하 인지질 복합체에 대한 자가항체가 혈전을 유발한다.

2폐 계면활성제

  • 주성분: 다이팔미토일 포스파티딜콜린(DPPC, ~40%) + PG + 계면활성 단백질 SP-A, SP-B, SP-C, SP-D. 제2형 폐포세포의 층판소체(ABCA3)에서 분비.
  • 폐포 표면장력을 낮춰 호기 말 폐포 허탈을 막는다(라플라스 법칙 P = 2T/r).
  • 태아 계면활성제 합성은 임신 28–32주 이후 증가하며 코르티솔이 유도한다.
  • 신생아 호흡곤란증후군(RDS): 미숙아 계면활성제 부족 → 무기폐, 저산소혈증, 유리질막.
    • 예방: 34주 미만 조산 위험 산모에게 산전 코르티코스테로이드(베타메타손).
    • 치료: 기관 내 외인성 계면활성제(포락탄트 알파 등), CPAP.
    • 태아 폐 성숙도: 양수 L/S 비(레시틴/스핑고미엘린) ≥ 2, PG 존재.
임상 연계

모체 당뇨는 태아 고인슐린혈증이 코르티솔의 계면활성제 유도를 방해해 같은 주수에서도 RDS 위험을 높인다. SFTPB, SFTPC, ABCA3 유전 결손은 만삭아의 치명적 호흡부전이나 소아 간질성 폐질환을 일으킨다.

3스핑고지질의 합성

  • 소포체: 세린 + 팔미토일-CoA → (세린 팔미토일전이효소 SPT, PLP) 3-케토스핑가닌 → 스핑가닌 → (세라마이드 합성효소 CerS1–6, 아실 길이 선택) 다이하이드로세라마이드 → (DES1) 세라마이드.
  • 골지:
    • 세라마이드 + PC → 스핑고미엘린(SMS) + DAG — 수초의 주성분.
    • 세라마이드 + UDP-포도당 → 글루코실세라마이드 → 락토실세라마이드 → 강글리오사이드(GM3 → GM2 → GM1…; 시알산 함유, 신경세포막).
    • 세라마이드 + UDP-갈락토스 → 갈락토실세라마이드 → 설파타이드 — 올리고덴드로사이트 수초.
  • 세라마이드–S1P 가변저항(rheostat): 세라마이드(세포자멸·인슐린 저항성) ↔ 스핑고신 ↔ 스핑고신-1-인산 S1P(생존·이동, S1PR1–5).
임상 연계

SPT 변이(SPTLC1/2)가 알라닌을 기질로 쓰면 독성 데옥시스핑고지질이 생겨 유전성 감각자율신경병증 1형(HSAN1)을 일으키며, 고용량 L-세린 보충으로 완화된다. 세린 결핍성 망막질환(MacTel 2)에서도 같은 기전이 확인되었다. 핀골리모드(S1P 수용체 조절제)는 림프구가 림프절에서 빠져나오지 못하게 해 다발성경화증 재발을 줄인다(B08).

4스핑고지질 분해와 리소좀 축적병

스핑고지질은 리소좀에서 비환원 말단부터 순차적으로 분해되며, 각 단계 효소의 결손이 특징적 축적병을 만든다(대부분 상염색체 열성; 파브리병은 X연관).

핵심

체리붉은반점(cherry-red spot): 망막 신경절세포에 지질이 쌓여 하얗게 보이는 가운데 신경절세포가 없는 중심와만 맥락막의 붉은색이 비쳐 보이는 현상. 테이-삭스, 니만-피크 A, 샌드호프, GM1 강글리오시드증, 중심망막동맥 폐쇄에서 나타난다.

임상 연계

GBA1 이형접합 보인자는 파킨슨병 위험이 5–10배 증가한다(가장 흔한 PD 유전 위험인자). 글루코세레브로시다아제 기능 저하가 α-시누클레인 응집을 촉진하는 양방향 고리가 제시되어 GCase 활성화제가 PD 치료제로 연구된다(B05, B06 참조).

막 인지질 → (cPLA₂, Ca²⁺·MAPK 활성화; 코르티코스테로이드가 아넥신-1 유도로 억제) 아라키돈산 → 세 경로.

  • 사이클로옥시게나아제(COX): COX-1(구성형; 위점막, 혈소판, 신장), COX-2(유도형; 염증, 신장·뇌에도 구성 발현) → PGG₂ → PGH₂ → 조직별 합성효소.
    • PGE₂: 발열(시상하부 EP3), 통증 과민, 위점막 보호, 신혈류 유지, 동맥관 개방 유지.
    • PGI₂(프로스타사이클린): 내피; 혈관확장·혈소판 억제.
    • TXA₂: 혈소판; 혈관수축·혈소판 응집.
    • PGF₂α: 자궁수축, 안압 저하(라타노프로스트).
    • PGD₂: 비만세포, 수면, 알레르기.

임상 연계

아스피린 악화 호흡기질환(AERD; Samter 삼징: 천식, 비용종, 아스피린 과민)은 COX-1 억제로 PGE₂의 제동이 사라지며 아라키돈산이 5-LOX 경로로 몰려 시스테이닐 류코트리엔이 과생산되어 발생한다.

6기타 지질 매개체

  • 특수 전염증 해소 매개체(SPM): EPA/DHA 유래 리졸빈(E·D 시리즈), 프로텍틴, 마레신; 아라키돈산 유래 리폭신. 염증의 '능동적 해소'를 유도(호중구 유입 차단, 대식세포 탐식 촉진). 아스피린-아세틸화 COX-2는 아스피린 유발 리폭신·리졸빈을 만든다.
  • 엔도카나비노이드: 아난다마이드(AEA), 2-AG → 시냅스 후 생성 후 역행성으로 전시냅스 CB1 수용체 작용 → 신경전달물질 방출 억제. FAAH, MAGL이 분해.
  • 리소포스파티드산(LPA): 오토탁신(ENPP2)이 생성; 섬유화·통증·암 이동.
  • S1P: 림프구 이동, 혈관 장벽 유지, 심박 조절(S1PR1 작용제의 서맥 부작용).

연구 최전선

  • 질량분석 기반 지질체학(lipidomics)으로 수천 종의 지질 분자종을 정량하며, 혈장 세라마이드 비(C16:0/C24:0)가 심혈관 위험 예측 지표로 임상 검사화되었다.
  • 리소좀 축적병 치료: 효소대체요법(ERT) → 기질감소요법(엘리글루스타트, 미글루스타트) → 샤페론(미갈라스타트; 파브리 반응성 변이) → 혈액뇌장벽 통과 ERT(트랜스페린 수용체 항체 융합 파비나페르스프 알파) → 조혈모세포/AAV 유전자 치료로 진화하고 있다.
  • 페로토시스: PUFA-PE의 지질 과산화가 GPX4·FSP1으로 방어되며, ACSL4가 감수성을 결정한다. 신경퇴행·허혈 손상·암 치료의 공통 기전으로 주목된다.

요약

  • 인지질은 막 비대칭성(PS 내엽)과 신호(PIP₂, 아라키돈산 저장)를 담당하고, DPPC는 폐 계면활성제의 핵심이다.
  • 스핑고지질은 세린 + 팔미토일-CoA에서 시작하며 세라마이드가 중심 허브이고 S1P와 균형을 이룬다.
  • 리소좀 스핑고지질 분해 효소 결손은 고셔·니만-피크·테이-삭스·파브리·크라베·MLD를 일으킨다.
  • 아라키돈산은 COX(PG, TX), LOX(LT), CYP 경로로 대사되며 아스피린·NSAID·COX-2 억제제·류코트리엔 길항제의 표적이다.
  • 염증은 리졸빈 등 SPM에 의해 능동적으로 해소된다.

  1. 저용량 아스피린이 혈소판의 TXA₂는 오래 억제하지만 내피의 PGI₂는 상대적으로 보존하는 이유는?

    해설 보기

    아스피린은 COX를 비가역적으로 아세틸화한다. 혈소판은 핵이 없어 새 COX-1을 합성하지 못하므로 혈소판 수명(7–10일) 동안 억제가 지속된다. 내피세포는 핵이 있어 수 시간 내 COX를 재합성하므로 PGI₂ 생산이 회복된다. 또한 저용량은 문맥 순환에서 혈소판을 먼저 아세틸화하고 전신 농도는 낮다.

  2. 6개월 영아가 발달퇴행, 소리에 대한 과도한 놀람반응, 망막 체리붉은반점을 보이나 간비장비대는 없다. 진단과 결손 효소, 축적물은?

    해설 보기

    테이-삭스병. 헥소스아미니다아제 A(HEXA) 결손으로 GM2 강글리오사이드가 신경세포 리소좀에 축적된다(양파껍질 모양 막성 세포질 소체). 내장 침범이 없어 간비장비대가 없다는 점이 니만-피크 A와의 감별점이다.

  3. 임신 31주 조산이 예상되는 산모에게 베타메타손을 투여하는 생화학적 근거는?

    해설 보기

    글루코코르티코이드는 제2형 폐포세포에서 계면활성제(DPPC 합성효소, SP-B, SP-C) 생성을 유도해 태아 폐 성숙을 촉진한다. 이로써 신생아 호흡곤란증후군, 뇌실내출혈, 괴사성 장염과 사망 위험이 감소한다.

  4. COX-2 선택적 억제제가 심혈관 혈전 위험을 높일 수 있는 기전은?

    해설 보기

    내피세포의 PGI₂(혈소판 억제·혈관확장) 생성은 상당 부분 COX-2 의존적인 반면, 혈소판 TXA₂ 생성은 COX-1에 의존한다. COX-2만 억제하면 PGI₂는 줄고 TXA₂는 유지되어 혈전 쪽으로 균형이 기운다(로페콕시브 철회 사례).
