1헴 생합성

헴은 적혈구 전구세포(전체의 ~85%)와 간(~15%; 사이토크롬 P450)에서 주로 합성된다. 첫 단계와 마지막 3단계는 미토콘드리아, 중간 4단계는 세포질에서 일어난다.

단계효소위치결손 질환
① 글리신 + 숙시닐-CoA → ALAALA 합성효소 (ALAS1 간 / ALAS2 적혈구; PLP)미토ALAS2 결손: X연관 철모구빈혈 / 기능획득: XLP

  • 조절: 간 ALAS1은 헴이 전사·mRNA 안정성·미토콘드리아 유입을 되먹임 억제하며, CYP 유도 약물(바르비투르산, 리팜핀, 알코올)·공복(PGC-1α)·프로게스테론이 유도한다. 적혈구 ALAS2는 철(IRE–IRP 시스템)에 의해 번역 조절되며 헴 되먹임을 받지 않는다.

2포르피린증의 임상

  • 급성 간 포르피린증(AIP, VP, HCP, ALAD): 상류 전구체 ALA·PBG 축적 → 신경독성(자율·운동·중추). 증상 5P: 복통(Pain in abdomen; 가장 흔함), 다발신경병증(Polyneuropathy), 정신증상(Psychological), 적색-갈색뇨(Port-wine urine), 유발인자(Precipitated by drugs). 저나트륨혈증(SIADH), 빈맥, 고혈압, 경련.
    • 유발: CYP 유도 약물(바르비투르산, 카르바마제핀, 페니토인, 설폰아마이드, 일부 경구피임약), 알코올, 공복·저칼로리, 황체기, 감염·스트레스.
    • 진단: 소변 PBG 정량(급성기 현저 증가) — 응급 선별.
    • 치료: 유발 약물 중단, 정맥 헤민(ALAS1 억제; 효과 가장 확실), 포도당 정주(경증; 포도당이 PGC-1α를 억제해 ALAS1↓), 통증·자율신경 조절(안전 약물 목록 참조), 재발성 발작 예방에 기보시란(간 ALAS1 siRNA).
  • 피부 포르피린증(PCT, EPP, CEP): 하류 포르피린 축적 → 빛(약 400 nm Soret 밴드) 흡수 → 활성산소 → 광과민.
    • PCT: 가장 흔한 포르피린증; 노출부 수포·취약성·다모증; 유발: 알코올, C형 간염, HIV, 철 과부하(HFE), 에스트로겐. 치료: 사혈, 저용량 하이드록시클로로퀸, HCV 치료.
    • EPP: 수포 없이 노출 수 분 내 극심한 작열통, 담석·간부전; 아파멜라노타이드(α-MSH 유사체 피하 이식제), 경구 MC1R 작용제(데르시멜라곤)와 페로킬라타아제 상류 ALAS2 조절 약물이 개발 중.
핵심

신경 증상은 ALA·PBG가 쌓이는 '급성 간형'에서만 나타나고, 광과민은 포르피린이 쌓이는 경우(PCT, EPP, CEP, 그리고 VP·HCP)에서 나타난다. VP·HCP는 두 증상 모두 가능하다.

임상 연계

납 중독: ALAD와 페로킬라타아제 억제 → 소변 ALA 증가, 적혈구 아연 프로토포르피린(ZPP) 증가, 미세구성 빈혈, 호염기성 반점(피리미딘 5'-뉴클레오티다아제 억제로 rRNA 잔존), 잇몸 납선, 신경병증(손목·발목 처짐), 소아 인지 저하. 킬레이트제(숙시머, CaNa₂EDTA, 다이머카프롤).

3헴 분해 개요

  • 비장·간 대식세포에서 헴 산소화효소-1(HO-1): 헴 → 빌리버딘(녹색) + Fe²⁺ + CO(유일한 내인성 CO 원천; 혈중 COHb 1% 수준). 빌리버딘 환원효소 → 빌리루빈(주황).
  • 비포합 빌리루빈 → 알부민 운반 → 간 OATP 흡수 → UGT1A1 글루쿠론산 포합 → MRP2로 담즙 배설 → 장내세균 → 유로빌리노겐(일부 재흡수·신장 배설) → 스테르코빌린(갈색 변).
  • HO-1은 스트레스(산화·열·헴) 유도 단백질로 항산화·항염 효과가 있다. 상세한 황달 감별은 B03 L04.

4카테콜아민

  • Tyr → (티로신 수산화효소 TH; BH₄; 속도결정; 카테콜아민 되먹임 억제, PKA 인산화로 활성) → L-DOPA → (방향족 L-아미노산 탈카복실화효소 AADC; PLP) → 도파민 → (도파민 β-수산화효소 DBH; 비타민 C, Cu²⁺; 소포 내) → 노르에피네프린 → (PNMT; SAM; 부신수질, 코르티솔이 유도) → 에피네프린.
  • 분해: MAO(미토콘드리아 외막; MAO-A: 5-HT·NE, MAO-B: 도파민) + COMT(SAM) → 바닐릴만델산(VMA), 호모바닐산(HVA), 메타네프린.

임상 연계

갈색세포종/부신경절종의 생화학 진단은 혈장 유리 메타네프린 또는 24시간 소변 분획 메타네프린이 VMA보다 민감하다(종양 내 COMT에 의해 지속적으로 생성). 약 40%가 생식세포 변이(SDHx, VHL, RET, NF1, MAX, TMEM127)를 가지므로 유전 상담이 권고된다. AADC 결핍(DDC)은 영아 안구운동발작·근긴장저하를 일으키며, AAV2-DDC 피하선조체 주입 유전자치료(엘라도카겐 엑수파르보벡)가 승인되었다.

5세로토닌, 멜라토닌, 히스타민, GABA

  • 세로토닌: Trp → (트립토판 수산화효소 TPH1 장크롬친화세포·TPH2 뇌; BH₄) 5-HTP → (AADC) 5-HT → (MAO-A) 5-HIAA. 인체 세로토닌의 약 90%는 장에서 생성되며 혈소판(SERT)에 저장된다.
    • 유암종 증후군: 간 전이 신경내분비종양에서 5-HT가 전신 순환 → 홍조, 설사, 기관지수축, 우심 판막 섬유화; 소변 5-HIAA 증가; Trp 소모로 펠라그라 발생 가능. 텔로트리스타트(TPH 억제제), 소마토스타틴 유사체.
    • 세로토닌 증후군: SSRI + MAOI/트라마돌/리네졸리드 등 → 고열, 간대성 근경련, 자율신경 불안정. 사이프로헵타딘.
  • 멜라토닌: 송과선에서 5-HT → (AANAT; 야간·노르에피네프린 의존) N-아세틸세로토닌 → (ASMT) 멜라토닌. 빛이 망막-시교차상핵 경로로 분비를 억제.
  • 히스타민: His → (히스티딘 탈카복실화효소; PLP) 히스타민. 비만세포·호염기구·위 ECL세포·뇌 결절유두핵. 수용체 H1(알레르기·각성), H2(위산), H3(신경 자가수용체), H4(면역). 고등어 중독(스콤브로이드): 부패 생선 세균이 히스티딘 → 히스타민.
  • GABA: 글루탐산 → (GAD65/67; PLP) GABA → (GABA 아미노기전이효소, PLP) 숙신산 세미알데하이드 → 숙신산(GABA 분로). 비가바트린은 GABA-T 비가역 억제제(영아연축). PLP 의존 효소이므로 피리독신 의존성 뇌전증(ALDH7A1; 축적된 P6C가 PLP를 불활성화)에서 신생아 난치성 경련이 B6에 반응한다. 이소니아지드 과량 → B6 고갈 → GABA 감소 → 경련(치료: 피리독신).

6NO, 크레아틴, 글루타티온, 폴리아민, 카르니틴

  • 산화질소(NO): L-아르기닌 + O₂ + NADPH → (NOS; BH₄, FAD, FMN, 헴, 칼모듈린) NO + 시트룰린. eNOS(혈관확장, 전단응력), nNOS(신경전달), iNOS(대식세포 고농도 NO; 패혈성 쇼크 저혈압). NO → 가용성 구아닐산 고리화효소 → cGMP → PKG → 평활근 이완. PDE5 억제제(실데나필)는 cGMP 분해를 막고, 질산염(니트로글리세린)과 병용 시 심한 저혈압.
  • 크레아틴: Arg + Gly → (AGAT; 신장) 구아니디노아세트산 → (GAMT; 간; SAM) 크레아틴 → 근육·뇌로 운반(SLC6A8) → 크레아틴 키나아제로 포스포크레아틴(빠른 ATP 완충). 크레아티닌은 비효소적 고리화 산물로 근육량에 비례해 일정하게 생성 → 사구체여과율 지표.
  • 글루타티온(GSH): γ-Glu-Cys-Gly. γ-글루타밀시스테인 합성효소(속도결정; GSH 되먹임) → GSH 합성효소. 기능: 과산화물 제거(GPx, 셀레늄), 생체이물 포합(GST; 아세트아미노펜 NAPQI 해독 → N-아세틸시스테인이 시스테인 공급), 티올 산화환원 완충. 결손: 5-옥소프롤린뇨증(용혈 + 대사산증; 아세트아미노펜 장기복용 후천성).
  • 폴리아민: 오르니틴 → (ODC, 속도결정) 푸트레신 → 스페르미딘 → 스페르민(SAM 유래 아미노프로필). 세포 증식·번역(eIF5A 하이푸신화). ODC 억제제 에플로르니틴(DFMO): 수면병(트리파노소마), 여성 다모증, 2023 고위험 신경모세포종 유지요법.
  • 카르니틴: 리신(단백질 내 트라이메틸리신) + Met(SAM) → 간·신장 합성 + 식이(붉은 고기). 장쇄 지방산 수송. 2차 결핍: 투석, 발프로산, 유기산혈증, 피발산 함유 항생제.

7트립토판 대사와 NAD⁺

  • 트립토판의 95%는 키뉴레닌 경로로 대사된다: Trp → (IDO1/IDO2, 간 TDO) N-포밀키뉴레닌 → 키뉴레닌 →
    • 키뉴레닌산(KYNA; 성상세포, NMDA·α7nAChR 길항 — 신경보호/인지 저하)
    • 3-하이드록시키뉴레닌 → 퀴놀린산(미세아교세포; NMDA 작용제, 흥분독성) → NAD⁺(de novo 합성)
  • 나이아신(B3) 결핍이 있을 때 트립토판 60 mg ≈ 나이아신 1 mg 당량. 펠라그라: 피부염, 설사, 치매, 사망(4D). 원인: 옥수수 주식(나이아신 결합형·Trp 부족), 알코올 사용장애, 하트넙병, 유암종, 이소니아지드(B6 결핍으로 키뉴레니나아제 저하).
  • IDO1은 염증(IFN-γ)으로 유도되어 국소 Trp 고갈 + 키뉴레닌(AhR 작용) → T세포 억제·조절 T세포 유도 → 면역관용(태반, 종양 면역회피). IDO1 억제제 에파카도스타트는 3상에서 펨브롤리주맙 병용 이득을 보이지 못했다.
  • 나이아신/니코틴아마이드 → NAD⁺ 재활용 경로(NAMPT 속도결정; NR·NMN 전구체) — 노화와 NAD⁺ 감소(B04 L10).

연구 최전선

  • 기보시란(GalNAc-siRNA)은 AIP에서 연간 발작률을 74% 줄였고(ENVISION), 간 표적 RNAi가 희귀 대사질환 치료의 범용 플랫폼임을 보였다. 다만 신장 기능·호모시스테인 상승이 관찰되었으며, 간 헴 감소로 헴 의존 효소 CBS 활성이 떨어지는 기전이 제시되어 연구가 진행 중이다.
  • 장내 미생물의 트립토판 대사물(인돌, 인돌-3-프로피온산)이 AhR·PXR을 통해 장벽·뇌 염증을 조절한다는 '장-뇌 축' 연구가 확장되었다(B08 L11).
  • 정신질환·신경퇴행질환에서 키뉴레닌 경로 불균형(퀴놀린산/키뉴레닌산 비)이 바이오마커·치료 표적으로 연구된다(B05 L15).

요약

  • 헴 합성의 속도결정 효소는 ALAS(간 ALAS1은 헴 되먹임, 적혈구 ALAS2는 철 조절)이다.
  • 급성 간 포르피린증은 ALA·PBG 축적으로 신경내장 발작, 피부 포르피린증은 포르피린 광과민을 일으킨다. 치료는 헤민, 포도당, 기보시란.
  • 티로신 → 도파민 → 노르에피네프린 → 에피네프린(TH가 속도결정), 분해는 MAO·COMT이다.
  • 트립토판은 세로토닌·멜라토닌과 키뉴레닌–NAD⁺ 경로로 가며, 펠라그라·유암종과 연결된다.
  • 아르기닌은 NO·크레아틴·요소·폴리아민의 공통 전구체이며, 글루타티온은 아세트아미노펜 해독의 핵심이다.

자가 평가

  1. 25세 여성이 다이어트와 새로 처방받은 항경련제 복용 후 심한 복통, 빈맥, 저나트륨혈증, 근력저하를 보이고 소변이 적갈색이다. 진단 검사와 치료는?

    해설 보기

    급성 간헐성 포르피린증(AIP) 급성 발작. 즉시 소변 PBG(및 ALA)를 정량한다. 유발 약물(CYP 유도 항경련제) 중단, 탄수화물 공급, 정맥 헤민 투여, 안전 약물로 통증·자율신경 증상 조절, 저나트륨혈증 교정, 호흡근 약화 감시. 재발 시 기보시란 예방을 고려한다.

  2. 납 중독에서 적혈구 아연 프로토포르피린이 증가하는 이유는?

    해설 보기

    납이 페로킬라타아제를 억제해 프로토포르피린 IX에 철 대신 아연이 삽입되기 때문이다(철결핍성 빈혈에서도 같은 이유로 증가). 납은 ALA 탈수효소도 억제해 소변 ALA가 증가한다.

  3. 비선택적 MAO 억제제 복용 중 숙성 치즈를 먹은 환자에게 고혈압 위기가 생기는 기전은?

    해설 보기

    티라민은 정상적으로 장과 간의 MAO-A에 의해 분해되지만 MAOI 복용 시 전신 순환으로 들어가 교감신경 말단에서 노르에피네프린을 대량 방출시키는 간접 교감신경작용제로 작용한다.

  4. 아세트아미노펜 과량 복용 시 N-아세틸시스테인이 효과적인 생화학적 이유는?

    해설 보기

    과량 시 글루쿠론산·황산 포합이 포화되어 CYP2E1이 독성 대사물 NAPQI를 더 많이 만든다. NAPQI는 글루타티온과 결합해 해독되는데, 글루타티온이 고갈되면 간세포 단백질과 결합해 괴사를 유발한다. NAC는 시스테인을 공급해 글루타티온을 재합성시키고 일부는 직접 NAPQI와 결합한다.
