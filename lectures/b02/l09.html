학습 목표

  1. 유전 부호, tRNA 아미노아실화, 리보솜 구조와 번역 개시·신장·종결의 기전을 설명한다.
  2. 번역 조절(eIF2α 인산화, mTORC1–4E-BP)과 통합 스트레스 반응을 설명한다.
  3. 항생제의 리보솜 표적과 리보솜병증을 연결한다.
  4. 단백질 접힘(샤페론), 번역후 변형(인산화, 당화, 유비퀴틴화 등), 콜라겐 합성을 설명한다.
  5. 유비퀴틴-프로테아솜계와 단백질 응집 질환(아밀로이드증, 신경퇴행)을 연결한다.

1유전 부호와 tRNA

  • 64개 코돈(61 감지 + 3 종결 UAA·UAG·UGA)이 20개 아미노산을 지정. 특성: 삼중, 겹치지 않음, 쉼표 없음, 축퇴성(대부분 3번째 위치 다양 → '동요(wobble)' 쌍), 거의 보편적(미토콘드리아 예외: UGA = Trp, AUA = Met, AGA/AGG = 종결).
  • 개시 코돈 AUG(Met; 세균은 fMet). 21·22번째 아미노산: 셀레노시스테인(UGA + SECIS 요소; 글루타티온 과산화효소, 갑상선 탈요오드효소, 티오레독신 환원효소), 피롤리신(고세균).
  • 아미노아실-tRNA 합성효소(aaRS): 아미노산 + ATP → 아미노아실-AMP → tRNA 3'-CCA에 결합. 20종, 교정 기능으로 정확도 10⁻⁴.
    • aaRS 변이: CMT 2형(GARS1, YARS1, AARS1 — 축삭 신경병증), 미토콘드리아 aaRS(DARS2 → LBSL 백질병증, RARS2 → 소뇌교 형성부전).
    • 자가항체: 항-Jo-1(히스티딜-tRNA 합성효소) → 항합성효소 증후군(근염, 간질성 폐질환, 기계공 손, 레이노).
    • 항생제 무피로신(Ile-tRNA 합성효소), 항진균 타바보롤(Leu-RS).

2리보솜과 번역 과정

  • 진핵 80S 리보솜 = 40S(18S rRNA) + 60S(28S, 5.8S, 5S rRNA). 세균 70S = 30S(16S) + 50S(23S, 5S). 펩티딜 전이효소는 23S/28S rRNA(리보자임).
  • 세 자리: A(아미노아실), P(펩티딜), E(출구).
  • 개시(진핵, 캡 의존): eIF2–GTP–Met-tRNAi 삼중체 + 40S + eIF1/1A/3 = 43S → eIF4F(eIF4E 캡 결합, eIF4G 골격, eIF4A 헬리케이스)가 캡에 장착 → 5'UTR 스캐닝 → Kozak 문맥(gccRccAUGG) AUG 인식 → eIF2 GTP 가수분해·방출(eIF2B가 GDP→GTP 재생) → eIF5B로 60S 결합 → 80S.
    • 대체: IRES(내부 리보솜 진입; HCV, 폴리오바이러스, 스트레스 시 일부 세포 mRNA), uORF(ATF4 재개시 조절).
  • 신장: eEF1A–GTP가 아미노아실-tRNA를 A자리로 → 코돈–안티코돈 확인 → 펩타이드 결합 형성 → eEF2–GTP 전위. 초당 약 5–6 아미노산(세균 ~20).
  • 종결: eRF1(3개 종결 코돈 모두 인식; tRNA 모방) + eRF3–GTP → 펩타이드 가수분해 방출 → ABCE1 리보솜 재순환.
  • 폴리솜: 하나의 mRNA에 여러 리보솜. 막 결합(분비·막단백, SRP) vs 유리 리보솜(세포질·핵·미토콘드리아 단백).
  • 리보솜 품질관리: 정지·충돌한 리보솜 → ZNF598 유비퀴틴화 → RQC(Listerin)로 미완성 사슬 분해.

임상 연계

백질 소실 백질뇌병증(VWM): eIF2B 5개 소단위(EIF2B1–5) 변이로 ISR이 과활성 → 감염·경미한 두부 외상 후 급격한 신경학적 악화, MRI에서 백질이 CSF처럼 '녹아' 보임. ISR 억제제 ISRIB 유사체(eIF2B 활성화제 DNL343 등)가 VWM·ALS에서 시험되고 있다.

6콜라겐: 번역후 변형의 교과서

  • 1차 구조: (Gly–X–Y)ₙ 반복, X = 주로 프롤린, Y = 하이드록시프롤린. 3번째마다 글리신(삼중나선 중앙 공간).
  • 세포 내: 프레프로콜라겐 → ER에서 프롤린·리신 수산화(비타민 C, Fe²⁺, α-KG, O₂) → 하이드록시리신 당화 → C-프로펩타이드 이황화결합으로 정렬 → 삼중나선(지퍼처럼 C→N) → 분비.
  • 세포 밖: 프로콜라겐 N·C 펩티다아제(ADAMTS2, BMP1)가 말단 절단 → 트로포콜라겐 자기조립 → 리실 산화효소(구리 의존)가 교차결합 → 미세섬유.

7단백질 분해와 응집 질환

  • 유비퀴틴-프로테아솜계(UPS): E1(활성; ATP) → E2(약 40종; 결합) → E3(약 600종; 기질 특이성: RING, HECT, RBR) → 다중 유비퀴틴 사슬(K48 → 프로테아솜 분해, K63 → 신호·DNA 수선·자가포식, M1 선형 → NF-κB) → 26S 프로테아솜(19S 조절 + 20S 촉매 β1 카스페이스 유사, β2 트립신 유사, β5 키모트립신 유사) → 탈유비퀴틴효소(DUB)가 유비퀴틴 재활용.
  • 프로테아솜 억제제(보르테조밉, 카르필조밉, 익사조밉): 형질세포는 면역글로불린 대량 합성으로 UPR 부담이 커 특히 민감 → 다발골수종·AL 아밀로이드증.
  • 면역프로테아솜(β1i, β2i, β5i): MHC I 항원 펩타이드 생성; 결손 → 프로테아솜 연관 자가염증증후군(PRAAS/CANDLE).
  • E3 연관 질환: 안젤만(UBE3A), 조기발병 PD(PRKN), VHL, MDM2–p53, 리들 증후군(ENaC의 NEDD4L 결합 부위 결손 → 고혈압).
  • 단백질 응집·아밀로이드: 교차 β-시트 섬유, 콩고레드 염색 편광에서 사과녹색 복굴절.

연구 최전선

  • 표적 단백질 분해(TPD): PROTAC(이기능; 표적 리간드–링커–E3 리간드)와 분자 접착제가 3상에 진입(베페데갈루타마이드 ER PROTAC). 'undruggable' 전사인자·스캐폴드 단백질 제거와 E3 리가아제 레퍼토리 확장이 과제이다.
  • 리보솜 프로파일링(Ribo-seq)으로 비정준 번역(uORF, lncRNA 내 소형 ORF, 마이크로단백질)이 대규모로 발견되었고, 일부는 암 특이 신생항원으로 면역치료 표적이 된다.
  • 크라이오-EM으로 환자 뇌의 타우·α-시누클레인·TDP-43 섬유 구조가 질환별로 다르다는 것이 밝혀져(타우 '접힘' 분류: AD, CTE, Pick, CBD, PSP), 구조 기반 진단 PET 리간드와 치료 항체 설계에 쓰인다(Scheres, Goedert 그룹).

요약

  • 유전 부호는 축퇴적이고 거의 보편적이며, aaRS가 정확도를 보장하고 그 결함은 신경병증·자가면역과 연결된다.
  • 진핵 번역은 eIF4F 캡 의존 스캐닝 개시, eEF1A/eEF2 신장, eRF1/3 종결로 진행된다.
  • eIF2α 인산화(ISR: PERK, PKR, GCN2, HRI)와 mTORC1–4E-BP가 번역의 주요 조절점이다.
  • 항생제는 세균 리보솜 30S/50S를 선택적으로 표적하지만 미토콘드리아 독성을 보일 수 있고, 리보솜병증은 조직 특이적 표현형을 보인다.
  • 번역후 변형(인산화, 당화, γ-카복실화, 콜라겐 수산화)과 UPS·아밀로이드는 다수 질환과 약물의 기초이다.

자가 평가

  1. 리네졸리드를 장기간(4주 이상) 투여한 환자에서 시신경병증, 말초신경병증, 젖산산증이 생길 수 있는 이유는?

    해설 보기

    미토콘드리아 리보솜은 세균 리보솜과 진화적으로 유사해 리네졸리드가 미토콘드리아 번역(23S 유사 rRNA)을 억제한다. 그 결과 mtDNA 부호화 호흡사슬 소단위 합성이 줄어 산화적 인산화 장애로 신경세포 손상과 젖산산증이 생긴다. 같은 기전으로 골수억제도 나타난다.

  2. 괴혈병에서 출혈과 상처 치유 지연이 생기는 생화학적 이유는?

    해설 보기

    비타민 C는 프롤릴·리실 수산화효소가 Fe²⁺를 환원 상태로 유지하는 데 필요하다. 결핍 시 하이드록시프롤린이 부족해 콜라겐 삼중나선이 체온에서 불안정해 분비·조립이 실패하고, 하이드록시리신 부족으로 교차결합이 약해진다. 혈관벽 기저막·결합조직이 약해 모낭 주위·잇몸·골막하 출혈이 생긴다.

  3. 보르테조밉이 다발골수종에 특히 효과적인 이유를 단백질 항상성 관점에서 설명하라.

    해설 보기

    골수종 세포는 대량의 면역글로불린을 합성해 ER에 잘못 접힌 단백질 부담이 크며, ERAD를 통한 프로테아솜 분해에 크게 의존한다. 프로테아솜이 억제되면 잘못 접힌 단백질이 축적되어 지속적 UPR(PERK–CHOP)로 자멸사가 유도되고, IκB 분해 차단으로 NF-κB 생존 신호도 감소한다.

  4. 통합 스트레스 반응에서 eIF2α 인산화가 전반적 번역은 줄이면서 ATF4 번역은 늘리는 기전은?

    해설 보기

    ATF4 mRNA의 5'UTR에는 상류 ORF(uORF1, uORF2)가 있다. 정상 시 리보솜은 uORF1 번역 후 빠르게 eIF2–GTP–Met-tRNA를 재적재해 억제성 uORF2에서 재개시하므로 ATF4 ORF를 지나친다. eIF2α 인산화로 삼중체가 부족하면 재적재가 지연되어 uORF2를 건너뛰고 ATF4 시작 코돈에서 재개시하게 된다.
