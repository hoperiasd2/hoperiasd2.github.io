학습 목표

  1. 신호전달의 일반 원리(리간드, 수용체, 증폭, 종결, 교차대화)를 설명한다.
  2. G단백질연결수용체(GPCR)와 cAMP·IP₃/DAG/Ca²⁺ 2차 전령, 세균 독소·약물 작용을 설명한다.
  3. 수용체 티로신 키나아제(RTK)의 Ras–MAPK, PI3K–AKT–mTOR 경로와 암 표적치료를 연결한다.
  4. JAK–STAT, TGF-β–SMAD, Wnt, Notch, Hedgehog, NF-κB 경로의 핵심과 질환을 설명한다.
  5. 핵수용체와 가스 신호(NO)의 작용 원리를 이해한다.

1신호전달의 일반 원리

  • 신호 양식: 내분비, 측분비, 자가분비, 접촉의존(주변분비), 시냅스.
  • 수용체 위치: 세포막(친수성 리간드: 펩타이드, 카테콜아민) vs 세포 내(소수성: 스테로이드, 갑상선호르몬, 레티노산, 비타민 D).
  • 막 수용체 4대 계열: 이온통로형, GPCR, 효소연결(RTK, 세린/트레오닌 키나아제, 사이토카인 수용체–JAK), 기타(Notch, Wnt Frizzled).
  • 증폭: 1개 수용체 → 다수 G단백 → 다수 cAMP → 키나아제 연쇄.
  • 종결·탈감작: GTP 가수분해(GTPase 내재·GAP), 포스파타아제, PDE, GRK 인산화 + β-아레스틴 결합 → 내재화, 수용체 하향조절.
  • 결과: 빠른 반응(효소·통로 변화, 초–분) vs 느린 반응(유전자 발현, 시간).

2G단백질연결수용체(GPCR)

GPCR은 7회 막관통 수용체로 인간 유전체에 약 800개가 있으며 승인 약물의 약 1/3이 표적한다. 리간드 결합 → 이종삼량체 G단백질(Gα·Gβγ)의 Gα GDP → GTP 교환 → Gα–GTP와 Gβγ가 분리되어 효과기를 조절.

3수용체 티로신 키나아제와 Ras–MAPK

  • 리간드(EGF, PDGF, FGF, VEGF, 인슐린, NGF) → 수용체 이량체화 → 상호 자가인산화 → 인산화 티로신이 SH2/PTB 도메인 단백질 결합 부위가 됨.
  • Ras–MAPK: Grb2(SH2)–SOS(GEF) → Ras-GDP → Ras-GTP → RAF → MEK → ERK → 핵 전사인자(Elk-1, c-Fos, c-Myc) → 증식·분화. Ras GAP(NF1의 뉴로피브로민)이 GTP 가수분해를 촉진해 끈다.
  • 종양유전자 변이: KRAS G12C/G12D/G12V(췌장암 >90%, 대장암 40%, 폐선암 30%), BRAF V600E(흑색종 50%, 갑상선 유두암, 털세포백혈병), EGFR 엑손19 결실·L858R(동아시아 비흡연 폐선암), HER2 증폭(유방암 15–20%), ALK·ROS1·RET·NTRK 융합.

4PI3K–AKT–mTOR와 인슐린 신호

  • RTK/IRS → PI3K → PIP₂ → PIP₃ → PDK1·mTORC2가 AKT 인산화·활성 → 생존(BAD·FOXO 억제), 포도당 흡수(AS160 → GLUT4), 글리코겐 합성(GSK3 억제), 단백질 합성(TSC2 억제 → Rheb → mTORC1 → S6K, 4E-BP1).
  • PTEN(지질 포스파타아제)이 PIP₃ → PIP₂로 되돌려 경로를 끈다.
  • mTORC1은 성장인자(AKT–TSC), 아미노산(Rag GTPase; 류신 센서 Sestrin2, 아르기닌 센서 CASTOR1), 에너지(AMPK → TSC2·Raptor 인산화)를 통합하는 '성장 스위치'.

임상 연계

mTOR 억제제(라파마이신 유사체)는 이식 거부 억제·약물 용출 스텐트·TSC 치료에 쓰이며, 모델 생물에서 수명 연장 효과가 가장 재현성 높게 확인된 약물이다(B04 L10).

핵심

같은 경로가 발생(형태 형성), 줄기세포 유지, 암에서 반복 등장한다. 생식세포 변이는 발생 증후군, 체세포 변이는 암을 일으키는 '동일 경로–다른 질환' 패턴을 기억하라.

6Ca²⁺ 신호, 핵수용체, 가스 신호

  • Ca²⁺: 세포질 ~100 nM vs 세포외 ~1–2 mM (10,000배). 유입(전압개폐 통로, 저장소작동 Ca²⁺ 유입 STIM1–ORAI1), 방출(IP₃R, RyR), 제거(PMCA, SERCA, NCX). 센서: 칼모듈린 → CaMKII, 칼시뉴린(→ NFAT 탈인산화 → T세포 활성; 사이클로스포린·타크롤리무스 표적).
  • 핵수용체(리간드 의존 전사인자; 48종):
    • I형(스테로이드: GR, MR, AR, ER, PR): 세포질에서 HSP90과 결합 → 리간드 결합 후 이량체 → 핵 → 호르몬 반응 요소(HRE).
    • II형(TR, RAR, VDR, PPAR, LXR, FXR): RXR과 이형이량체로 DNA에 상주, 리간드가 공동억제자 → 공동활성자 전환.
    • 약물: 타목시펜(SERM), 엔잘루타마이드(AR), 미페프리스톤, 피오글리타존(PPARγ), 오베티콜산(FXR), 전-트랜스 레티노산(APL의 PML-RARα 분화 유도).
  • 산화질소(NO): 세포막 자유 확산 → 가용성 구아닐산 고리화효소의 헴에 결합 → cGMP → PKG → 평활근 이완. 리오시구앗(sGC 자극제) 폐고혈압, 베리시구앗 심부전.
임상 연계

안드로겐 무감응 증후군(AR 기능소실, X연관): 46,XY이지만 완전형은 여성 외부생식기, 맹관 질, 자궁 없음(AMH 정상 작용), 사춘기 유방 발달(테스토스테론의 방향족화), 겨드랑이·음모 결여, 잠복고환(생식세포종양 위험).

연구 최전선

  • GPCR의 크라이오-EM 구조 폭증으로 구조 기반 약물 설계와 '알로스테릭 조절제'가 확대되었다. GLP-1 수용체 작용제(세마글루타이드)와 GIP/GLP-1(티르제파타이드), GIP/GLP-1/글루카곤 삼중 작용제(레타트루타이드)는 비만·당뇨·심혈관·신장·MASH·수면무호흡 치료를 재편하고 있다.
  • KRAS '불가능한 표적'의 극복: G12C 이후 G12D 억제제(MRTX1133), 범-RAS(ON) 억제제(다라삭시닙/RMC-6236)가 임상에 진입했다.
  • 공간·단일세포 인산화체학과 광유전학적 신호 조작으로 '신호의 동역학(진동·펄스)'이 정보를 부호화한다는 개념(ERK 펄스 빈도 → 증식 결정)이 정립되었다.

요약

  • 신호전달은 수용체 활성 → 증폭 → 효과기 → 종결(탈감작)의 원리를 따른다.
  • GPCR은 Gs(cAMP↑), Gi(cAMP↓), Gq(IP₃/DAG/Ca²⁺)로 나뉘고 콜레라·백일해 독소가 각각 Gs·Gi를 변형한다.
  • RTK–Ras–MAPK와 PI3K–AKT–mTOR는 증식·생존의 두 축이며 대표적 종양유전자 표적이다(EGFR, BRAF, KRAS, PIK3CA).
  • JAK–STAT, TGF-β, Wnt, Notch, Hedgehog, NF-κB는 발생 증후군과 암, 염증의 공통 경로이다.
  • 핵수용체는 리간드 의존 전사인자이며 Ca²⁺–칼시뉴린–NFAT은 면역억제제의 표적이다.

자가 평가

  1. 콜레라 독소와 백일해 독소는 모두 cAMP를 증가시킨다. 각각의 분자 기전 차이를 설명하라.

    해설 보기

    콜레라 독소는 Gαs를 ADP-리보실화해 내재 GTP 가수분해 활성을 없애 Gαs가 지속적으로 활성(GTP 결합) 상태에 머물게 한다. 백일해 독소는 Gαi를 ADP-리보실화해 수용체와의 결합(GDP–GTP 교환)을 막아 Gαi가 불활성 상태에 갇히므로 아데닐산 고리화효소에 대한 억제가 사라진다.

  2. KRAS 활성 변이 대장암에서 항EGFR 항체(세툭시맙)가 효과가 없는 이유는?

    해설 보기

    KRAS는 EGFR의 하류에 있으므로, KRAS가 GTP 결합형으로 지속 활성화되어 있으면 상류 EGFR을 차단해도 MAPK 신호가 계속 전달된다. 따라서 RAS 야생형(및 BRAF 야생형) 확인 후 항EGFR 치료를 선택한다.

  3. 결절성 경화증 환자에서 에베롤리무스가 혈관근지방종·뇌실막하 거대세포 성상세포종을 줄이는 원리는?

    해설 보기

    TSC1/TSC2 복합체는 Rheb의 GAP으로서 mTORC1을 억제한다. TSC 결손 시 Rheb–GTP가 증가해 mTORC1이 지속 활성화되어 세포 성장·증식이 증가한다. 에베롤리무스는 FKBP12와 결합해 mTORC1을 억제하므로 과성장이 억제된다.

  4. 진성적혈구증가증의 JAK2 V617F 변이가 에리트로포이에틴 없이도 적혈구 생성을 증가시키는 기전과 진단적 의의는?

    해설 보기

    V617F는 JAK2의 자기억제 유사키나아제(JH2) 도메인 변이로 키나아제가 리간드 없이 활성화되어 EPO 수용체–STAT5 신호가 지속된다. 그 결과 혈청 EPO는 낮은데도 적혈구가 증가한다. 진성적혈구증가증의 약 95%에서 발견되어 2차성 적혈구증가증과의 감별에 핵심이다.
