학습 목표

  1. 빌리루빈의 생성·운반·포합·배설 경로와 황달의 감별(비포합/포합)을 설명한다.
  2. 유전성 고빌리루빈혈증(길버트, 크리글러-나자르, 두빈-존슨, 로터)과 신생아 황달을 비교한다.
  3. 담즙산 합성·장간순환·FXR/FGF19 조절과 담즙정체 질환·약물을 설명한다.
  4. 탄수화물·단백질·지질 소화흡수의 효소와 수송체, 흡수장애 질환을 설명한다.
  5. 철·구리·비타민 B12의 흡수 대사와 관련 질환을 정리한다.

1빌리루빈 대사

  • 생성: 하루 약 250–350 mg, 80%는 노화 적혈구 헴(비장 대식세포), 20%는 무효 조혈·간 헴 단백(사이토크롬).
  • 헴 → (HO-1) 빌리버딘 → (빌리버딘 환원효소) 비포합 빌리루빈(지용성, 알부민 결합, 소변 배설 안 됨; 유리형은 혈액뇌장벽 통과 → 핵황달).
  • 간 흡수: OATP1B1/1B3 → 세포 내 리간딘(GST) → 소포체 UGT1A1이 글루쿠론산 2개 포합 → 포합 빌리루빈(수용성) → 소관막 MRP2(ABCC2)로 담즙 배설(속도결정 단계). 일부는 MRP3로 혈액으로 되돌아가 OATP로 재흡수('간세포 호핑').
  • 장: 세균 β-글루쿠로니다아제·환원 → 유로빌리노겐 → 일부 재흡수(장간순환·소변 배설) / 스테르코빌린(갈색 변).
  • 측정: 반 덴 베르그 반응 — 직접(포합 + 델타 빌리루빈) / 간접(비포합 = 총 − 직접). 델타 빌리루빈은 알부민에 공유결합한 포합형으로 반감기가 길어(~19일) 회복기 황달 지속을 설명.
구분원인소변 빌리루빈소변 유로빌리노겐변 색
비포합 우세 (전간성)용혈, 무효 조혈, 길버트, 크리글러-나자르음성증가(용혈)정상/진함
포합 우세 – 간세포성간염, 간경변, 약물, 두빈-존슨양성증가/정상정상
포합 우세 – 담즙정체/폐쇄성담석, 췌두부암, PBC, PSC, 담도폐쇄양성(진한 소변)감소/없음회색(무담즙변)

2유전성 고빌리루빈혈증과 신생아 황달

질환결함빌리루빈특징
길버트 증후군UGT1A1 프로모터 TA 반복(28; 서양) / *UGT1A1*6 G71R(동아시아)비포합, 대개 <3–4 mg/dL인구 5–10%; 공복·스트레스·감염 시 상승; 양성; 이리노테칸 독성↑; 아타자나비르 시 황달

두빈-존슨ABCC2(MRP2)포합흑색 간(에피네프린 대사물 색소), 소변 코프로포르피린 I 증가; 양성
로터SLCO1B1+SLCO1B3 동시 결손포합정상 색 간, 양성
  • 신생아 생리적 황달: 적혈구 수명 짧음(80–90일)·HbF 높음 + UGT1A1 미성숙 + 장간순환 증가(장내 세균 부족, β-글루쿠로니다아제) → 생후 2–4일 정점, 비포합.
  • 병적 황달 신호: 생후 24시간 내 황달, 빠른 상승(>0.2 mg/dL/h), 2주 이상 지속(만삭), 포합 빌리루빈 >1 mg/dL(담도폐쇄 등 담즙정체 — 응급 평가).
  • 광선요법: 청록색 빛(460–490 nm)이 빌리루빈을 수용성 구조 이성질체(루미루빈) 및 광이성질체로 바꿔 포합 없이 배설.
  • 모유 황달(모유 수유 황달 vs 모유 황달: 섭취 부족 vs 모유 β-글루쿠로니다아제·인자).
임상 연계

담도폐쇄증은 신생아 담즙정체의 가장 흔한 원인이며 생후 60일 이내 카사이 문합술을 시행해야 예후가 좋다. 대변 색 카드 선별(대만·일본·한국 도입)이 조기 발견에 효과적이다. 소아 간이식의 가장 흔한 적응증이다.

3담즙산 대사와 장간순환

  • 합성(간): 콜레스테롤 → 고전 경로 CYP7A1(속도결정) / 대체 경로 CYP27A1 → 1차 담즙산 콜산(CA), 케노데옥시콜산(CDCA) → 글리신/타우린 포합(pKa↓, 이온화 → 장 흡수 방지·미셀 형성) → BSEP(ABCB11)로 담즙 분비. 인지질은 MDR3(ABCB4), 콜레스테롤은 ABCG5/8.
  • 장: 지방 미셀 형성 → 회장 말단 ASBT로 95% 재흡수 → 문맥 → 간 NTCP 흡수(장간순환; 하루 6–10회 순환, 풀 3–5 g). 대장 세균이 탈포합·7α-탈수산화 → 2차 담즙산 데옥시콜산(DCA), 리토콜산(LCA; 독성, 황산화로 해독).
  • 조절: 담즙산 → 회장 FXR → FGF19 → 간 FGFR4/β-Klotho → CYP7A1 억제; 간 FXR → SHP → CYP7A1 억제, BSEP 유도. TGR5(GPCR): GLP-1 분비, 갈색지방 열생성, 담낭 이완.
  • 담즙산은 '호르몬'이자 미생물 생태 조절자이며 비만대사수술 후 담즙산 증가가 대사 개선에 기여한다.
질환·약물기전
진행성 가족성 간내 담즙정체(PFIC)1형 ATP8B1, 2형 ABCB11(BSEP; HCC 위험), 3형 ABCB4(MDR3; GGT 높음) → IBAT 억제제 오데빅시밧, 마랄릭시밧(가려움·담즙산 감소)
알라질 증후군JAG1/NOTCH2 — 담관 부족, 나비 척추, 후배아환, 말초 폐동맥 협착 → 마랄릭시밧
원발성 담즙성 담관염(PBC)항미토콘드리아 항체(PDC-E2), 중년 여성 → UDCA, 불응 시 오베티콜산(FXR 작용제; 간경변 환자 간손상으로 사용 제한), 엘라피브라노르·셀라델파(PPAR 작용제, 2024 승인)

담즙산 설사회장 절제·크론병 → 대장에서 Cl⁻ 분비 → 담즙산 결합제

4탄수화물과 단백질의 소화흡수

  • 탄수화물: 침·췌장 α-아밀라아제(α-1,4 → 말토스, 말토트리오스, α-한계덱스트린) → 솔가장자리 이당류분해효소: 수크라아제-이소말타아제, 말타아제-글루코아밀라아제, 락타아제(β-갈락토시다아제), 트레할라아제 → 단당류 → SGLT1(포도당·갈락토스), GLUT5(과당) → 기저측 GLUT2.
    • 락타아제 비지속성(성인 젖당불내증): 전 세계 약 65–70%, 동아시아 90% 이상. 젖당이 대장에서 발효 → H₂·CO₂·단쇄지방산 → 복부팽만·삼투성 설사. 수소 호기 검사로 진단.
    • 선천성 수크라아제-이소말타아제 결핍: 영아 설사(자당 도입 시) → 사크로시다아제 효소.
    • 포도당-갈락토스 흡수장애(SLC5A1): 신생아 심한 설사 → 과당 기반 분유.
  • 단백질: 펩신(위) → 트립신·키모트립신·엘라스테이스·카복시펩티다아제(췌장; 엔테로펩티다아제가 트립시노겐 활성 → 연쇄 활성) → 솔가장자리 펩티다아제 → 아미노산 수송체(B⁰AT1, b⁰⁺AT 등)와 다이/트라이펩타이드 PEPT1.
    • 엔테로펩티다아제 결핍: 영아 부종·성장 장애·저단백혈증.
    • 유전성 췌장염: PRSS1 기능획득(트립신 자가분해 저항) → 반복 췌장염, 췌장암 위험; SPINK1, CFTR, CTRC 변이.

5지질 소화흡수와 흡수장애

  • 혀·위 리파아제(신생아에서 중요) → 췌장 리파아제 + 콜리파아제(담즙산 미셀 표면에서 작용) → 2-모노아실글리세롤 + 지방산; 콜레스테롤 에스터라아제; 포스포리파아제 A₂.
  • 미셀(담즙산 + 인지질 + 2-MG + 지방산 + 콜레스테롤 + 지용성 비타민) → 솔가장자리 흡수(CD36, NPC1L1 콜레스테롤 — 에제티미브 표적).
  • 장세포 내: TG 재합성(MGAT/DGAT) → MTP가 apoB-48에 지질 적재 → 킬로미크론 → 림프. 중쇄지방산(MCT; C8–C12)은 미셀·킬로미크론 없이 문맥으로 직접 흡수.
흡수장애 분류예단서
관강 내(소화 장애)만성 췌장염·낭성섬유증(췌장 외분비 부전), 담즙산 부족(담즙정체, 회장 절제), 소장 세균 과증식지방변, 대변 엘라스테이스-1 저하 → 췌장효소 대체(PERT)
점막셀리악병(HLA-DQ2/DQ8, 글루텐 → tTG 항체, 융모 위축; 철결핍·골다공증·포진상 피부염), 열대 스프루, 휘플병(PAS 양성 대식세포), 이당류분해효소 결핍항-tTG IgA(총 IgA 확인), 십이지장 생검
흡수 후(운반)무베타지단백혈증, 장림프관확장증극세포, 림프구감소·저알부민
  • 지용성 비타민 결핍: A(야맹증, 각막연화), D(골연화), E(척수소뇌 변성, 용혈), K(INR 상승, 출혈).

6철, 구리, 비타민 B12의 흡수와 대사

  • 철(하루 흡수 1–2 mg, 배설 조절 없음 → 흡수에서 조절):
    • 비헴철 Fe³⁺ → 솔가장자리 DCYTB 환원 → Fe²⁺ → DMT1 흡수 → 페리틴 저장 또는 기저측 페로포틴 배출 → 헤페스틴 산화 → 트랜스페린. 헴철은 별도 경로(수송체·세포내섭취; 기전 미확정)로 흡수된 뒤 HO-1로 철이 유리된다.
    • 헵시딘(간 분비): 페로포틴 결합·분해 → 흡수·대식세포 철 방출 차단. 철 과잉·염증(IL-6–STAT3)이 증가시키고, 빈혈·저산소·적혈구 생성(에리트로페론)이 억제.
    • 질환: 철결핍빈혈(페리틴 <30 ng/mL), 만성 염증 빈혈(헵시딘↑ → 페리틴 정상·높음, 트랜스페린 포화도 낮음), 유전성 혈색소증(HFE C282Y — 북유럽; 헵시딘 상대 결핍 → 철 과흡수 → 간경변·당뇨·청동 피부·관절병증·심근병증; 사혈), 철 불응성 철결핍빈혈(TMPRSS6 → 헵시딘↑).
  • 구리: 장 CTR1 흡수 → ATP7A로 기저측 배출(결손: 멘케스병) → 간 → ATP7B가 세룰로플라스민에 적재·담즙 배설(결손: 윌슨병 — 간·신경·카이저-플라이셔 고리, 세룰로플라스민↓, 24시간 소변 구리↑ → 페니실라민·트리엔틴·아연).
  • 비타민 B12: 식이 단백 결합 → 위산·펩신 유리 → 침 합토코린(R 단백) 결합 → 십이지장 췌장 단백분해로 유리 → 위벽세포 내인자(IF) 결합 → 회장 말단 큐빌린–앰니오네스 수용체 흡수 → 트랜스코발라민 II.
    • 결핍 원인: 악성빈혈(항IF·항벽세포 항체, 위축성 위염), 위절제·비만수술, 회장 절제·크론병, 메트포르민·PPI 장기 복용, 엄격한 채식, 광절열두조충, 질소 산화물(N₂O; 코발라민 산화 → 급성 척수병증).
    • 결과: 거대적모구빈혈 + 아급성 연합 변성(후삭·측삭), 말초신경병증, 인지장애; MMA·호모시스테인 상승(B01 L05, L10).
임상 연계

아산화질소(웃음 가스) 남용 젊은 성인의 급성 척수병증·신경병증이 증가하고 있다. 혈청 B12는 정상일 수 있으나 MMA·호모시스테인이 상승하며 MRI에서 경수 후삭의 '역 V자' T2 고신호를 보인다. 비경구 B12 즉시 투여가 필요하다.

연구 최전선

  • 담즙산–미생물–숙주 축: 장내 미생물이 만드는 담즙산 접합체(MCA, 아미노산 접합 담즙산 — 새로운 '미생물 접합 담즙산' 수백 종 발견, Quinn et al., Nature 2020)가 면역과 대사를 조절한다는 연구가 확장되고 있다.
  • 크리글러-나자르 1형에 대한 AAV8-UGT1A1 유전자 치료가 광선요법 의존도를 줄였으며, 윌슨병 AAV-ATP7B 치료와 구리 결합 약물(비스-콜린 테트라티오몰리브덴산은 개발 중단)이 연구 중이다.
  • 헵시딘 조절제(헵시딘 모방 루스페르타이드 — 진성적혈구증가증 3상 성공, 헵시딘 억제제 — 염증 빈혈)가 철 대사 질환 치료를 확장하고 있다.

요약

  • 빌리루빈은 UGT1A1 포합과 MRP2 배설을 거치며, 황달은 비포합(용혈·길버트)과 포합(간세포성·담즙정체)으로 감별한다.
  • 크리글러-나자르(UGT1A1)·두빈-존슨(MRP2)·로터(OATP)는 유전성 고빌리루빈혈증이고, 신생아 포합 황달은 담도폐쇄 응급 평가가 필요하다.
  • 담즙산은 CYP7A1이 합성하고 장간순환과 FXR–FGF19가 조절하며, PFIC·PBC·담석은 이 경로의 이상이다.
  • 탄수화물(락타아제·SGLT1), 단백질(엔테로펩티다아제·트립신), 지질(리파아제·미셀·MTP)의 단계별 결손이 흡수장애를 만든다.
  • 철은 헵시딘–페로포틴, 구리는 ATP7A/7B, B12는 내인자–큐빌린 경로로 조절되며 각각의 결손이 특징적 질환을 일으킨다.

자가 평가

  1. 25세 남성이 감기 후 경미한 황달을 보였다. 총 빌리루빈 3.2, 직접 0.3 mg/dL, 혈색소·망상적혈구·간효소 정상이다. 진단과 임상적 의미는?

    해설 보기

    길버트 증후군(UGT1A1 활성 저하에 의한 비포합 고빌리루빈혈증; 공복·감염 시 악화)이다. 양성으로 치료가 필요 없지만 이리노테칸(SN-38 포합 저하로 중증 호중구감소·설사), 아타자나비르·인디나비르 등 UGT1A1 의존 약물 사용 시 주의가 필요하다.

  2. 무담즙변(회색 변), 진한 소변, 가려움을 동반한 황달 환자의 검사 소견으로 예상되는 것은?

    해설 보기

    포합 빌리루빈 우세 상승, 소변 빌리루빈 양성, 소변 유로빌리노겐 감소·소실(장으로 빌리루빈이 가지 않음), ALP·GGT 현저 상승, 담즙산 상승(가려움), 장기간이면 지용성 비타민 K 흡수 장애로 INR 상승(비타민 K 정주로 교정됨). 영상으로 담관 확장 여부를 확인한다.

  3. 만성 염증 질환 환자의 빈혈을 철결핍빈혈과 구분하는 철 지표 패턴과 그 기전은?

    해설 보기

    만성 염증 빈혈은 혈청 철·트랜스페린 포화도가 낮지만 페리틴은 정상·증가하고 TIBC는 정상·감소한다. IL-6가 간 헵시딘을 증가시켜 페로포틴을 분해하므로 장 흡수와 대식세포 철 방출이 막혀 철이 저장고에 갇히기 때문이다. 철결핍빈혈은 페리틴이 낮고 TIBC가 증가하며, 가용성 트랜스페린 수용체가 증가한다.

  4. 셀리악병 선별검사로 항-tTG IgA를 측정할 때 총 IgA를 함께 측정하는 이유는?

    해설 보기

    셀리악병 환자에서 선택적 IgA 결핍의 빈도가 일반 인구보다 높아(약 2–3%), IgA 결핍이면 항-tTG IgA가 위음성이 된다. 총 IgA가 낮으면 IgG 기반 검사(항-DGP IgG, tTG IgG)를 사용하며, 검사는 글루텐 섭취 중에 시행해야 한다.
